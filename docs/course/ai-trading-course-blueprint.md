# AI 트레이딩 강의 Blueprint

> 이 문서는 강의 설계의 단일 기준 문서입니다.  
> 패스트캠퍼스 제출용 스프레드시트는 이 문서를 바탕으로 작성하고, 브레인스토밍 원문은 `data/cursor_ai_trading_course_planning.md`에 보존합니다.

## 1. 강의 목표

- 대상: 코딩과 퀀트 경험이 거의 없는 한국 개인 투자자
- 약속: 코드를 외우는 대신 전략을 규칙으로 표현하고, AI에게 구현을 요청하고, 사람이 결과를 검증하는 방법을 배웁니다.
- 범위: 한국 주식 중심의 데이터 수집, 백테스트, WFA, 신호 알림, 로컬 가상 매매 장부, 마지막 KIS 연동
- 제외: 수익 보장, LLM의 자유로운 실시간 주문, HFT, 1초봉·틱 기반 전략

## 2. 핵심 교육 철학

### 2.1 사람이 판단하는 작업 루프

```text
생각
→ 결과 모습이 포함된 목표를 AI에게 전달
→ 사람이 차트·표·동작을 확인
→ 부족한 점만 후속 프롬프트
```

- 코드가 강사와 같을 필요는 없습니다.
- 확인은 AI에게 위임하지 않습니다.
- 각 단계의 체크리스트를 통과하면 다음 단계로 이동합니다.

### 2.2 전략 개발 루프

```text
유명 전략의 원리 이해
→ 규칙 문장 작성
→ 변경 가능한 파라미터 범위 제한
→ 거래비용 포함 백테스트
→ MDD와 손실 구간 확인
→ WFA
→ 사람이 유지·변경·폐기 결정
```

“우리만의 전략”은 지표를 무한히 추가하는 전략이 아닙니다. 알려진 원리를 출발점으로 제한된 변경만 실험하고, 가설·설정·결과를 버전별로 기록하는 전략입니다.

## 3. 강의 알고리즘 지도

강의는 특정 한 전략을 정답으로 제시하지 않습니다. 네 전략을 같은 평가 틀에 넣어 비교합니다.

1. 추세추종
   - 직관: 상승 추세에 참여하고 추세가 무너지면 방어
   - 주요 위험: 늦은 진입·청산, 횡보장 whipsaw
2. 변동성 돌파·모멘텀
   - 직관: 평소보다 강한 가격 움직임을 추종
   - 주요 위험: 높은 회전율과 거래비용
3. 듀얼 모멘텀·자산배분
   - 직관: 상대적으로 강한 자산을 선택하고 절대 모멘텀이 약하면 현금
   - 주요 위험: 급반등 초기를 놓침
4. 페어 트레이딩
   - 직관: 시장 방향보다 경제적으로 연결된 두 종목의 상대가격 평균회귀를 거래
   - 주요 위험: 관계 붕괴, 대주 재고·공매도·차입비용

각 알고리즘은 이론과 실습을 분리합니다. 이론에서는 규칙·유니버스·잘 작동하는 국면·실패 국면을 설명하고, 실습에서는 같은 출력 형식으로 수익률·MDD·비용·약점 구간을 확인합니다.

## 4. WFA: 과거 속의 미래

WFA의 “다음 구간”은 실제 달력의 미래를 미리 보는 것이 아닙니다. 현재는 이미 과거인 데이터를 당시 시점으로 되돌려 재생하는 모의 미래입니다.

```text
회차 1: 과거 A에서 파라미터 선택 → 아직 보지 않은 과거 B에서 평가
회차 2: 시간창 이동 → 과거 B까지 학습 → 과거 C에서 평가
회차 3: 같은 과정을 현재 직전까지 반복
```

- 각 회차는 당시 이용 가능했던 데이터만 사용합니다.
- 결과는 out-of-sample 성적표이지 실제 미래 보장이 아닙니다.
- 최종 선택 뒤에는 별도 holdout과 Paper Trading을 확인합니다.
- 가장 좋아 보이는 숫자를 같은 데이터에서 사후 선택하지 않습니다.

## 5. 미국 WFA 시그니처 데모

### 5.1 역할

기존 S&P 500 페어 트레이딩 구현은 상세페이지, 무료 세미나, WFA 고급 사례에 사용합니다.

### 5.2 하이브리드 규칙

- 일반 국면: S&P 500 보유
- 페어 국면 진입:
  - 고점 대비 하락률 `-10%` 이하
  - 100일 이동평균의 기울기가 음수
  - 이전 페어 국면 종료 후 40거래일 쿨다운
- 일반 국면 복귀:
  - 페어 국면 최소 60거래일 유지
  - 이동평균 기울기 회복 확인

`hybrid_result`는 전체 전환 전략 결과입니다.

- `hybrid_equity`: S&P 500과 페어 전략을 연결한 전체 자산 곡선
- `regime`: 날짜별 `sp500` 또는 `pairs`
- `episode_results`: 하락 국면마다 다시 실행한 페어 WFA 성적표
- `pairs_equity`: 전 기간 페어만 운용한 비교용 자산 곡선

`episode_results`는 “하락장별 성적표 묶음”입니다. 각 항목에는 해당 하락 국면의 거래, 일별 수익률, 리밸런싱, MDD와 요약 통계가 포함됩니다.

## 6. 한국형 지수-현금 전략 연구실

### 6.1 목적

공매도와 증권사 API 없이도 시장 국면, 손실 제어, 파라미터 선택과 WFA를 가르칩니다.

### 6.2 비교 전략

- 비교군: KOSPI 200 추종 ETF 계속 보유
- 실험군: 지수 하락폭과 이동평균 추세가 동시에 위험 신호이면 다음 거래일부터 현금 대기
- 하락폭 후보: `-5%`, `-10%`
- 추세 window: 사전에 정한 소수 후보만 비교
- 현금 수익률: 첫 실습에서는 0%, 후속 실습에서 CMA·단기채 수준을 선택적으로 반영

### 6.3 확인 지표

- 누적수익률과 연환산수익률
- MDD와 손실 회복기간
- 시장 참여율과 현금 보유기간
- 전략 전환 횟수
- 거래비용과 whipsaw 손실

핵심 질문은 “수익률이 조금 낮아져도 MDD가 크게 줄면 어떤 전략을 선택할 것인가?”입니다.

## 7. 데이터 주기

일봉은 기준점이지 고정 제약이 아닙니다.

- 일봉: 장기 연구, 시장 국면, 추세추종, 듀얼 모멘텀, WFA
- 1시간봉: 최근 관계와 국면 재확인
- 5~15분봉: 진입·청산 시점과 실행 품질 검증
- 1초봉·틱: HFT가 아니므로 제외

세밀한 과거 데이터와 실시간 스트리밍은 다른 요구사항입니다. 강의용 분봉은 저장된 데이터로 제공할 수 있고, 실시간 스트리밍은 마지막 KIS 확장에서만 필요합니다.

## 8. 가격 공급원

전략 엔진은 가격 공급원과 분리합니다.

1. `ReplayMarketData`
   - 저장된 과거 데이터를 실시간처럼 재생
   - API 키 없이 모든 수강생이 동일한 장면을 재현
   - 화면에 “과거 데이터 재생”이라고 명시
2. `EndOfDayMarketData`
   - FinanceDataReader 일봉
   - 장 마감 후 신호 생성과 다음 거래일 계획
3. `KisMarketData`
   - 마지막 KIS 연동
   - 잔고·체결 동기화와 선택형 주문이 우선
   - WebSocket은 장중 기능이 필요한 보너스 범위

FinanceDataReader와 KRX 무료 Open API를 보장된 실시간 체결가 소스로 표현하지 않습니다.

## 9. 가상 매매 장부

개발명 `PaperBroker`는 증권사 서버가 아니라 프로젝트 내부의 가상 현금·포지션·체결 기록기입니다. 수강생 화면에서는 “가상 매매 장부”로 표시합니다.

```text
신호 발생
→ 알림
→ 실행·거절·보류 선택
→ 가상 수량과 예상 체결가 기록
→ 수수료·슬리피지 반영
→ 잔고와 손익 갱신
```

실제 돈, 증권사 계좌, 거래소 주문은 사용하지 않습니다.

## 10. 실제 운영과 KIS 확장

### 10.1 기본 운영

- 장 마감 후 일봉 신호
- 사용자가 증권사 앱에서 직접 주문
- 사용자가 `실행/거절/보류`, 수량, 실제 체결가를 기록
- 로컬 장부와 실제 계좌의 차이를 매일 확인

### 10.2 확장 순서

```text
수동 체결 입력
→ 증권사 거래내역 CSV 가져오기
→ KIS 잔고·체결 읽기 전용 연동
→ KIS 모의주문
→ 선택형 가드레일 실주문
```

KIS는 실시간 데이터 자체보다 잔고·체결 동기화와 주문 연결을 위해 사용합니다.

## 11. 알림과 사용자 승인

- 텔레그램: 신호, 실행·거절·보류 버튼, 일일 보고서
- 카카오톡·이메일: 신호와 보고서 전달 보조
- 알림 장애가 전략과 주문 상태를 바꾸지 않도록 알림과 실행 엔진을 분리

## 12. 자동화 가드레일

AI는 직접 주문하지 않습니다. 사람이 승인한 전략 버전을 결정론적 엔진이 실행합니다.

- 포지션 및 종목별 한도
- 일일 손실 한도
- 데이터 지연 감지
- API 오류
- 예상 포지션과 실제 잔고 불일치
- 신규 진입 중단
- 미체결 주문 취소
- 기존 포지션 청산은 사전 손절 규칙 또는 사람 승인

운영 원칙은 “매일 관찰, 천천히 변경, 긴급 시 즉시 중단”입니다.

## 13. 전략 변경 주기

- 매일: 데이터·API·포지션·손익·비용·슬리피지·이상 징후 확인
- 손실 발생: AI 보고서와 제한된 변경 후보 기록
- 주간: 반복되는 문제인지 검토
- 월간 또는 리밸런스 시점: 충분한 표본이 쌓인 후보만 재검증
- 배포: WFA·holdout·Paper Trading을 통과하고 사람이 승인한 버전만 반영

하루 손실만 보고 파라미터를 즉시 바꾸지 않습니다.

## 14. 무료 세미나와 유료 강의

### 무료 세미나

- 검증된 미국 S&P 500 하이브리드 WFA 결과
- 전체 결과와 2008년 등 대표 하락 episode
- “일반 국면에는 지수, 구조적 하락 국면에는 상대가격 또는 현금”이라는 메시지
- 한국 적용 구조는 개념도로 설명
- 미국 결과를 한국 실적으로 표현하지 않음

### 유료 강의

- 한국 데이터와 단순한 공통 백테스트 틀
- 네 알고리즘의 이론·실습
- WFA와 과최적화
- 가상 매매 장부와 알림
- 마지막 KIS 연동

## 15. 공개 표현 원칙

- “검증 완료 결과 재생”과 “실제 계산”을 구분합니다.
- 모의 체결은 `Paper Trading`으로 표시합니다.
- 과거 수익은 미래 수익을 보장하지 않는다고 명시합니다.
- 공매도·대주 재고·거래 API 제약을 숨기지 않습니다.
- 수익률만 강조하지 않고 MDD·비용·실패 구간을 함께 보여줍니다.

## 16. 결정 상태

### 확정

- 초보자에게 Git 용어를 노출하지 않음
- 첫 WFA 데모는 미국 S&P 500 기존 구현
- 한국 실습은 KOSPI 200 지수-현금 전략 포함
- 일봉 기준, 필요 시 1시간봉·5~15분봉
- 로컬 가상 매매 장부로 API 없는 실습 제공
- 실제 운영 기본값은 신호 알림과 사용자 직접 주문

- AI 직접 주문 금지

### 실험 필요

### 후속
