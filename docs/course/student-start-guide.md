# AI 트레이딩 강의 데모 시작 안내

이 폴더는 Git 프로젝트가 아니라 실행 가능한 완성 폴더입니다. 소스 관리 명령을 사용할 필요가 없습니다.

## 화면 열기

### Windows

1. ZIP 압축을 풉니다.
2. 폴더를 Cursor로 엽니다.
3. `start_windows.bat`를 더블클릭합니다.
4. 브라우저가 열리면 `검증 결과 재생`을 선택합니다.

처음 실행할 때 Python 환경과 필요한 패키지를 설치하므로 시간이 걸릴 수 있습니다.
`py` 명령을 찾을 수 없다는 메시지가 나오면 Cursor 채팅에
“이 폴더를 실행할 수 있도록 Python 3.12를 설치하고 다시 실행해 주세요”라고 요청합니다.

### macOS·Linux

터미널에서 다음을 실행합니다.

```bash
bash start_mac_linux.sh
```

## 첫 목표 문장

Cursor 채팅에 다음 문장을 붙여 넣습니다.

> 이 완성 폴더의 AI 트레이딩 강의 데모를 실행해 주세요. 브라우저에 ‘검증 완료 결과 재생’이라는 설명과 누적 자산 곡선, Drawdown, 붉은 하락 국면이 보여야 합니다. 실제 거래 API나 실제 주문은 사용하지 마세요.

## 사람이 확인할 체크리스트

- 화면에 `검증 완료 결과 재생`이라고 표시되어 있나요?
- 전체 WFA를 몇 초 만에 새로 계산했다고 표현하지 않나요?
- 누적 수익률과 MDD가 함께 보이나요?
- 붉은 하락 국면과 지수·하이브리드 곡선이 구분되나요?
- 손실 구간에서 원인을 단정하지 않고 관찰과 가능한 원인을 구분하나요?
- 다음 행동이 `유지`, `허용 파라미터 변경 후 재검증`, `중단`으로 제한되나요?
- 주문 화면에 `PAPER TRADING`과 `실제 주문 없음`이 표시되나요?

원하는 결과가 없다면 보이지 않는 항목 하나만 구체적으로 후속 프롬프트로 요청합니다.

## 두 실행 모드의 차이

- 검증 결과 재생: 강사가 장시간 실행해 저장한 결과를 인터넷 없이 재생합니다.
- 빠른 실제 계산: 소수 종목과 짧은 기간으로 실제 계산하며 인터넷이 필요합니다. 정식 결과와 숫자가 다를 수 있습니다.

## 한국형 연구실

- KOSPI 200 지수: 시장 위험을 판단하는 온도계
- KODEX 200 수정주가: 실제 수익을 계산하는 투자 상품
- 현금: 위험 신호 때 손실을 줄이기 위한 포지션

신호 당일 종가로 판단하고 다음 거래일부터 적용합니다.

## 가상 매매 장부

`실행` 버튼은 증권사에 주문하지 않습니다. 예상 가격, 수수료, 슬리피지, 가상 현금과 가상 포지션만 로컬 파일에 기록합니다.

실제 계좌 주문은 이 데모의 범위가 아닙니다.
