# 상세페이지 강사 이미지 체크리스트

코드·그래프 제작과 별도로 원본 사진 3~4장을 준비합니다.

## 권장 구도

1. 정면 상반신 — 밝고 신뢰감 있는 기본 프로필
2. 노트북 작업 — Cursor 또는 차트 화면을 보는 자연스러운 장면
3. 설명 장면 — 화면이나 보드를 가리키는 강의용 구도
4. 여유 컷 — 썸네일 문구를 넣을 수 있도록 한쪽에 빈 공간이 있는 가로 구도

## 파일

- 원본 JPG 또는 PNG
- 사진당 가로 2,000px 이상 권장
- 필터·배경 제거 전 원본도 함께 보관
- 파일명: `instructor_01_profile`, `instructor_02_working` 형식
- 얼굴과 손이 잘리지 않은 여유 있는 크롭

## 촬영 시 확인

- 작은 썸네일에서도 얼굴과 표정이 보이는가
- 모니터에 개인정보·API 키·계좌번호가 보이지 않는가
- 실제 거래 수익을 보장하는 문구가 화면에 없는가
- 정장 한 종류보다 강의 분위기에 맞는 자연스러운 복장 변화를 포함하는가
