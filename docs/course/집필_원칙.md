## 1. 정의 없이 쓰지 않는다

수강생이 모를 수 있는 말은 **첫 등장 자리에서 한 줄로** 풀어씁니다. 뒤에 설명하거나 별도 용어집으로 미루지 않습니다.

| | |
|---|---|
| ❌ | "라이브러리 관리를 대신해 주는 도구입니다" — `라이브러리`가 뭔지 안 나옴 |
| ✅ | "**라이브러리**: 남이 미리 만들어 둔 **기능 묶음**. 직접 안 만들고 가져다 씁니다" |

**같은 것을 두 이름으로 부르지 않습니다.** `라이브러리` / `패키지` 처럼 섞어 쓰면 초보자는 다른 것으로 읽습니다. 하나를 골라 끝까지 씁니다.

용어가 서너 개 이상 몰리면 클립 첫머리에 작은 표로 묶고, **"지금 외우실 필요 없습니다. 나올 때마다 다시 설명합니다"** 를 덧붙입니다.

## 2. 프롬프트에 정답을 심지 않는다 ★

**이 원칙이 가장 중요합니다.**

프롬프트는 **모르는 것을 AI가 대신하게 만드는 도구**입니다. 목표와 판단 기준을 주는 것이지, 내가 이미 아는 답을 받아쓰게 하는 게 아닙니다.

강사가 아는 정답을 프롬프트에 넣으면 그 순간은 성공하지만, **수강생은 아무것도 배우지 못합니다.** 다음에 다른 함정을 만나면 미리 써둔 줄이 없으니까요.

**Clip 02 실제 사례**

```prompt
❌ Windows라면, 경로에 WindowsApps가 들어간 python은 진짜 Python이 아니라
   Microsoft Store 안내용 껍데기야. 그건 '없음'으로 처리해줘.
```
→ 강사가 아는 정답. Windows에만 해당하고, 다른 함정에는 못 씁니다.

```prompt
✅ "설치돼 있다고 표시되는 것"이 아니라 "실제로 실행되는지"가 기준이야.
```
→ **판단 기준**. 어떤 함정이든 걸러냅니다. 그리고 수강생이 다음 프로젝트에서도 씁니다.

**강사의 경험은 프롬프트가 아니라 해설에 씁니다.** "제가 여기서 10분을 날렸습니다"는 좋은 이야기지만, 그건 **왜 저 기준이 필요한지 설명하는 자리**에 있어야 합니다.

`[하지 말 것]` 칸도 같습니다. 특정 파일 이름을 나열하는 대신 **"요청한 것 외에는 만들지 마"** 처럼 규칙으로 씁니다.

## 3. 정당화는 결정 직전에 둔다

"왜 이걸 쓰는가"는 **그 결정을 내리기 바로 전**에 있을 때 읽힙니다. 앞에 몰아두면 아직 생기지 않은 질문에 답하는 꼴이라 그냥 넘어갑니다.

| 내용 | ❌ 있던 자리 | ✅ 옮긴 자리 |
|---|---|---|
| 왜 앱이 아니라 확장인가 | 이론 핵심 | `Install` 누르기 직전 |
| 왜 파이썬이 필요한가 | (없었음) | 진단 프롬프트 직전 |
| `.venv`가 무엇인가 | (프롬프트 안에 단어만) | 폴더가 실제로 생긴 뒤 |

## 4. 검색으로 풀리는 것은 뺀다

"혹시 이런 경우엔?"을 다 담으면 **정작 90%의 흐름이 끊깁니다.**

판단 기준은 하나입니다 — **검색으로 풀리면 빼고, 검색으로 안 나오면서 막히면 치명적인 것만 남깁니다.**

Clip 02에서 이 기준으로 약 80줄을 덜어냈습니다.

| 뺀 것 | 이유 |
|---|---|
| Cursor 화면 전환 안내 | 소수만 해당, 검색으로 해결 |
| VS Code 설치 상세 (41줄) | 대다수가 이미 앎 |
| `Auto` 없을 때 원인 진단 3단계 | 검색으로 해결 |
| 첫 설치자에게 해당 없는 설정 확인 | 논리적으로 발생 불가 |

대신 **검색으로 안 나오는 대안 한 문장**은 남겼습니다. `Auto`가 없는 수강생이 승인 지옥을 겪다가 "이 강의가 잘못됐구나" 하는 게 첫날 최대 이탈 요인이기 때문입니다.

## 5. "지금 몰라도 된다"고 말해준다

초보자의 이탈은 *"모르는 게 나왔다"* 가 아니라 **"이걸 알아야 하는 건지 아닌지 모르겠다"** 에서 생깁니다.

당장 이해할 필요 없는 것이 나오면 **명시적으로 그렇게 적습니다.**

> 지금 외우실 필요 없습니다. 하시면서 자연스럽게 익으실 거예요.

## 6. 임의의 선택에는 "왜" 한 줄을 붙인다

종목·기간·개수처럼 강사가 고른 값에는 이유를 답니다. 그래야 **강의를 안 들은 사람도 논리를 따라오고**, 나중에 직접 바꿔 씁니다.

| 선택 | 붙인 이유 |
|---|---|
| 삼성전자 | 포털에서 **1초 만에 대조 가능**한 종목이라서 |
| 5거래일 | 한눈에 들어오면서 눈으로 대조하기 충분한 최소량 |
| 라이브러리 3개 | 가져오기 + 다루기 + 그리기. **딱 최소** |

## 8. 번호는 대단원마다 1부터

**목차만 봤을 때 번호 기준이 한눈에 보여야 합니다.**

규칙은 하나입니다 — **각 대단원(`##`)은 자기 하위 항목(`###`)에 1부터 번호를 매긴다.**

```
이론 핵심
   1. 왜 AI 코딩인가?
   2. 비용은 얼마나 드나
   3. 오늘의 진행 흐름

실습 — 실습 01
   Step 1. 확장 설치와 자율권 모드 설정
   Step 2. 작업 폴더 생성 및 열기
   ...

자주 발생하는 문제 및 트러블슈팅
   1. 진단 결과 "Python 없음"이라고 나올 때
   2. 원인 모를 에러로 멈출 때
   ...
```

- **실습 구간만 `Step`이라는 이름을 함께 씁니다.** 순서대로 따라 해야 하는 구간이라는 신호이고, 대본과 영상에서 "Step 4로 가겠습니다"라고 부르기 위해서입니다
- **0번을 만들지 않습니다.** `Step 0` 같은 건 쓰지 않습니다
- **번호 없는 짧은 안내는 제목으로 만들지 않습니다** — 목차에 번호 없는 항목이 하나 끼면 그 자리에서 기준이 무너져 보입니다. 본문 굵은 글씨로 씁니다

## 9. 검증은 선언이 아니라 실제로 한다

이 강의를 관통하는 주제입니다. 자료 곳곳에서 같은 모양으로 반복되어야 합니다.

| Step | "선언" | "실제" |
|---|---|---|
| 진단 | "파이썬이 있다" | **실제로 실행되는가** |
| 대조 | AI의 "완료했습니다" | **포털 시세와 숫자가 맞는가** |
| diff | AI가 쓴 코드 | **승인 전에 내 눈으로 본다** |

새 클립을 쓸 때도 **"여기서 수강생이 무엇을 자기 눈으로 확인하는가"** 를 항상 하나 넣습니다.

## 10. 실습 프롬프트는 네 칸 골격 그대로 쓴다

Clip 03에서 가르친 골격을 **모든 실습 프롬프트가 같은 머리말로** 따릅니다. 수강생은 이 네 줄을 보고 "아, 그 네 칸"이라고 알아봐야 합니다.

| 상황 | 머리말 순서 |
|---|---|
| 새로 만들 때 | `[맥락]` → `[만들 것]` → `[하지 말 것]` → `[확인]` |
| 이미 있는 파일을 고칠 때 | `[맥락]` → `[수정할 것]` → `[하지 말 것]` → `[확인]` |

**실제로 어긋났던 사례 (2026-09 전수 점검)**

| | |
|---|---|
| ❌ | Part 3~5 전체(27개)가 `...하고 싶어. (Context)` / `...실행해줘: (Deliverable)` / `...알려줘. (Verification)` 처럼 문장 끝 영문 괄호로 바뀌어 있었고, `[하지 말 것]` 칸이 통째로 빠진 클립이 17개 |
| ✅ | 네 칸 머리말로 복원. `[하지 말 것]`은 그 클립의 실제 위험(익일 시가 체결, 모의투자 서버 한정, 검증 실패 시 주문 금지)으로 채움 |

`[하지 말 것]`을 빈 칸으로 두거나 "화면 멈추는 창 띄우지 마" 한 줄만 넣지 않습니다. 원칙 2대로 **그 클립에서 AI가 저지를 법한 우회를 규칙으로** 씁니다.

**의도적으로 골격을 안 쓰는 프롬프트**(Clip 03 이전의 짧은 진단 요청, 캡슐화 모양만 보여주는 조각)는 ```` ```prompt ```` 펜스 위에 주석을 달아 검사에서 뺍니다. 목록 항목 안에 넣으면 목록이 끊어지니 목록 위에 빈 줄로 감싸 둡니다.

```markdown
<!-- prompt-check: skip — 4칸 골격(클립 03)을 배우기 전의 짧은 진단 요청 -->
```

## 11. 고친 뒤에는 검사기를 돌린다

강의를 매일 찍지 않으면 형식은 조용히 어긋납니다. 눈으로 43개를 다시 읽는 대신 **커밋 전에 한 번** 돌립니다.

```bash
.venv/bin/python runners/check_lecture_consistency.py
```

| 검사 | 잡는 것 |
|---|---|
| P1 4칸 골격 | 프롬프트에 네 머리말이 다 있는가 |
| P2 구형 표기 | `(Context)` 같은 영문 괄호 표기가 남았는가 |
| C1 차트 형식 | Plotly를 배운 Clip 09 이후 프롬프트가 `.png`를 요구하는가 |
| H1 HTML 재빌드 | `.md`를 고치고 `.html` 빌드를 빠뜨렸는가 |
| S1 대본↔교재 | 대본이 말하는 차트 파일 이름이 교재에 없는가 |
| F1 종목 유니버스 | Part 3~5에 백테스트한 적 없는 종목코드가 들어왔는가 |
| F2 고정 위험값 | 2층 하드 가드레일(-0.03 / -0.02)이 다른 값으로 적혔는가 |
| F3 금지 표현 | 폐기된 수치·용어가 남아 있는가 |
| N1 실습 번호 | 본문 `실습 NN`과 `curriculum.json`이 어긋나거나 번호가 끊겼는가 |

FAIL이 하나라도 있으면 종료 코드 1입니다. 새 검사가 필요해지면 이 스크립트에 한 함수를 더합니다.

## 12. 앞 클립에서 정한 것은 뒤 클립에서 바꾸지 않는다 ★

원칙 2와 함께 **가장 자주, 가장 조용히 깨지는 원칙**입니다. 매일 촬영하지 않으면 몇 주 전에 정한 값을 잊고, 뒤 클립에서 아무렇지 않게 다른 값을 씁니다. 수강생에게는 "앞에서 A라고 했는데 뒤에서 B라고 하는" 자료가 됩니다.

**2026-09 전수 점검에서 실제로 나온 것**

| 앞에서 (Clip 01~15, 촬영 완료) | 뒤에서 | 처리 |
|---|---|---|
| Clip 11: 변동성 돌파를 **1배수 KODEX 200**으로 검증, "레버리지 섞지 마" | Clip 16부터 아무 설명 없이 **KODEX 레버리지** | 자산 교체는 유지하되 Clip 16에 **왜 바꾸는지** 문단 추가 |
| Clip 15: 페어 스위칭 **10.7년간 46회** | Clip 23 표: "페어 **연 25회**" | 실측값으로 표 재작성, 지어낸 CAGR 삭제 |
| Clip 07: 낙폭을 **MDD(최대 낙폭)**로 정의 | Clip 21·30: "드로다운" | 용어 통일 |

**규칙**

1. **뒤 클립에서 값을 바꿔야 한다면, 바꾸지 말라는 뜻이 아니라 "왜 바꾸는지 그 자리에 쓰라"는 뜻입니다.** 위 VBO 사례처럼 한 문단이면 충분합니다. 설명 없는 교체만 금지합니다.
2. **숫자를 기억으로 쓰지 않습니다.** 성과·거래 횟수·기간은 반드시 실제 실행 결과에서 가져옵니다. 표를 채우려고 그럴듯한 값을 적는 순간, 수강생이 같은 프롬프트를 돌려 다른 숫자를 보게 됩니다.
3. **고정값은 검사기에 등록합니다.** 종목 유니버스, 2층 하드 가드레일(-3% / -2%), 폐기된 표현은 `runners/check_lecture_consistency.py`의 `STRATEGY_UNIVERSE` / `FIXED_RISK_VALUES` / `BANNED_PHRASES`에 있습니다. 새 사실이 확정되면 여기에 한 줄 추가하세요. 그래야 다음에 또 어긋날 때 사람이 아니라 스크립트가 잡습니다.
4. **한 개념에 값이 둘이면 층을 나눠 적습니다.** 전략 손절(-10%, 월 단위, 조정 가능)과 장중 하드 손절(-3%, 실시간, 고정)처럼요. 둘 다 "손절"이라 섞이기 쉬우므로 Clip 24 기준표처럼 **1층/2층 표를 나눠** 둡니다.

5. **교재에는 실습 결과 숫자를 적지 않습니다.** 우리 프롬프트를 돌리면 나오는 수익률·MDD·샤프·손실 구간 날짜는 강의 화면에서 보여 주고, 교재에는 "무엇을 비교해 읽을지"만 씁니다. 숫자를 박아 두면 데이터 종료일이나 구현이 조금만 달라도 수강생 결과와 어긋나고, 앞뒤 클립의 숫자끼리도 어긋납니다. 강사가 확인용으로 쓰는 참고값은 **강사 대본의 '촬영 참고값'**에만 두고, 재현 스크립트(예: `risk_overlay_backtest.py`)로 다시 뽑습니다. 기간·비용·규칙 값처럼 **실습 조건**은 숫자로 적습니다.
6. **촬영분도 필요하면 고칩니다.** 교재 상단 안내대로 교재가 기준입니다. 영상 화면과 달라진 곳에는 본문에 ⚠️ **정정** 표시를 남깁니다.

**확인만 하고 건드리지 않은 것 (촬영 완료 예외 목록)**

- **Clip 01의 0.1초 상시 감시 표현**: Tier 2 상시 감시 주기로 "0.1초"를 선언했으나, 증권사 API 한도상 시세 폴링은 1초이고 판정→발주 반응이 0.1초입니다. Part 4(클립 28·32·35)에서 이 내용을 상세히 연결 설명하고 Clip 01 원문은 그대로 유지합니다.
