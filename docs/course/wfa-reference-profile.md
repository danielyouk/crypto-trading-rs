# 미국 WFA 강의 기준 설정

기준 ID: `us-sp500-course-v2`

이 설정은 `stock-trading-eda-scheduled_eng.ipynb`의 cell 72와 74에서 약 2시간 50분 걸렸던 계산 경로를 고정한 것입니다. 이중 복귀 경로(+20% 반등 / 100일 MA 기울기 fallback), 다음 거래일 체결, 진입 퍼널 진단을 적용한 공식 runner의 최신 실행 시간은 약 53분 18초입니다. 코드의 일반 기본값이나 이전 `runners/run_wfa.py` 실험값을 강의 수치와 섞지 않습니다.

## 데이터

- 유니버스: 실행 시점의 S&P 500 구성 종목
- 종목 가격: Yahoo Finance `Adj Close`
- 벤치마크: SPY `Adj Close`
- 시작일: 1990-01-01
- 고정 종료일: 2026-06-18 미포함
- 초기 자본: 10,000 USD
- 생존편향: 현재 구성 종목을 과거로 적용하는 한계를 면책 문구에 표시

## WFA

- 학습 window: 최근 36개월 rolling
- 검증 구간: 180거래일
- 리밸런싱: 월초
- returns correlation: 0.40 이상 0.85 이하
- 공적분 유의수준: 0.05
- 종목별 학습 구간 overlap: 90% 이상
- 이동 window 후보: 10~30거래일, 간격 2일
- 진입 z-score 후보: 1.5~3.0, 간격 0.1
- watchlist: 20개
- 최대 동시 포지션: 7개
- 하루 신규 진입: 최대 2개
- 레버리지: 3배
- stop-loss: 슬롯 자본의 5%
- 포트폴리오 circuit breaker: 12%
- 최소 보유: 3거래일
- 수수료: leg당 0.5 bps
- 슬리피지: leg당 0.5 bps
- 실행 시점: 종가 신호는 다음 거래일 종가에 체결

## 시장 국면 전환

- 페어 진입: S&P 500 고점 대비 -10% 이하이면서 100일 이동평균 기울기가 음수
- 기울기 확인: 최근 15일 평균
- 최소 페어 국면(느린 복귀 경로): 60거래일
- 지수 복귀 (이중 경로, 먼저 충족되는 쪽):
  - 빠른 경로: 하락 에피소드 저점 대비 +20% 반등 (교과서 ±20% 정의)
  - 느린 fallback: 100일 이동평균의 20일 기울기가 최근 15일 평균으로 양수
- 재진입 쿨다운: 40거래일
- baseline carry: 페어 0 bps, 지수 환헤지 0 bps
- 미반영 비용: 공매도 대차·마진·환헤지 carry와 지수↔페어 전환 비용
- 진단: 전 기간 페어 경로에는 연도별 진입 퍼널(`pairs_entry_diagnostics`)을 기록

따라서 “비용 반영 결과”는 위 수수료와 슬리피지만 뜻합니다. carry와 국면 전환 비용까지 포함한 완전 비용 모델로 표현하지 않습니다.

## 이전 runner와의 차이

이전 runner는 노트북과 달리 -15% 진입, 공적분 0.10, overlap 80%, z-score 1.0~2.5, watchlist 200, 최대 슬롯 10, stop-loss 8% 등을 사용했습니다. 이 값들은 별도 실험 설정이며 강의 기준에서 제외했습니다.

## 결과 객체의 용도

- `hybrid_result`: 전체 지수·페어 전환 전략의 equity, MDD, regime
- `hybrid_result.pairs_result`: 전 기간 페어만 운용한 저활동 진단 비교군의 거래와 리밸런싱. 공통 표시 시작일에는 다른 곡선과 같은 초기 금액으로 정규화합니다.
- `hybrid_result.episode_results`: 실제 하락 국면마다 실행된 페어 WFA 결과

노트북의 `wfa_result` 분석 셀은 위 세 목적을 나누어 사용해야 합니다. `wfa_result = hybrid_result`로 치환하지 않습니다.
