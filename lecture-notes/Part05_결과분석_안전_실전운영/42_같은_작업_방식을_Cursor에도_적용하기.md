# 같은 작업 방식을 Cursor에도 적용하기

## 이번 클립에서 만들 것

지금까지 만든 시스템을 **다른 AI 도구(Cursor)로 그대로 이어서** 고쳐 봅니다. 그러려면 먼저 반년 뒤의 나와 다른 도구가 읽을 **인수인계 문서**가 있어야 합니다. 이 문서를 만들고, Cursor로 같은 작업 폴더를 열어 작은 수정 하나를 시켜 봅니다.

> 💡 운용에는 AI가 필요 없습니다. 프로그램과 파일만 있으면 매일 돌아갑니다. AI는 **만들거나 고칠 때만** 쓰고, 그때 쓰는 도구는 무엇이든 됩니다.

- Cursor로 같은 폴더를 열어 이어서 작업하기

## 이론 핵심

### 1. 도구가 바뀌어도 되는 이유

이 시스템은 파이썬 파일 몇 개와 JSON 파일로 되어 있습니다. 어느 AI 도구로 만들었는지는 파일에 남지 않습니다. 그래서 Claude Code를 쓸 수 없게 되거나 다른 도구가 더 좋아져도, 같은 폴더를 다른 도구로 열어 **같은 네 칸 프롬프트**([맥락]·[만들 것]·[하지 말 것]·[확인])로 요청하면 됩니다.

도구보다 중요한 것은 **설명서**입니다. 반년 뒤의 나도, 새 도구도 이 폴더에 무엇이 있고 무엇을 건드리면 안 되는지 모릅니다. 그래서 인수인계 문서를 하나 두고, 어떤 도구를 쓰든 "먼저 이 문서를 읽어"로 시작합니다.

---

### 2. Cursor로 같은 폴더 열기

**Cursor**는 AI 기능이 들어간 코드 편집기입니다. 새 폴더를 만들지 않고 **지금 쓰던 작업 폴더를 그대로** 엽니다. `.env`, 프로그램, 가상환경(`.venv`)이 모두 그 안에 있기 때문입니다.

1. [cursor.com](https://cursor.com)에서 Cursor를 설치하고 실행합니다.
2. **File → Open Folder**로 작업 폴더를 엽니다. 처음 열면 "이 폴더를 신뢰하느냐"고 묻는데, 내 폴더이니 신뢰를 선택합니다.
3. 오른쪽 AI 대화창을 엽니다(단축키 `Ctrl+L`, Mac은 `Cmd+L`). 대화창 아래에서 **Agent** 모드를 고르면 파일을 고치고 명령도 실행할 수 있습니다.
4. 명령을 실행하기 전에 허락을 물으면 내용을 보고 허락합니다. 프로그램은 작업 폴더의 `.venv` 파이썬으로 실행해야 합니다.

Claude Code와 다른 점은 화면뿐입니다. 요청하는 방식은 같습니다.

## 실습 — 실습 30: 인수인계 문서를 만들고 Cursor에서 이어서 작업하기

### 먼저: 인수인계 문서 만들기 (Claude Code)

Claude Code 대화창에 아래 프롬프트를 입력하세요.

> 📁 **공유 파일**: 이 프롬프트는 작업 폴더의 파일들을 읽기만 하고, `docs/handover.md`를 만듭니다.

```prompt
[맥락] 이 작업 폴더의 트레이딩 시스템을 반년 뒤의 나, 다른 사람, 다른 AI 도구가 이어받을 수 있게 인수인계 문서를 만들고 싶어. 운용에는 AI가 필요 없고 프로그램만 실행하면 되지만, 고칠 때는 어떤 AI 도구를 써도 되게 하려는 거야.

[만들 것] 'docs/handover.md'를 작성해줘. 작업 폴더의 파일을 실제로 읽고 적어:
1. 프로그램 파일마다 무엇을 하는지 한 줄씩. 이름 순이 아니라 하루 흐름 순으로.
2. 매일 무엇을 언제 실행하는지, 사람이 하는 일은 무엇인지.
3. 프로그램끼리 주고받는 파일(신호, 주문 목록, 기록)의 이름과 역할.
4. 새 컴퓨터에서 처음 설치할 때 필요한 것(파이썬, 라이브러리, .env의 항목 이름).
5. 어떤 AI 도구에 일을 시킬 때 지킬 규칙: 네 칸(맥락/만들 것/하지 말 것/확인)으로 요청하기, 주문을 보내는 프로그램은 함부로 실행하지 않기, .env 값은 보여 주지 않기.

[하지 말 것]
- 파일을 읽지 않고 기억으로 쓰지 마. 실제 폴더에 있는 것만 적어.
- .env의 값을 문서에 적지 마. 항목 이름만 적어.
- 프로그램을 고치거나 실행하지 마.

[확인] 문서를 보여줘. 프로그램 파일 가운데 빠진 것이 있으면 알려줘.
```

### 이어서: Cursor에서 작은 수정 하나 (Cursor)

Cursor로 같은 작업 폴더를 열고, AI 대화창(Agent 모드)에 아래 프롬프트를 입력하세요. Claude Code에서 쓰던 네 칸 그대로입니다.

```prompt
[맥락] 이 폴더는 docs/handover.md에 설명된 트레이딩 시스템이야. 먼저 그 문서를 읽어. 작은 수정 하나를 해 보려고 해.

[만들 것]
1. daily_journal.py가 만드는 일지 맨 아래에 "이 일지는 (프로그램 이름)이 (만든 시각)에 만들었습니다" 한 줄을 적게 고쳐줘.
2. 작업 폴더의 .venv 파이썬으로 daily_journal.py를 실행해, 오늘 일지 맨 아래에 그 줄이 들어갔는지 보여줘.

[하지 말 것]
- 주문을 보내는 프로그램(execute_orders.py, risk_guard.py)은 실행하지 마.
- 이 수정 말고 다른 파일은 고치지 마. .env는 열지도 마.

[확인] 바뀐 부분과, 새로 만든 일지의 마지막 줄을 보여줘.
```

같은 프롬프트를 Codex 같은 다른 도구에 넣어도 똑같이 통합니다.
