# 분석 결과를 전략 개선과 재검증으로 연결하기

## 이번 클립에서 만들 것

이 클립이 끝나면, 여러분은 일일 손실에 과민반응하여 코드를 망가뜨리는 초보자의 치명적 실수를 방지하고, 최소 2주~1개월의 누적 데이터를 바탕으로 **'가설 수립 ➔ 파라미터/필터 조정 ➔ 워크포워드(WFA) 재검증 ➔ 주간 정책 반영'**으로 이어지는 프로 퀀트의 안전한 **'전략 개선 루프(Strategy Iteration Loop)'**를 마스터하게 됩니다.

> 💡 **퀀트의 제1 계명**: 하루 이틀 손실이 났다고 전략을 수정하지 마세요. 그것은 전략의 결함이 아니라 금융시장의 자연스러운 분산(Variance)입니다. 전략 수정은 반드시 **통계적 유의성(최소 30회 이상의 거래 표본)**이 확보되었을 때만 신중하게 단행해야 합니다.

- **과민 반응의 덫 (Knee-jerk Reaction)**: 일일 손실 후 파라미터를 바꾸는 행위가 과최적화로 이어지는 이유
- 전략 개선의 3단계 안전 필터: 통계 표본 검증 ➔ 가설의 보편성 검토 ➔ Out-of-Sample WFA 재검증
- 개선된 룰셋을 안전하게 배포하는 **주간 정책(`weekly_policy.json`) 버전 관리(`v1.1`, `v1.2`)**
- **실습 25**: 누적 매매 일지를 바탕으로 한 전략 개선안 수립 및 WFA 재검증 시뮬레이션

## 이론 핵심

### 1. 전략 개선의 올바른 의사결정 트리

```text
[손실 발생] 
   └── 최근 30회 거래의 누적 승률과 손익비가 백테스트 기대치 범위 내인가?
       ├── YES (통계적 정상 범위) ──> 전략 수정 금지! 기존 정책 유지
       └── NO  (구조적 이상 발생) ──> [3단계 안전 개선 절차 착수]
                                        ① AI 손실 진단서 작성
                                        ② 보편적 필터(ATR, 버퍼) 가설 수립
                                        ③ 최근 3개년 WFA 재검증 (WFE >= 60% 필수)
                                        ④ 통과 시 주간 정책 버전 업그레이드
```

---

### 2. 주간 정책 버전 관리 (`weekly_policy.json`)

전략을 수정할 때는 기존 코드를 덮어쓰지 않고, 명확한 변경 사유(Changelog)를 기록하며 버전을 올립니다.

```json
{
  "policy_version": "1.1",
  "changelog": "변동성 돌파 전략에 ATR(14) 변동성 필터 추가 (WFA 재검증 WFE 68% 통과)",
  "effective_period": { "start_date": "2026-09-01", "end_date": "2026-09-05" },
  "strategy_weights": { ... }
}
```

## 실습 — 실습 25: 전략 개선 가설 수립 및 WFA 재검증

Claude Code 대화창에 아래 프롬프트를 입력하세요.

```prompt
누적 매매 결과를 바탕으로 전략 개선 가설을 수립하고 WFA 재검증을 수행해줘. (Context)

다음 요구사항에 맞춰 분석과 검증을 진행해줘: (Deliverable)
1. 최근 1개월간 발생한 횡보장 손실을 방어하기 위해 '변동성 돌파 전략에 ATR 필터 결합' 가설을 수립해줘.
2. 기존 전략 vs 개선 가설 전략의 최근 3개년 WFA(워크포워드) 성과를 대조 검증해줘.
3. WFE 효율성 지표와 MDD 개선폭을 산출하고, 실전 정책 반영 적격 여부를 판정해줘.
4. 검증을 통과했다면 업그레이드된 'weekly_policy_v1.1.json' 파일을 생성해줘.

실행 완료 후 화면에 재검증 비교 성과표를 출력하고 정책 파일 생성 경로를 알려줘. (Verification)
```

### 내 눈으로 확인할 체크리스트

- [ ] WFA 재검증을 통해 새로운 필터가 미래 구간에서도 유효함을 수학적으로 확인했다.
- [ ] 버전과 변경 사유가 명확히 기록된 `weekly_policy_v1.1.json`이 생성되었다.
