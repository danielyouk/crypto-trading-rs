# AI 사용 비용을 관리하며 시스템을 효율적으로 운영하기

## 이번 클립에서 만들 것

이 클립이 끝나면, 여러분은 Claude Code 같은 AI 도구를 매일 트레이딩 시스템 분석에 활용하면서도, **매번 똑같이 보내는 앞부분은 할인받고(프롬프트 캐싱), AI가 한 번에 읽는 양은 줄이는(컨텍스트 압축)** 방법으로 **월 AI 사용 비용을 커피 한두 잔 가격(월 5,000원~10,000원 미만)**으로 통제하는 운영 노하우를 터득하게 됩니다.

이 클립에는 AI 요금과 관련된 말(토큰, 캐싱, 컨텍스트)이 한꺼번에 나옵니다. 처음 나오는 자리에서 한 줄씩 풀어 쓰니 외우실 필요는 없습니다.

| 용어 | 뜻 |
|---|---|
| LLM | 글을 읽고 쓰도록 학습된 대형 AI 모델. Claude가 그중 하나입니다 |
| 토큰 | AI가 글을 잘게 나눠 세는 단위. 요금이 이 개수로 매겨집니다 (증권사 API의 접근 토큰과는 다른 것) |
| 입력 토큰 / 출력 토큰 | 내가 AI에게 보내는 글의 토큰 / AI가 답으로 쓴 글의 토큰 |
| 컨텍스트 | AI가 이번 대화에서 한꺼번에 읽고 있는 대화·파일 전체 |
| 시스템 프롬프트 | 대화마다 맨 앞에 자동으로 붙는 고정 안내문(도구 사용법, 기본 규칙 등) |
| 프롬프트 캐싱 / 캐시 히트 토큰 | 매번 똑같이 보내는 앞부분을 AI 쪽에서 잠시 기억해 두는 것 / 그 기억을 다시 써서 싸게 처리된 토큰 |

> 💡 **비용 관리의 핵심**: AI에게 매번 전체 프로젝트 파일 50개를 처음부터 끝까지 다 읽게 만들면 토큰 낭비가 심해집니다. 필요한 데이터와 최근 요약본만 넘겨 AI가 읽는 양을 줄이는 **'컨텍스트 다이어트'**가 비용 절감의 열쇠입니다.

- AI 요금이 매겨지는 방식과 **프롬프트 캐싱** (매번 똑같이 보내는 앞부분은 최대 90% 할인)
- AI가 읽는 양을 줄이는 **세 가지 요령**
- 이 클립은 실습 없이 설명으로 지나갑니다. 다음 분석부터 요령 세 가지를 그대로 쓰면 됩니다.

### 1. 토큰 비용 체계와 프롬프트 캐싱의 마법

Claude 모델은 대화의 앞부분(시스템 프롬프트, 매번 함께 읽히는 기본 코드 설명 등)이 이전과 똑같으면 그 부분을 잠시 기억해 두었다가 다시 씁니다(**프롬프트 캐싱**). 기억에서 다시 읽은 몫(캐시 히트)은 비용이 1/10 수준으로 줄어듭니다.
