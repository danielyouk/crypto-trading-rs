# AI 사용 비용을 관리하며 시스템을 효율적으로 운영하기

## 이번 클립에서 만들 것

이 클립이 끝나면, 여러분은 Claude Code 같은 AI 도구를 매일 트레이딩 시스템 분석에 활용하면서도, **매번 똑같이 보내는 앞부분은 할인받고(프롬프트 캐싱), AI가 한 번에 읽는 양은 줄이고(컨텍스트 압축), 정액제와 쓴 만큼 내는 방식 중 내 사용량에 맞는 쪽을 고르는** 방법으로 **월 AI 사용 비용을 커피 한두 잔 가격(월 5,000원~10,000원 미만)**으로 통제하는 운영 노하우를 터득하게 됩니다.

이 클립에는 AI 요금과 관련된 말(토큰, 캐싱, 컨텍스트)이 한꺼번에 나옵니다. 처음 나오는 자리에서 한 줄씩 풀어 쓰니 외우실 필요는 없습니다.

| 용어 | 뜻 |
|---|---|
| LLM | 글을 읽고 쓰도록 학습된 대형 AI 모델. Claude가 그중 하나입니다 |
| 토큰 | AI가 글을 잘게 나눠 세는 단위. 요금이 이 개수로 매겨집니다 (증권사 API의 접근 토큰과는 다른 것) |
| 입력 토큰 / 출력 토큰 | 내가 AI에게 보내는 글의 토큰 / AI가 답으로 쓴 글의 토큰 |
| 컨텍스트 | AI가 이번 대화에서 한꺼번에 읽고 있는 대화·파일 전체 |
| 시스템 프롬프트 | 대화마다 맨 앞에 자동으로 붙는 고정 안내문(도구 사용법, 기본 규칙 등) |
| 프롬프트 캐싱 / 캐시 히트 토큰 | 매번 똑같이 보내는 앞부분을 AI 쪽에서 잠시 기억해 두는 것 / 그 기억을 다시 써서 싸게 처리된 토큰 |

> 💡 **비용 관리의 핵심**: AI에게 매번 전체 프로젝트 파일 50개를 처음부터 끝까지 다 읽게 만들면 토큰 낭비가 심해집니다. 필요한 데이터와 최근 요약본만 넘겨 AI가 읽는 양을 줄이는 **'컨텍스트 다이어트'**가 비용 절감의 열쇠입니다.

- AI 요금이 매겨지는 방식: 보내는 글(입력 토큰), 받는 글(출력 토큰), 기억해 둔 앞부분을 다시 쓴 몫(캐시 히트 토큰)
- 매번 똑같이 보내는 앞부분을 싸게 처리받는 **프롬프트 캐싱**의 원리 (그 부분 비용 최대 90% 할인)
- 장 마감 일지와 주간 분석 때 AI가 읽는 양을 줄이는 **'3가지 요령'**
- 쓴 만큼 내는 방식(API 종량제)과 월 구독 정액제(Claude Pro/Team) 중 어느 쪽이 싸지는지 가르는 사용량
- **실습 29**: "읽어" 대신 "분석해"로 맡기고, 대화창에 들어온 양을 원본과 비교

## 실습 — 실습 29: "읽어" 대신 "분석해"로 맡기기

Claude Code 대화창에 아래 프롬프트를 입력하세요.

> 📁 **공유 파일**: 이 프롬프트는 `orders_history.json`(주문과 체결 기록), 가장 최근 잔고 기록(`logs/holdings_날짜.json`), 가장 최근 신호 파일(`signals.json`)을 분석에 쓰고, `price_cache` 폴더는 크기만 잽니다. 새 파일은 만들지 않습니다.

```prompt
[맥락] AI 사용 요금(토큰: AI가 글을 잘게 나눠 세는 단위로, 요금이 이 개수로 매겨짐)을 줄이고 싶어. 데이터를 대화창에 통째로 읽히지 말고, 네가 데이터를 분석해서 결과만 가져오게 하고 싶어. 작업 폴더의 orders_history.json, 가장 최근 logs/holdings_날짜.json, signals.json, price_cache 폴더를 쓴다.

[만들 것]
1. 파일 내용을 대화창에 펼치지 말고 그 자리에서 파이썬으로 계산해서, 결과만 짧게 보여줘: 지금까지의 체결(종목, 수량, 예상 가격 대비 체결 가격 차이), 보유 종목별 평가손익, 신호 파일의 목표 수량과 지금 보유의 차이.
2. 끝나면 비교표를 보여줘: [원본 파일을 그대로 읽었다면 대화창에 들어왔을 글자 수 / 이번에 실제로 대화창에 들어온 결과의 글자 수], 각각의 어림 토큰 수와 예상 비용. 원본 쪽은 orders_history.json, 신호 파일, price_cache 폴더의 가격 파일 전체의 크기로 재고, 토큰을 어림한 방법도 적어.
3. 예상 비용은 쓴 만큼 내는 방식(API 종량제)의 입력 토큰 단가로 계산하고, 단가는 공식 요금표에서 확인해 모델 이름·출처와 함께 적어. 확인하지 못하면 비용 칸은 비워 둬.

[하지 말 것]
- 파일 내용을 통째로 출력하거나 읽지 마. 원본은 크기만 재.
- 분석용 파일이나 프로그램을 새로 만들지 마. 그 자리에서 계산만 해.
- 글자 수는 실제로 잰 값을 쓰고, 짐작한 숫자를 적지 마.

[확인] 분석 결과와 비교표를 보여줘.
```
