## 이론 핵심

### 1. 토큰 비용 체계와 프롬프트 캐싱의 마법

Anthropic Claude 모델(Sonnet 3.7 등)은 대화의 앞부분(시스템 프롬프트, 기본 코드 구조)이 동일할 경우 **프롬프트 캐싱(Prompt Caching)**을 적용하여 비용을 1/10 수준으로 깎아줍니다.

```text
[일반적인 매회 전체 호출]
• 매번 20,000 토큰 전송 ➔ 1회당 0.06달러 ➔ 매일 10회 호출 시 월 18달러 (약 25,000원)

[프롬프트 캐싱 & 컨텍스트 압축 적용]
• 캐시 히트(Cache Hit) 시 90% 할인 ➔ 1회당 0.006달러 ➔ 매일 10회 호출 시 월 1.8달러 (약 2,500원!)
```

## 실습 — 실습 29: 토큰 경량화 프롬프트 벤치마크

Claude Code 대화창에 아래 프롬프트를 입력하여 토큰 사용량을 절감하는 데이터 요약 전송 기법을 실습하세요.

```prompt
토큰 비용을 90% 절감하는 경량화된 일일 성과 분석 요청을 작성하고 실행해줘. (Context)

다음 작업을 수행해줘: (Deliverable)
1. 1년치 시계열 전체를 보내는 대신, 파이썬으로 오늘 계좌의 핵심 메트릭(일간 손익, 체결 3건, 현재 잔고)을 15줄 이내의 간결한 JSON 문자열로 요약 추출하는 헬퍼 함수 'summarize_daily_context()'를 작성해줘.
2. 이 요약 JSON만을 Claude Code에게 전달하여 일일 분석 코멘트를 생성하게 해줘.
3. 기존 전체 데이터 로드 방식 대비 절감된 토큰 수(입력 바이트 수)와 예상 절감 비용을 대화창에 비교 출력해줘.

실행 완료 후 화면에 토큰 절감 비교표를 보여줘. (Verification)
```
