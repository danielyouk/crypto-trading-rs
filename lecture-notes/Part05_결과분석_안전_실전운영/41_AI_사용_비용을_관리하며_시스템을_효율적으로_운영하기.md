이 클립에는 AI 요금과 관련된 말이 한꺼번에 나옵니다. 지금 외우실 필요 없습니다. 나올 때마다 다시 설명합니다.

| 용어 | 뜻 |
|---|---|
| LLM | 글을 읽고 쓰도록 학습된 대형 AI 모델. Claude가 그중 하나입니다 |
| 토큰 | AI가 글을 잘게 나눠 세는 단위. 요금이 이 개수로 매겨집니다 (증권사 API의 접근 토큰과는 다른 것) |
| 입력 토큰 / 출력 토큰 | 내가 AI에게 보내는 글의 토큰 / AI가 답으로 쓴 글의 토큰 |

> 💡 **비용 관리의 핵심**: AI에게 매번 전체 프로젝트 파일 50개를 처음부터 끝까지 다 읽게 만들면 토큰 낭비가 심해집니다. 필요한 데이터와 최근 요약본만 넘겨 AI가 읽는 양을 줄이는 **'컨텍스트 다이어트'**가 비용 절감의 열쇠입니다.

- AI 요금이 매겨지는 방식: 보내는 글(입력 토큰), 받는 글(출력 토큰), 기억해 둔 앞부분을 다시 쓴 몫(캐시 히트 토큰)
- 매번 똑같이 보내는 앞부분을 싸게 처리받는 **프롬프트 캐싱**의 원리 (그 부분 비용 최대 90% 할인)
- 장 마감 일지와 주간 분석 때 AI가 읽는 양을 줄이는 **'3가지 요령'**
- 쓴 만큼 내는 방식(API 종량제)과 월 구독 정액제(Claude Pro/Team) 중 어느 쪽이 싸지는지 가르는 사용량

## 이론 핵심

### 1. 토큰 비용 체계와 프롬프트 캐싱의 마법

Claude 모델은 대화의 앞부분(시스템 프롬프트, 매번 함께 읽히는 기본 코드 설명 등)이 이전과 똑같으면 그 부분을 잠시 기억해 두었다가 다시 씁니다(**프롬프트 캐싱**). 기억에서 다시 읽은 몫(캐시 히트)은 비용이 1/10 수준으로 줄어듭니다.

```text
[일반적인 매회 전체 호출]
• 매번 20,000 토큰 전송 ➔ 1회당 0.06달러 ➔ 매일 10회 호출 시 월 18달러 (약 25,000원)

[프롬프트 캐싱 & 컨텍스트 압축 적용]
• 캐시 히트 시 90% 할인 ➔ 1회당 0.006달러 ➔ 매일 10회 호출 시 월 1.8달러 (약 2,500원!)
```

## 실습 — 실습 29: 토큰 경량화 프롬프트 벤치마크

Claude Code 대화창에 아래 프롬프트를 입력하여 토큰 사용량을 절감하는 데이터 요약 전송 기법을 실습하세요.

```prompt
[맥락] AI에게 보내는 글을 줄여서, AI 사용 요금(토큰: AI가 글을 잘게 나눠 세는 단위로, 요금이 이 개수로 매겨짐)을 90% 줄이는 가벼운 일일 성과 분석 요청을 작성하고 실행하고 싶어.

[만들 것] 다음 작업을 수행해줘:
1. 1년치 날짜별 데이터 전체를 보내는 대신, 오늘 계좌의 핵심 숫자(일간 손익, 체결 3건, 현재 잔고)만 15줄 이내의 JSON(프로그램끼리 주고받는 정해진 형식의 텍스트)으로 뽑아 주는 작은 파이썬 함수 'summarize_daily_context()'를 작성해줘.
2. 이 요약 JSON만을 Claude Code에게 전달하여 일일 분석 코멘트를 생성하게 해줘.
3. 전체 데이터를 보내는 기존 방식과 요약 방식을 나란히 놓고, 보내는 글의 길이(글자 수)와 그것을 토큰으로 어림한 수, 예상 비용을 대화창에 비교 출력해줘. 토큰으로 어림한 방법도 함께 적어.

[하지 말 것]
- 요약 JSON에 오늘 실제 데이터에 없는 값을 채우지 마. 항목이 비었으면 빈 값(null)으로 두고 그 이유를 표시해.
- 글의 길이는 실제로 잰 글자 수를 써. 토큰 수와 비용은 그 글자 수에서 계산하고, 계산 방법 없이 짐작한 숫자를 적지 마.
- 요약 함수와 비교표 외에 다른 파일을 만들지 마.

[확인] 대화창에 기존 방식 vs 요약 방식의 글자 수·어림 토큰 수·예상 비용 비교표가 출력되었는지, 그리고 요약 JSON만으로 생성된 분석 코멘트가 함께 표시되었는지 확인해줘.
```
