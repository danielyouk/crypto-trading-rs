# 모의투자에서 실제 투자로 전환하기 전 확인할 사항

## 이번 클립에서 만들 것

이 클립이 끝나면, 여러분은 가상 머니로 진행하던 모의투자 단계를 성공적으로 졸업하고, 실제 소중한 내 자본을 투입하여 실전 자동매매로 전환할 때 발생할 수 있는 모든 리스크를 사전에 점검하는 **'실전 전환 10대 프로페셔널 체크리스트(Live-Trading Readiness Checklist)'**와 **'자금 단계별 투입 로드맵'**을 확립하게 됩니다.

> 💡 **수강생 안심 선언**: 실전으로 넘어갈 때 처음부터 전 재산(1억, 5천만 원)을 한 번에 넣으면 절대로 안 됩니다! 100만 원, 300만 원의 '학습용 소액 실전자금'으로 최소 1개월간 시스템의 무결성을 검증한 뒤 단계적으로 자금을 늘려야 합니다.

- 모의투자와 실전 투자의 **결정적 3가지 현실 차이 (심리적 압박, 실제 호가 체결 슬리피지, 세금/출금 이슈)**
- **실전 전환 10대 체크리스트 (인증, 보안, 자산관리, 하드가드레일, 비상 대응)**
- 단계별 자금 스케일업 로드맵 (Stage 1: 100만 원 ➔ Stage 2: 1,000만 원 ➔ Stage 3: 목표 운용 자산)
- **실습 28**: Claude Code와 함께 내 시스템의 실전 배포 적격성(Go/No-Go) 감사 수행

### 2. 실전 전환 10대 최종 체크리스트

1. **[모의투자 검증]** 최소 2주 이상 모의투자에서 에러 없는 무인 주문/체결 이력을 기록했는가?
2. **[보안 격리]** `.env` 파일에 실전 `APP_KEY`가 안전하게 보관되어 있고 `.gitignore`가 적용되었는가?
3. **[하드 손절 가동]** 개별 종목 -3% 도달 시 사람 승인 없이 0.1초 만에 즉시 시장가 청산되는가?
4. **[서킷브레이커]** 일일 계좌 -2% 도달 시 전 종목 비상 청산 및 당일 매매 잠금이 테스트되었는가?
5. **[1회 주문 상한]** 1회 주문 금액 상한(예: 300만 원 이하)이 `order_validator.py`에 걸려 있는가?
6. **[슬리피지 마진]** 왕복 0.3% 이상의 거래비용 스트레스 테스트에서도 수익성이 유지되는가?
7. **[킬 스위치]** `kill_switch.flag` 생성 시 즉시 모든 발주가 중단되는 비상 탈출구가 있는가?
8. **[일일 저널]** 매일 장 마감 후 체결 내역과 PnL이 파일로 자동 기록되는가?
9. **[소액 시작 원칙]** 최초 실전 투입 자금이 총 투자 가능 금액의 10% 이하(100~300만 원)인가?
10. **[심리적 각오]** 백테스트에서 확인한 최대 손실(MDD -10%)을 감내할 마음의 준비가 되었는가?

## 실습 — 실습 28: 실전 배포 적격성(Go/No-Go) 감사

Claude Code 대화창에 아래 프롬프트를 입력하세요.

```prompt
모의투자에서 실전 투자로 전환하기 전 시스템 무결성을 점검하는 'system_audit.py'를 작성하고 감사 보고서를 생성해줘. (Context)

다음 항목들을 점검해줘: (Deliverable)
1. .env 파일의 보안 설정 및 Git 제외 상태 검사
2. weekly_policy.json의 유효기간 및 승인 상태 검사
3. risk_guard.py의 하드 손절(-3%) 및 서킷브레이커(-2%) 로직 검사
4. order_validator.py의 주문 상한선 설정 검사
5. 10대 체크리스트 점검 결과를 종합하여 실전 배포 판정(GO / NO-GO)과 권장 시작 자금 가이드를 'docs/live_trading_readiness_audit.md' 파일로 저장해줘.

실행 완료 후 화면에 최종 판정표를 출력해줘. (Verification)
```
