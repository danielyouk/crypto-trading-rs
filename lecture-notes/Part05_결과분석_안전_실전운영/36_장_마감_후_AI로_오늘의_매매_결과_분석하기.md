# 장 마감 후 AI로 오늘의 매매 결과 분석하기

## 이번 클립에서 만들 것

이 클립이 끝나면, 여러분은 장 마감 후 매매 데이터를 바탕으로 **'체결 영수증 ➔ 손익 분해 ➔ AI 원인 진단'**으로 이어지는 정밀 사후 분석 리포트를 생성하고, AI가 도출한 원인 후보와 실제 계좌 숫자를 교차 검증하는 포스트-마켓 리뷰 루틴을 완전히 마스터하게 됩니다.

> 💡 **수강생 안심 안내**: 기록 없는 투자는 도박입니다. 퀀트 시스템 트레이딩의 진정한 강점은 **모든 진입과 청산, 체결 슬리피지가 1원 단위의 데이터로 남아 객관적 분석이 가능하다는 점**에 있습니다.

- 일일 매매 성과표의 4대 핵심 축: 시그널 발생, 정책 부합 여부, 실제 체결 단가, 실현 손익
- AI를 활용한 **'손익 기여도(PnL Attribution) 및 슬리피지 누수 분석'**
- 단일 거래의 일희일비(감정)를 배제하고 통계적 이상치를 걸러내는 피드백 기법
- **실습 24**: Claude Code를 통한 당일 체결 내역 심층 진단 리포트 생성

### 2. AI 분석 리포트의 가설 수립 메커니즘

AI에게 일일 데이터를 넘겨주면 다음과 같은 정량적 근거 기반의 가설을 도출합니다.
- *"KODEX 레버리지에서 발생한 -1.8% 손실은 09:15 급등 후 14:00 이후 외인 매도세로 인한 장 후반 급락이 원인입니다."*
- *"KB금융 페어트레이딩은 Z-Score가 1.2에서 0.3으로 정상 수렴하며 +0.9%의 차익을 안정적으로 실현했습니다."*

## 실습 — 실습 24: AI 일일 매매 심층 분석 실행

Claude Code 대화창에 아래 프롬프트를 입력하세요.

```prompt
오늘의 매매 체결 내역과 계좌 잔고 데이터를 바탕으로 AI 심층 성과 분석 리포트를 작성해줘. (Context)

다음 요구사항에 맞춰 분석을 수행해줘: (Deliverable)
1. orders_history.json과 daily_journal.md 데이터를 로드해줘.
2. 각 체결 건별 [신호 발생가 vs 실제 체결가]를 대조하여 슬리피지(%)를 산출해줘.
3. 오늘의 총 손익을 4대 전략별 기여도(추세, 돌파, 모멘텀, 페어)로 분해한 표를 대화창에 출력해줘.
4. 오늘 발생한 손실 거래에 대해 시장 요인(KOSPI 등락)과 전략 요인을 대조한 'AI 원인 분석 의견서'를 작성하고 'docs/daily_performance_review.md'로 저장해줘.

실행 완료 후 화면에 전략별 손익 기여도 표와 AI 총평을 출력해줘. (Verification)
```

---

### 내 눈으로 확인할 체크리스트

- [ ] 체결 건별 슬리피지 추정치와 수수료 합계가 명확히 계산되었다.
- [ ] 오늘 계좌 손익이 4개 전략별로 얼마씩 기여했는지 분해된 표를 확인했다.
- [ ] `docs/daily_performance_review.md`에 정량적 근거가 담긴 AI 분석 보고서가 저장되었다.
