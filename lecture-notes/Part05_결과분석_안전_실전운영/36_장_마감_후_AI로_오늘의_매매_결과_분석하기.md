# 장 마감 후 AI로 오늘의 매매 결과 분석하기

## 이번 클립에서 만들 것

이 클립이 끝나면, 여러분은 장 마감 후 매매 데이터를 바탕으로 **'체결 영수증 ➔ 손익 분해 ➔ AI 원인 진단'**으로 이어지는 정밀 사후 분석 리포트를 생성하고, AI가 내놓은 원인 후보를 실제 계좌 숫자와 맞춰 보는 장 마감 후 점검 루틴을 완전히 마스터하게 됩니다.

> 💡 **수강생 안심 안내**: 기록 없는 투자는 도박입니다. 퀀트 시스템 트레이딩의 진정한 강점은 **모든 진입과 청산, 체결 슬리피지가 1원 단위의 데이터로 남아 객관적 분석이 가능하다는 점**에 있습니다.

- 일일 매매 성과표의 4대 핵심 축: 시그널 발생, 정책 부합 여부, 실제 체결 단가, 실현 손익
- AI로 **오늘 총손익이 네 전략에서 각각 얼마씩 나왔는지 나눠 보기(손익 기여도)**와 **주문한 가격과 실제 체결 가격의 차이(슬리피지)로 새어 나간 돈 확인**
- 거래 하나하나의 손익에 일희일비하지 않고, 평소와 크게 다른 거래만 골라내 원인을 보는 법
- **실습 24**: Claude Code를 통한 당일 체결 내역 심층 진단 리포트 생성

### 2. AI가 손익의 원인을 추정하는 방식

AI에게 일일 데이터를 넘겨주면, 숫자를 근거로 "이것 때문일 것 같다"는 원인 후보(가설)를 내놓습니다. 아래는 그런 문장의 예시입니다. 후보일 뿐이니 실제 계좌 숫자와 맞춰 보는 것은 우리 몫입니다.
- *"KODEX 레버리지에서 발생한 -1.8% 손실은 09:15 급등 후 14:00 이후 외국인 투자자의 매도로 인한 장 후반 급락이 원인입니다."*
- *"KB금융 페어트레이딩은 Z-Score(두 종목의 가격 차이가 평소보다 얼마나 벌어졌는지 나타낸 숫자)가 1.2에서 0.3으로 줄어 평소 수준으로 돌아오며 +0.9%의 차익을 안정적으로 실현했습니다."*

## 실습 — 실습 24: AI 일일 매매 심층 분석 실행

Claude Code 대화창에 아래 프롬프트를 입력하세요.

```prompt
[맥락] 오늘의 매매 체결 내역과 계좌 잔고 데이터를 바탕으로 AI 심층 성과 분석 리포트를 작성하고 싶어.

[만들 것] 다음 분석을 수행해줘:
1. orders_history.json과 클립 34에서 만든 오늘 자 일지(`docs/daily_journal_YYYYMMDD.md`)를 로드해줘.
2. 각 체결 건별 [신호 발생가 vs 실제 체결가]를 대조하여 슬리피지(%)를 산출해줘.
3. 오늘 총손익이 네 전략(추세, 돌파, 모멘텀, 페어)에서 각각 얼마씩 나왔는지 나눈 표를 대화창에 출력해줘.
4. 오늘 발생한 손실 거래마다, 시장 전체가 빠져서 생긴 손실인지(그날 KOSPI 등락과 비교) 우리 규칙 때문에 생긴 손실인지 나눠 본 'AI 원인 분석 의견서'를 작성하고 'docs/daily_performance_review.md'로 저장해줘.

[하지 말 것]
- orders_history.json과 오늘 자 일지에 실제로 있는 체결과 숫자만 써. 없는 거래를 만들어 넣거나 손익을 추정으로 채우지 마.
- 손실 원인을 '시장이 빠져서'로 뭉뚱그리지 마. 시장 전체 때문인 부분과 우리 규칙 때문인 부분을 나눠 각각 근거 수치를 붙여.
- 분석 보고서만 써. 전략 코드나 정책 파일을 고치지 마.

[확인] 대화창에 네 전략별 손익을 나눈 표와 AI 총평이 출력되었는지, 그리고 'docs/daily_performance_review.md' 파일이 저장되어 경로가 표시되었는지 확인해줘.
```

- [ ] 오늘 계좌 손익이 4개 전략별로 얼마씩 기여했는지 분해된 표를 확인했다.
