# 텔레그램으로 매매 알림과 승인·거절 버튼 만들기

## 도입 멘트 (2분)

시그널 엔진이 신호를 만들기 시작했으니, 이제 그 신호가 여러분의 주머니 속 휴대폰으로 와야 합니다. 오늘 클립이 끝나면 텔레그램에 승인·거절 버튼이 달린 알림이 도착합니다. 이 버튼이 앞으로 여러분 시스템의 유일한 매수 관문이 됩니다.

## 진행 흐름

- (0~2분) 도입
- (2~6분) 이론: 알림 채널의 3조건 (즉시성·이동성·응답 가능) — 텔레그램 인라인 버튼의 강점
- (6~11분) **화면 시연**: BotFather로 봇 만들기
  - `/newbot` → 이름 설정 → 봇 토큰 수령 (토큰은 모자이크)
  - 토큰을 .env에 저장 — "앱키와 똑같은 취급"이라고 명시
  - **함정 예방**: 봇에게 먼저 말을 걸어 대화를 시작해야 함을 이 시점에 시연
- (11~18분) **실습 15 시연**: 프롬프트 입력 → 테스트 신호 발생 → 휴대폰 화면 미러링으로 알림 도착 장면
  - 승인 클릭 → 시스템 로그에 "승인됨" 기록 확인
  - 거절 클릭 → "거절됨" 기록 + 아무 일도 없음 확인
- (18~22분) 자주 발생하는 문제 (채팅 ID 미발견, 토큰 오타, 버튼 무반응) + 마무리

## 강조 포인트

- 휴대폰 미러링으로 알림 도착 순간을 반드시 화면에 담을 것 — 이 클립 최대의 "와" 포인트
- 아직 버튼은 기록만 한다는 점을 명확히 — 주문 연결은 c03에서. 단계 분리를 다시 강조
- "봇에게 먼저 말 걸기"를 놓치는 수강생이 가장 많음 — 두 번 반복해서 안내

## 마무리 멘트 (1분)

이제 시장의 신호가 여러분을 찾아옵니다. 다음 클립에서는 같은 알림을 카카오톡과 이메일로도 받아보고, 채널마다 어떤 역할을 맡길지 정리하겠습니다.
