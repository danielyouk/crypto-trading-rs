## 도입 멘트 (2분)

오늘이 Part 4의 하이라이트입니다. 신호가 오고, 여러분이 승인 버튼을 누르면, 모의 계좌에 실제 체결 내역이 생깁니다. Part 1 첫 클립에서 데모로 봤던 바로 그 장면을 오늘 여러분 손으로 만듭니다.

## 진행 흐름

- (0~2분) 도입
- (2~7분) 이론: "승인 없이는 주문 없다"를 구조로 강제하기
  - 매수 주문의 유일한 경로 = 승인 버튼. AI도 스케줄러도 우회 불가
- (7~10분) 이론: 주문의 세 가지 사전 결정 (수량 계산 규칙·가격 방식·신호 유효 시간)
  - 접수와 체결의 차이 — 체결 회신까지가 한 사이클
- (10~17분) **실습 16 시연**: 프롬프트 입력 → 승인·거절 두 시나리오 실연
  - 테스트 신호 → 휴대폰에서 승인 클릭 → "체결 완료" 회신 도착
  - **핵심 검증 장면**: MTS 모의투자 화면을 열어 같은 체결 내역을 나란히 확인
  - 거절 시나리오: 계좌에 아무 흔적 없음 확인
- (17~20분) 자주 발생하는 문제 (장 시간 밖 주문 거부, 모의/실전 주문 코드 구분, 토큰 만료) + 마무리

## 강조 포인트

- 승인 클릭 → 체결 회신 → MTS 확인의 3연속 장면이 이 강의 전체의 대표 컷 — 촬영에 가장 공들일 것
- 장 운영 시간에 촬영 필수 (모의투자도 장중에만 체결)
- "거절과 무시가 안전하게 아무 일도 안 하는 것"도 성공 조건임을 체크리스트로 짚을 것
- 03_paper_approval.gif와 동일한 흐름임을 언급 — Part 1 데모와의 수미상관

## 마무리 멘트 (1분)

여러분의 승인 한 번이 주문이 되어 체결까지 돌아왔습니다. 매수의 관문은 완성입니다. 다음 클립에서는 반대편, 여러분이 응답하지 못하는 순간에 시스템이 여러분을 지키는 자동 손절을 만듭니다.
