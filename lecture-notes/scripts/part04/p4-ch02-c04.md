## 도입 멘트 (2분)

매수는 사람이 승인해야만 나가게 만들었습니다. 그런데 손절도 그렇게 하면 어떻게 될까요? 회의 중에, 잠든 사이에 손실이 커져도 시스템은 기다리기만 할 겁니다. 오늘은 이 강의의 하이브리드 철학의 나머지 절반, 무응답 시 자동으로 실행되는 손절을 만듭니다.

## 진행 흐름

- (0~2분) 도입
- (2~8분) 이론: 매수와 손절의 비대칭
  - "매수를 놓치면 기회를 잃고, 손절을 놓치면 돈을 잃는다" — Part 1부터 이어온 문장 회수
  - 무응답 = 실행이 기본값인 이유
- (8~12분) 이론: 유예 시간 설계 (1분은 너무 짧고 1시간은 너무 김 → 기본 10분)
  - "손절 취소"도 유효한 선택이지만 로그에 남는다 — Part 5에서 내 개입의 성적표를 확인할 것 예고
- (12~19분) **실습 17 시연**: 유예 시간 1분으로 축소 + 가짜 가격 하락 주입
  - 손절 알림 도착 → 일부러 응답하지 않고 대기 → 1분 후 자동 매도 실행 → 회신 확인
  - [이번엔 유지] 선택 시나리오: 매도 안 나가고 로그에 선택 기록
  - MTS에서 매도 체결 확인
- (19~22분) 자주 발생하는 문제 (중복 매도, 버튼 응답이 타이머를 못 멈춤, 장 밖 하락) + 마무리

## 강조 포인트

- 알림을 받고도 **일부러 응답하지 않는** 시연이 핵심 — 침묵 속에서 시스템이 움직이는 긴장감을 살릴 것
- 유예 시간 숫자보다 "미리 정하고 지킨다"가 본질임을 강조
- 중복 매도 버그는 실제 돈이라면 사고 — 테스트 단계에서 잡는 것의 가치를 언급

## 마무리 멘트 (1분)

이제 시스템은 여러분이 자리를 비워도 정해진 규칙으로 여러분을 지킵니다. 다음 클립에서는 장이 끝난 저녁, 내일 시스템이 무엇을 할지 미리 알려주는 시나리오 알림을 만들겠습니다.
