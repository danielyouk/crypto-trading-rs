# 코딩을 몰라도 나만의 트레이딩 시스템을 만들 수 있을까?

## 도입 멘트 (2분)

안녕하세요, 다니엘입니다. 반갑습니다. 

이 강의를 클릭하신 분들은 대부분 비슷한 생각을 하셨을 겁니다. "코딩도 모르고 퀀트도 잘 모르는데, 내가 정말 나만의 자동매매 시스템을 만들 수 있을까?" 

오늘 첫 시간에는 긴 이론이나 문법 강의를 하지 않겠습니다. 대신 제가 실제로 운영하고 있는 시스템이 돌아가는 모습을 있는 그대로 먼저 보여드리겠습니다. 그리고 이 시스템을 만드는 동안 단 한 줄의 코드도 직접 타이핑하지 않고 오직 AI 에이전트와의 대화로 완성했다는 점을 증명해 보이겠습니다.

---

## 진행 흐름

### 1. [0~2분] 오프닝 & 강의의 본질 선언
- 강사 소개 및 커리어 배경(기계공학 엔지니어 → AI 데이터 사이언티스트 → 퀀트 시스템 구축) 1문장 요약.
- "이 강의는 코딩을 가르치는 강의가 아닙니다. 투자 아이디어를 시스템으로 설계하고 검증하는 **사고의 방식(Thinking Process)**을 배우는 과정입니다."

### 2. [2~9분] 핵심 라이브 데모 시연 (풀 사이클 7분)
- **화면 구성**: 좌측 모의계좌 HTS/대시보드 + 우측 터미널 및 텔레그램 창.
- **단계별 시연 포인트**:
  - ① 시장 데이터 감시 중 조건 충족 → 시그널 감지 로그 출력. (강조: 이때 주문은 나가지 않음!)
  - ② 텔레그램으로 봇 알림 도착 (종목명, 진입 사유, 목표가/손절가 리포트 + `[승인]` / `[거절]` 인라인 버튼).
  - ③ 강사가 스마트폰/PC에서 `[승인]` 버튼 클릭.
  - ④ 즉시 모의투자 계좌에 매수 체결 알림 및 체결 로그 팝업.
  - ⑤ 장 마감 시뮬레이션 → 일일 성과 리포트 및 손실 진단서 자동 생성 화면 시연.
- **시연 중 멘트**: "보시다시피 사람이 승인하지 않으면 시스템은 단 1원의 주문도 넣지 않습니다. 이것이 우리가 만들 시스템의 기본 원칙입니다."

### 3. [9~14분] 개념 설명: 100% 자동매매의 환상과 복잡계 시장 (교수식 브리핑)
- **닫힌계 vs 복잡계 비유**:
  - 기계공학의 닫힌계(Closed System): 비행기나 자동차는 물리 법칙이 고정되어 있어 100% 자동제어가 가능함.
  - 금융시장의 복잡계(Complex Adaptive System): 시장 참여자들의 심리와 환경이 얽혀 규칙 자체가 계속 바뀜.
  - 결론: 100% 전자동 봇은 시장 국면이 바뀌는 순간 계좌를 깨뜨린다.
- **인간 개입형 하이브리드 아키텍처의 필연성**:
  - 지치지 않는 계산과 데이터 감시는 AI에게.
  - 거시적 판단과 최종 승인은 사람(나)에게.
  - 돌발 급락에 대한 손절은 감정을 배제한 기계적 규칙에게.

### 4. [14~18분] 패러다임 전환: 코더에서 시스템 아키텍트로
- 문법 암기식 코딩 학습의 좌절과 한계 지적.
- **생각 → 요청 → 확인 → 개선 4단계 루프** 설명:
  - "코드가 강사와 똑같은지 보지 마세요. 화면에 차트가 제대로 나왔는지만 보세요."
  - 확인을 AI에게 맡기면 안 되는 이유 (AI의 과도한 자기 확신).
- 5개 파트 완주 로드맵과 각 단계별 산출물 브리핑 (5대 모듈 다이어그램 조망).

### 5. [18~20분] 마무리 및 다음 클립 안내
- "컴퓨터와 아이디어만 있으면 충분합니다."
- 다음 클립: Claude Code 설치 및 첫 주식 데이터 연동 환경 구축 예고.

## 강조 포인트

- **모의투자(Paper Trading) 강조**: 데모 화면에서 '모의계좌' 워터마크나 계좌 번호를 명확히 보여주어 현실성과 안전성을 동시에 각인.
- **환상 깨기 & 신뢰 구축**: 허황된 수익률 자랑을 배제하고, "얼마나 버는가만큼 얼마나 덜 잃는가"가 핵심임을 선언.
- **화면과 문서의 상호작용**: 좌측의 마크다운 교재를 한 줄씩 읽지 않고, 다이어그램과 표를 가리키며 직관적 개념 중심으로 전달.
