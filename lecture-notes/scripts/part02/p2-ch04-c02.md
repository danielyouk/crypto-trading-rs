# ETF 데이터를 활용해 자산배분 전략 검증하기

## 도입 멘트 (1분)

실습 06입니다. 오늘 결과물에는 지금까지 없던 차트가 하나 추가됩니다 — 매월 무엇을 들고 있었는지 보여주는 보유 자산 타임라인입니다. 하락장에서 전략이 채권으로 피신하는 장면을 이 타임라인에서 직접 목격하는 것이 오늘의 목표입니다.

## 진행 흐름

- (0~1분) 도입: 오늘의 하이라이트는 타임라인 차트
- (1~5분) 이론: 이 백테스트에서 확인할 핵심 장면
  - 급락기에 채권 구간이 보이는가 / 상승장은 주식으로 보냈는가
  - 리밸런싱 기준일 착시 — 견고한 전략은 기준일을 옮겨도 큰 그림 유지
- (5~14분) **실습 시연**: 생각→요청→확인→개선
  - (5~6분) 생각: 차트 1장 + 성과표 + 타임라인
  - (6~9분) 요청: SPY/EFA/AGG 15년 프롬프트 입력 — 해외 ETF도 FinanceDataReader로 되는 것 확인
  - (9~12분) 확인: 체크리스트 대조 — 2020년 초 타임라인에 AGG 구간이 있는지 확대해서 확인
  - (12~14분) 개선: 특정 월의 수익률 계산값과 보유 결정을 표로 검증하는 후속 프롬프트 시연
- (14~18분) 결과 해석 + 견고성 실험
  - 전략 MDD vs SPY 단순 보유 MDD 비교
  - 모멘텀 기간을 12개월→6개월로 바꿔 재실행, 큰 그림이 유지되는지 즉석 비교
- (18~20분) 수강생 실습 안내 + 마무리

## 강조 포인트

- 타임라인에서 채권 전환 장면을 찾는 순간이 이 클립의 "아하 모먼트" — 시간을 충분히 쓸 것
- 기간 변경 실험(12개월→6개월)은 과최적화 감각을 심는 장치 — "숫자가 조금 달라져도 결론이 같은가"가 질문
- 배당 포함 여부 등으로 강사와 수익률이 다를 수 있음 — 장면(체크리스트) 기준으로 판정
- 연 12회 이하 거래 확인으로 "느린 전략 = 낮은 비용"을 성과표에서 실증
