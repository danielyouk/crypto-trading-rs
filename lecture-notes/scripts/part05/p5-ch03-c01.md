## 도입 멘트 (1분)

시스템이 잘 돌아도 AI 비용이 수익보다 크면 지속할 수 없습니다. 오늘은 짧지만 현실적인 주제, 내 시스템이 AI를 얼마나 쓰고 있고 어디서 아낄 수 있는지를 15분 만에 정리하겠습니다.

## 진행 흐름

- (0~1분) 도입: "비용도 거래비용이다" — Part 2의 거래비용 관점과 연결
- (1~5분) 이론: 과금 구조 두 갈래
  - API 종량제 vs 정액제(Claude Code Max 등) 표 비교
  - 우리 시스템의 병행 구조: 자동 보고서=API, 대화형 개발=정액제
- (5~9분) 이론: 절감의 세 지렛대
  - 캐시 활용(반복 프롬프트), 저가 모델 혼용(단순 작업), 호출 시점 제한(장 마감 후로 모으기)
  - 모델별 역할 분담표 — 보고서 요약은 저가, 손실 분석은 상위 모델
- (9~13분) **데모**: 내 시스템의 AI 호출 지점·월 비용 추정 프롬프트 시연
  - 저가 모델로 내릴 수 있는 지점과 예상 절감액이 표로 나오는 장면
  - 시연 중: 모델 단가는 수시로 바뀌므로 금액보다 "어디서 많이 쓰나" 순위가 목적임을 언급
- (13~15분) 따라 해보기 안내 + 마무리

## 강조 포인트

- 정확한 금액이 아니라 비용 구조 파악이 목표 — 수강생 청구액이 달라도 당황하지 않게
- 최고 모델 만능주의 깨기: 표 정리에 최고 모델을 쓰는 것은 낭비
- 강의 촬영 시점과 가격이 다를 수 있음을 명시 (가격표는 항상 최신 확인)

## 마무리 멘트 (1분)

비용을 아는 순간부터 시스템은 취미가 아니라 운영이 됩니다. 다음 클립에서는 재미있는 실험을 하나 합니다. 지금까지의 프롬프트를 Claude Code가 아닌 Codex에 그대로 넣어보고, 우리가 배운 것이 도구가 아니라 작업 방식이라는 것을 확인하겠습니다.
