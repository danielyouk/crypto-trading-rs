# AI 알고리즘 트레이딩 강의 교재 & 빌드 가이드

> **"수강생 여러분만의 살아있는 투자 전략 핸드북을 만드세요."**
> 
> 이 폴더는 단순한 정적 교재가 아니라, 여러분이 강의를 들으며 직접 수정하고 백테스트 결과를 덧붙여 나만의 웹북으로 빌드할 수 있는 **Docs-as-Code(코드형 문서)** 환경입니다.

---

## 1. 폴더 구조 (MD & HTML 단일 통합 구조)

마크다운 원본(`.md`)과 웹 교재(`.html`)가 각 Part 폴더 안에 나란히 위치합니다.

```
lecture-notes/
├── README.md               # 이 가이드 문서
├── MASTER-PLAN.md          # 5개 파트 43클립 마스터 커리큘럼 맵
├── curriculum.json         # 클립 메타데이터 (파트·챕터·제목·시간·실습)
├── build.py                # 1초 HTML 재빌드 스크립트 (수강생 실행용)
├── index.html              # 전체 교재 목차 (브라우저로 바로 열기)
│
├── assets/
│   └── style.css           # 좌측 반화면(760px) 최적화 스타일시트
├── template/
│   ├── index.html.j2       # 목차 템플릿
│   └── page.html.j2        # 개별 클립 템플릿
│
├── part01/                 # Part 1: AI와 함께 시작하는 트레이딩 시스템
│   ├── p1-ch01-c01.md      # 마크다운 원본 (자유롭게 수정 가능!)
│   ├── p1-ch01-c01.html    # 변환된 HTML 웹 교재
│   └── ...
├── part02/                 # Part 2: 4가지 투자 전략 백테스트
│   ├── p2-ch01-c01.md
│   ├── p2-ch01-c01.html
│   └── ...
├── part03/                 # Part 3: 시장 변화와 워크포워드 점검·개선
├── part04/                 # Part 4: 시그널부터 승인·모의주문 연결
├── part05/                 # Part 5: 일일 결과 분석과 안전한 운영
│
└── scripts/                # 강사용 강의 진행 스크립트 (HTML 변환 제외)
```

---

## 2. 교재 열람 방법 (브라우저로 바로 보기)

별도의 웹 서버나 설치 없이, **`lecture-notes/index.html`**을 크롬이나 엣지 브라우저로 더블클릭해서 열면 됩니다.

- **화면 배치 추천**: 모니터 **좌측 절반에 HTML 교재**를 띄우고, **우측 절반에 Claude Code / Cursor**를 띄워 실습하세요.
- **프롬프트 복사**: 교재 안의 프롬프트 블록 우측 상단 `[복사]` 버튼을 누르면 AI에게 보낼 명령어가 클립보드에 바로 복사됩니다.
- **체크리스트**: 강의를 들으며 `[ ]` 체크박스를 직접 클릭하여 실습 완성을 점검할 수 있습니다.

---

## 3. 수강생을 위한 나만의 교재 커스터마이징 & 빌드 방법

수강생 여러분은 제공된 마크다운(`.md`) 파일을 나만의 노트로 자유롭게 발전시킬 수 있습니다:

1. **관심 종목 변경**: `part02/p2-ch02-c02.md`의 프롬프트 템플릿에 삼성전자 대신 자신이 관심 있는 종목(예: SK하이닉스, NAVER 등)을 적어두기.
2. **실습 결과 및 메모 기록**: 직접 돌려본 백테스트 CAGR, MDD 수치나 개인적인 깨달음을 각 `.md` 파일 하단에 자유롭게 추가.
3. **나만의 프롬프트 보관**: AI와 대화하며 가장 효과적이었던 후속 프롬프트를 노트에 정리.

### ⚡ 1초 만에 HTML 다시 빌드하기

`.md` 파일을 수정한 뒤, 터미널에서 다음 명령을 실행하면 모든 HTML 웹 페이지가 즉시 새로고침됩니다:

```bash
# lecture-notes 폴더 안에서 실행할 때
python build.py

# 또는 프로젝트 루트 폴더에서 실행할 때
python runners/build_lecture_notes.py
```

빌드가 끝나면 브라우저에서 `F5(새로고침)`만 누르면 여러분이 추가한 나만의 메모와 백테스트 수치가 깔끔한 웹북으로 반영됩니다.
