# 오류가 발생했을 때 AI와 함께 해결하는 방법

## 이번 클립에서 만들 것

이 클립이 끝나면, 앞으로 알고리즘 트레이딩 시스템을 구축하며 마주칠 어떤 복잡한 에러와 돌발 상황 앞에서도 당황하지 않고 해결하는 **'4단계 AI 디버깅 표준 프로토콜'**과 **'시각적·데이터 검증 기법'**을 완벽하게 체득하게 됩니다.

> 💡 **수강생 안심 선언**: 프로그래밍과 AI 코딩에서 에러는 '내가 무언가를 잘못해서 실패한 사건'이 아닙니다. 에러 메시지는 AI가 코드를 완성하기 위해 인간에게 건네는 **가장 완벽하고 가치 있는 피드백 신호(Feedback Signal)**입니다. 시니어 퀀트 개발자도 하루에 수십 번씩 에러를 만나며 작업합니다.

- **퀀트 트레이딩 4대 에러 유형**(환경/데이터/침묵의 논리/시각화)의 원인과 해결 패턴 이해
- AI에게 에러를 전달할 때 절대로 놓쳐서는 안 되는 **4단계 디버깅 프로토콜** 마스터
- 로그가 남지 않는 '침묵의 에러(차트 깨짐, NaN 결측치 전파)'를 잡는 **스크린샷 캡처 및 데이터 형상 진단법**
- 초보자가 흔히 저지르는 **3대 디버깅 안티패턴(Anti-patterns)** 탈출

### 3. AI와 함께하는 4단계 디버깅 표준 프로토콜

에러를 만났을 때 AI에게 던지는 프롬프트의 품질이 해결 속도를 결정합니다. 아래의 **4단계 프로토콜**을 복사기처럼 그대로 사용하세요.

```text
[Step 1: Raw Traceback] 터미널에 출력된 에러 메시지 전체 복사 (절대 요약하지 않음)
   ↓
[Step 2: Context Tagging] "무엇을 하다가(어떤 파일을 실행하다가)" 났는지 1문장 추가
   ↓
[Step 3: Target Re-statement] 원래 얻으려 했던 "최종 결과물의 형태"를 다시 선언
   ↓
[Step 4: Verification Request] 수정 후 정상 동작 여부를 확인하는 검증 출력 요청
```

#### 터미널 스택트레이스(Traceback)의 비밀
초보자는 흔히 터미널의 가장 마지막 한 줄(예: `ZeroDivisionError: division by zero`)만 AI에게 보냅니다. 하지만 AI에게는 **중간 줄에 적힌 "몇 번째 파일, 몇 번째 라인에서 어떤 함수를 호출했는가"**라는 스택트레이스가 10배 더 중요합니다. 반드시 **위아래 전체를 통째로 복사**하세요.

### 4. 로그가 없을 때의 무기 — 시각적 스크린샷 캡처와 데이터 형상 출력

만약 터미널에 아무런 붉은 에러 글씨가 뜨지 않는데도 결과가 이상하다면 어떻게 해야 할까요?

1. **화면 캡처 전달 (Multimodal Prompting)**: 차트가 찌그러졌거나 한글이 깨졌다면 말로 구구절절 설명하지 말고 **화면을 캡처해서 Cursor/Claude Code 채팅창에 붙여넣기(Ctrl+V)**하세요. 최신 AI는 이미지를 보고 즉시 폰트 설정 코드(`plt.rc('font', family='Malgun Gothic')`)나 레이아웃 조절 코드(`plt.tight_layout()`)를 생성합니다.
2. **데이터 형상(Shape)과 결측치 출력 요청**: 숫자가 이상할 때는 AI에게 데이터의 중간 상태를 확인해 달라고 요청합니다.
   > *"데이터프레임의 상위 5줄(`head()`), 결측치 개수(`isna().sum()`), 데이터 타입(`dtypes`)을 출력해서 이상이 없는지 먼저 진단해줘."*

## 자주 발생하는 문제 및 Q&A

**Q1. AI가 코드를 고쳤다고 하는데 여전히 똑같은 에러가 반복됩니다. 어떻게 해야 하나요?**  
AI가 이전 대화 맥락에 갇혀 같은 실수를 반복하는 현상입니다. 이럴 때는 대화창에 `/clear`를 입력해 대화 메모리를 초기화한 뒤, **"프로젝트의 원래 목표 + 작업 중인 파이썬 파일 경로 + 방금 발생한 에러 로그 전체"**를 하나의 프롬프트에 담아 새롭게 질문하면 즉시 해결됩니다.

**Q2. 에러 로그가 수백 줄이 넘어서 터미널 위로 훌쩍 지나가 버립니다. 어디서부터 복사해야 하나요?**  
터미널 창을 위로 스크롤하여 파이썬 실행 명령어(예: `python test.py`) 바로 다음 줄부터 맨 아래 프롬프트 입력창 직전까지 마우스 드래그로 긁어서 복사하면 됩니다. 터미널 출력이 너무 길다면 `"방금 실행한 파이썬 에러 로그를 error.log 파일로 저장해줘"`라고 지시해도 좋습니다.

**Q3. 터미널에 붉은색 글씨로 긴 문장이 떴는데, 프로그램은 끝까지 실행되어 차트 파일이 나왔습니다. 이것도 에러인가요?**  
그것은 `Error`가 아니라 **`Warning(경고)`**일 가능성이 높습니다 (예: `FutureWarning: Series.__getitem__ treating keys as positions is deprecated`). 경고는 실행을 멈추지는 않지만 향후 라이브러리 업데이트 시 에러가 될 수 있으므로, 해당 경고 문구를 AI에게 복사해 주며 *"이 경고가 발생하지 않도록 최신 문법으로 코드를 다듬어줘"*라고 요청하면 코드가 더욱 견고해집니다.
