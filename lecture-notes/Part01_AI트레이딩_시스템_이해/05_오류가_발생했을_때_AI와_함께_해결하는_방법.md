### 3. 에러와 수정에도 같은 네 칸을 쓴다

Clip 03에서 후속 수정 4칸을 **읽어 두었습니다.** 오늘은 그 칸을 **이미 있는 차트 스크립트에 던집니다.**

새 공식이 아닙니다. 2번째 칸 이름만 `만들 것`에서 `수정할 것`으로 바뀝니다.

| 오늘 만나는 상황 | 후속 4칸에서 하는 일 |
|---|---|
| 에러는 없는데 결과가 다름 | 화면 표를 `"""`에 넣고, **바꿀 점만** 선언 |
| 붉은 에러가 남 | **로그 전체**를 `"""`에 넣고, 날조·우회를 금지 |
| 에러 없이 차트만 이상함 | 말로 설명하지 말고 **화면을 붙여넣기** |

#### 오류 추적 로그(Traceback)의 비밀

**Traceback**: 프로그램이 멈추기 직전까지 **어느 파일의 몇 번째 줄**을 거쳐 왔는지 적어 준 기록입니다.

초보자는 마지막 한 줄만 복사합니다. AI에게는 **중간 줄의 파일 이름과 줄 번호**가 더 중요합니다. 위아래를 통째로 복사한 뒤 `"""`로 감싸세요.

### 4. 로그가 없을 때의 무기 — 시각적 스크린샷 캡처와 데이터 형상 출력

만약 화면에 아무런 오류 메시지가 뜨지 않는데도 결과가 이상하다면 어떻게 해야 할까요?

1. **화면 캡처 전달**: 차트가 찌그러졌거나 한글이 깨졌다면 말로 설명하지 말고 **화면을 캡처해서 대화창에 붙여넣기(Ctrl+V)** 하세요. AI가 이미지를 보고 그 컴퓨터에 맞는 한글 폰트와 여백을 고릅니다.
2. **중간 상태 확인**: 숫자는 나왔는데 느낌이 이상하면, 표의 앞부분·빈칸 개수·열 이름을 먼저 보여 달라고 요청합니다. 고치기 전에 **어디가 비었는지**를 눈으로 확인하는 단계입니다.

### 실습 03-A: 결과는 나왔는데 원하는 것과 다를 때

에러는 없습니다. 차트가 이미 있습니다. 하단 거래량에 **20일 거래량 이동평균선**만 얹습니다.

화면에 나온 최근 5일 요약표를 복사해 `"""` 안에 넣으세요. 날짜와 숫자는 사람마다 다릅니다.

```prompt
[맥락]
Clip 04에서 만든 삼성전자 차트 스크립트가 이미 있어.
실행 후 화면에 나온 요약은 아래와 같아:
"""
(여기에 본인 화면의 최근 5일 요약표를 그대로 붙여넣기)
"""

[수정할 것]
- 새 파일을 만들지 말고 기존 차트 스크립트만 수정해줘.
- 하단 거래량 패널에 20일 거래량 이동평균선을 겹쳐 그려줘.
- 수정된 차트를 기존 이미지 파일 이름 그대로 다시 저장해줘.

[하지 말 것]
- 기존 종가·이동평균선·거래량 막대 로직을 지우거나 바꾸지 마.
- 새 스크립트나 새 이미지 파일을 만들지 마.
- 숫자를 지어내지 마.

[확인]
- 스크립트를 다시 실행하고, 저장된 파일 경로와 거래량 이평이 포함된 요약표를 보여줘.
```

> **결과 관찰**: 새 파일이 생기지 않고, 기존 20/60/120일선은 그대로인 채 거래량 패널에만 선이 하나 더 생깁니다.

### 실습 03-B: 붉은 에러가 났을 때

먼저 일부러 실패하는 요청을 보냅니다. `999999`는 존재하지 않는 종목코드입니다.

```prompt
[맥락] 방금 만든 차트 스크립트를 다른 종목으로도 확인하고 싶어.

[만들 것] 종목코드 999999의 최근 2년 일봉으로 같은 차트를 만들어줘.

[하지 말 것] 데이터를 못 가져오면 비슷한 종목으로 바꾸거나 값을 지어내지 말고,
무엇이 실패했는지 그대로 보여주고 멈춰.
```

화면에 로그가 뜨면, **위아래 전체를 복사**해 후속 4칸에 넣습니다.

```prompt
[맥락]
기존 차트 스크립트를 종목코드 999999로 실행했더니 화면에 아래가 나왔어:
"""
(여기에 에러 로그 전체를 그대로 붙여넣기)
"""

[수정할 것]
- 새 파일을 만들지 말고 기존 스크립트에서 원인을 찾아 수정해줘.
- 조회가 실패하면 값을 만들지 말고, 무엇이 실패했는지 보여준 뒤 멈춰줘.
- 수정이 끝나면 원래 종목(삼성전자 005930)으로 되돌려 차트가 다시 나오게 해줘.

[하지 말 것]
- 비슷한 종목으로 슬쩍 바꾸거나 숫자를 지어내지 마.
- 잘 되던 차트 구성을 처음부터 다시 짜지 마.

[확인]
- 잘못된 종목코드로 한 번 더 실행해, 정직하게 멈추는지 보여줘.
- 이어서 삼성전자로 실행해 차트 파일이 다시 저장되는지 보여줘.
```

> **결과 관찰**: 울타리가 있으면 AI는 실패를 숨기지 않습니다. 없었다면 비슷한 종목이나 가짜 숫자로 우회했을 수 있습니다. Clip 03의 가짜 시세 하드코딩을 여기서 막습니다.

### 실습 03-C: 에러 없이 차트만 이상할 때

붉은 글씨는 없는데 한글이 네모(`□□□`)이거나, 이동평균선 앞부분이 비어 보일 수 있습니다.  
**말로 추측하지 말고**, 화면을 붙여넣거나 빈칸이 몇 개인지 먼저 물어보세요.

차트가 깨져 보이면 이미지를 대화창에 붙인 뒤:

```prompt
[맥락]
기존 차트 파일이 이미 있어. 방금 연 이미지와 화면 출력은 아래와 같아.
(이미지는 대화창에 붙여넣기)
"""
(화면에 보인 안내 문구가 있으면 그대로 붙여넣기)
"""

[수정할 것]
- 새 파일을 만들지 말고 기존 스크립트만 수정해줘.
- 제목과 축의 한글이 이 컴퓨터에서 깨지지 않게 해줘.
- 같은 파일 이름으로 차트를 다시 저장해줘.

[하지 말 것]
- 종가·이동평균·거래량 계산을 바꾸지 마.
- 화면을 멈추는 창을 띄우지 마.

[확인]
- 다시 저장한 파일 경로를 보여줘. 내가 이미지를 열어 한글을 확인할게.
```

숫자가 이상하면, 고치기 전에 중간 상태만 요청합니다.

```prompt
[맥락]
기존 차트 스크립트의 이동평균선 앞부분이 비어 보이는 것 같아.

[수정할 것]
- 코드를 고치기 전에, 이동평균 열에서 빈칸이 며칠분인지와 전체 행 수를 표로 보여줘.

[하지 말 것]
- 빈칸을 임의의 숫자로 채우지 마.
- 새 파일을 만들지 마.

[확인]
- 빈칸 개수와 행 수를 숫자로 보여준 뒤에만, 차트 표시에 해가 되지 않게 처리할 방법을 제안해줘.
```

## 자주 발생하는 문제 및 Q&A

**Q1. AI가 코드를 고쳤다고 하는데 여전히 똑같은 에러가 반복됩니다. 어떻게 해야 하나요?**  
AI가 이전 대화 맥락에 갇혀 같은 실수를 반복하는 현상입니다. 이럴 때는 대화창에 `/clear`를 입력해 대화 메모리를 초기화하거나 새 세션을 연 뒤, **"프로젝트의 원래 목표 + 작업 중인 파이썬 파일 경로 + 방금 발생한 에러 로그 전체"**를 하나의 프롬프트에 담아 새롭게 질문하면 즉시 해결됩니다.

**Q2. 에러 로그가 너무 길어서 화면 위로 훌쩍 지나가 버립니다. 어디서부터 복사해야 하나요?**  
오류가 시작된 줄(`Traceback`이 보이는 줄)부터 맨 끝 에러 이름까지 통째로 복사한 뒤, 후속 4칸의 `[맥락]` 안에서 `"""`로 감싸세요. 한 줄만 보내면 AI가 위치를 못 찾습니다.

**Q3. 실행 결과창에 붉은색 글씨나 긴 영문 문장이 떴는데, 프로그램은 끝까지 실행되어 차트 파일이 나왔습니다. 이것도 에러인가요?**  
그것은 `Error`가 아니라 **`Warning(경고)`**일 가능성이 높습니다 (예: `FutureWarning: Series.__getitem__ treating keys as positions is deprecated`). 경고는 실행을 멈추지는 않지만 향후 라이브러리 업데이트 시 에러가 될 수 있으므로, 해당 경고 문구를 AI에게 복사해 주며 *"이 경고가 발생하지 않도록 최신 문법으로 코드를 다듬어줘"*라고 요청하면 코드가 더욱 견고해집니다.
