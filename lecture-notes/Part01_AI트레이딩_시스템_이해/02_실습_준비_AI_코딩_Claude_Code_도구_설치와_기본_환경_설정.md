### 1. 왜 AI 코딩인가? — 문법을 몰라도 시스템을 만든다

전통적인 코딩이 사람이 프로그래밍 문법을 학습해 모든 줄을 타이핑하는 방식이었다면, 에이전트 기반 코딩은 **사람이 전략의 목표와 규칙을 정의하고 AI가 코드 작성과 실행을 전담**하는 방식입니다.

### 2. 왜 데스크탑 앱이 아니라 편집기 확장인가?

Claude Code는 터미널 CLI, 데스크탑 앱, 편집기 확장(Extension)의 3가지 형태로 제공됩니다. 모두 동일한 엔진과 요금제를 사용하지만, 본 강의가 확장을 권장하는 핵심 이유는 3가지입니다.

## 실습 — 실습 01: AI 도구 환경 구축

### Step 1. 확장 설치 및 자율권 모드 설정

#### 1-1. 에디터 준비 및 확장 설치
1. **VS Code** (또는 Cursor)를 실행합니다.
2. 왼쪽 사이드바의 **Extensions**(네모 블록 아이콘)를 클릭합니다.
3. 검색창에 **`Claude Code`**를 입력하고 Anthropic 공식 확장을 **Install**합니다.
4. 작업용 빈 폴더 `ai-trading`을 생성한 뒤 `File` → `Open Folder`로 엽니다.
5. Claude 아이콘을 눌러 대화창을 열고 로그인합니다.

#### 1-2. 자율권 모드 설정 (Auto 권장)
프롬프트 입력창 하단의 모드 버튼을 클릭하거나 `Shift + Tab`을 눌러 모드를 설정합니다.

| 모드 | 파일 수정 (Edit) | 터미널 명령 실행 (Bash) | 추천 사용 상황 |
|---|---|---|---|
| **Manual** | 승인 필요 | 승인 필요 | 중요한 코드 변경 직접 검토 시 |
| **Edit automatically** | 자동 승인 | 승인 필요 | 일반 파일 작성 시 |
| **Auto** | **자동 승인** | **안전 명령 자동 승인** | **초기 환경 구축 및 일괄 실행 시 (권장)** |

> 💡 **안내**: 목록에 `Auto`가 보이지 않는 경우 `Edit automatically`를 선택하고, 명령어 실행 팝업 시 **`Yes, and don't ask again`**을 선택하시면 됩니다.


### Step 4. 좌우 비교 화면(Diff) 체험 및 시세 교차 검증

#### 4-1. 수동 승인(Diff) 체험하기
1. 프롬프트 하단 모드를 **`Manual`**로 변경합니다.
2. 아래 프롬프트를 입력합니다:
   ```prompt
   hello_market.py에 최근 5일 종가의 평균을 계산해서 표 아래에 한 줄로 출력하는 코드를 추가해줘.
   ```
3. 에디터 중앙에 열리는 **좌우 비교 화면(Diff)**에서 초록색 변경 줄을 확인하고, 필요 시 직접 텍스트를 수정한 뒤 승인합니다.

#### 4-2. 내 눈으로 확인할 체크리스트

- [ ] **환경 격리 완료**: 폴더 내에 `.venv`와 `hello_market.py`가 깔끔하게 생성되었다.
- [ ] **패키지 설치 확인**: `pandas`, `matplotlib`, `FinanceDataReader` 버전 정보가 정상 출력되었다.
- [ ] **데이터 무결성 대조**: 화면에 출력된 삼성전자 최근 종가가 **포털 증권 화면의 실제 종가와 정확히 일치**한다.
- [ ] **인간 감독 루프 확인**: Manual 모드에서 AI의 코드 제안을 diff 화면으로 검토하고 승인했다.

## 입문자가 가장 많이 묻는 질문 (FAQ)

**Q1. Windows에서 파이썬이 설치되어 있다고 뜨는데 실제 실행이 안 됩니다.**  
Windows 기본 'Microsoft Store 파이썬 껍데기(스텁)'가 잡혀있기 때문입니다. AI에게 `"uv를 사용해서 Python 3.12를 새로 설치하고 가상환경을 다시 만들어줘"`라고 요청하면 깔끔하게 해결됩니다.

**Q2. 패키지 다운로드 중 타임아웃 오류가 발생합니다.**  
일시적 네트워크 지연일 수 있습니다. 대화창에 `"pip install 타임아웃 시간을 늘려서 다시 설치해줘"`라고 프롬프트를 전달하세요.

**Q3. 콘솔 화면에서 한글이 깨져 보입니다.**  
Windows 인코딩 문제일 수 있습니다. `"출력에서 한글이 깨지지 않도록 UTF-8 인코딩을 적용해줘"`라고 요청하시면 AI가 출력 코드를 보정합니다.
