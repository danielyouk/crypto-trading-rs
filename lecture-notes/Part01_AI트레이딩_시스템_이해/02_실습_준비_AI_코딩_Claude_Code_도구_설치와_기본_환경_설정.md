## 실습 — 실습 01: AI 도구 환경 구축

### Step 0. 확장 설치와 자율권 모드 설정

#### 0-1. 확장 설치

1. **Cursor** 또는 **VS Code**를 실행합니다. (둘 중 편한 것을 쓰시면 됩니다. 화면 구성이 거의 같습니다.)
2. 왼쪽 사이드바의 **Extensions**(네모 블록 아이콘)를 클릭합니다.
3. 검색창에 **`Claude Code`**를 입력하고, Anthropic이 만든 확장을 **Install** 합니다.
4. 설치 후 나타난 Claude 아이콘을 클릭해 대화창을 열고, **로그인**합니다.

#### 0-2. 자율권 모드 설정 — AI에게 어디까지 맡길 것인가

대화창에서 **`Shift + Tab`**을 누르면 모드 목록이 뜹니다. 이건 **"AI가 뭘 할 때마다 나에게 물어볼 것인가"**를 정하는 스위치입니다.

| 모드 | 뜻 | 언제 쓰나 |
|---|---|---|
| **Manual** | 편집할 때마다 승인 버튼을 눌러야 함 | 처음 감을 잡을 때 |
| **Plan** | 코드를 고치지 않고 계획만 세워서 보고 | 큰 작업 전에 방향만 볼 때 |
| **Edit automatically** | 편집을 승인 없이 진행 | **오늘 실습에 사용** |
| **Auto** | 안전 검사를 통과한 작업은 자동 진행, 위험한 것만 멈춤 | 목록에 있다면 이걸 쓰셔도 좋습니다 |

**오늘은 `Edit automatically`(또는 `Auto`)를 선택하세요.** 이 설정을 안 하면 실습 내내 승인 버튼을 수십 번 눌러야 합니다.

> ⚠️ **여러분 화면에는 모드가 3개일 수도, 4개일 수도 있습니다.** 편집기 종류, 운영체제, 확장 버전에 따라 목록이 다르게 보입니다. 실제로 같은 확장 버전인데도 어떤 컴퓨터에는 `Auto`가 보이고 어떤 컴퓨터에는 안 보입니다.
>
> **그래서 이 강의는 절대 "몇 번째 항목을 고르세요"라고 말하지 않습니다.** 목록을 보고 **이름으로** 고르세요. `Auto`가 없으면 `Edit automatically`를 고르시면 결과는 같습니다.
>
> 이건 오늘 하루의 예외가 아니라 앞으로 계속 만날 상황입니다. **AI 도구는 화면이 자주 바뀝니다. 화면을 외우지 말고 원리를 기억하세요.** 지금 우리가 하려는 건 "승인 버튼을 매번 안 누르게 만드는 것"이고, 그걸 해주는 항목이 어떤 이름이든 그걸 고르면 됩니다.

### Step 1. 작업 폴더 생성 및 열기

1. 원하는 위치(예: 바탕화면)에 **`ai-trading`** 폴더를 새로 만듭니다.
2. 편집기에서 `File` → `Open Folder`로 이 폴더를 엽니다.
3. Claude 대화창이 이 폴더를 작업 공간으로 인식했는지 확인합니다.

> 📌 **왜 폴더를 따로 만드나요?** AI가 만드는 파일이 다른 자료와 섞이지 않게 하기 위해서입니다. 뭔가 잘못돼도 이 폴더만 지우면 원상복구됩니다.

### Step 2. 진단 프롬프트 — 아무것도 설치하지 않고 상태만 확인

대화창에 아래를 입력합니다.

```prompt
아직 아무것도 설치하지 마. 진단만 해줘.

이 컴퓨터에서 실제로 실행되는 Python이 있는지, 그리고 uv가 설치돼 있는지
확인해서 표 하나로 알려줘.

Windows라면, 경로에 WindowsApps가 들어간 python은 진짜 Python이 아니라
Microsoft Store 안내용 껍데기야. 그건 '없음'으로 처리해줘.
```

**왜 이 단계가 따로 있을까요?** 한 번에 다 시키면, AI는 중간에 막혔을 때 멈추지 않고 **혼자 우회로를 찾습니다.** 그 우회가 잘못된 방향이면 우리는 한참 뒤에야 알아차립니다. 30초짜리 진단을 먼저 하면 갈림길이 눈에 보이고, 그 다음 요청이 훨씬 정확해집니다.

마지막 줄이 이상하게 구체적이죠? Windows에는 **Python이 설치된 척하는 껍데기 프로그램**이 기본으로 들어 있습니다. 사람도 AI도 여기에 잘 속아서, "Python이 있다"고 판단하고 진행했다가 원인 모를 실패를 겪습니다. 실제로 이 강의를 준비하면서 여기서 10분을 날렸습니다.

#### 진단 결과에 따라 갈리는 길

| 진단 결과 | 다음 Step 3에서 |
|---|---|
| Python **있음** | 아래 프롬프트를 그대로 사용 |
| Python **없음** | 아래 프롬프트의 `[만들 것]` 첫 줄에 **`uv를 사용해서 Python 3.12부터 설치해줘.`** 를 추가 |

`uv`는 Python 자체가 없어도 알아서 설치해 주는 도구라, 이 한 줄이면 해결됩니다.

### Step 3. 구축 프롬프트 — 네 칸으로 나눠 요청하기

```prompt
[맥락] 한국 주식 데이터를 분석하는 프로젝트를 시작할 거야.

[만들 것]
- 이 폴더에 Python 가상환경(.venv)을 만들고
  pandas, matplotlib, FinanceDataReader 3개를 설치해줘.
- check.py 파일 하나를 만들어서, 삼성전자(005930)의 최근 5거래일 일봉
  (날짜/시가/고가/저가/종가/거래량)을 표로 출력하게 해줘.

[하지 말 것]
- check.py 외에 다른 파일이나 폴더는 만들지 마.
  requirements.txt, README.md, setup 스크립트 전부 필요 없어.
- 주가 숫자를 코드에 직접 적어넣지 마. 반드시 조회한 결과만 출력해.
- 중간에 실패하면 혼자 우회하지 말고, 에러 메시지를 그대로 보여주고 멈춰.

[확인] 다 끝나면 설치된 3개 라이브러리 버전과 5행짜리 표만 보여줘.
```

#### 이 네 칸은 무엇이고, 왜 필요한가

**복사해서 붙여넣기 전에 이 표를 먼저 보세요.** 앞으로 이 강의의 모든 프롬프트가 이 구조를 따릅니다.

| 칸 | 하는 일 | 이 칸이 없으면 |
|---|---|---|
| **[맥락]** | AI에게 지금 무슨 일을 하는 중인지 알려줌 | AI가 용도를 추측해서 엉뚱한 방향으로 감 |
| **[만들 것]** | 완성됐을 때의 **결과물 모습**을 선언 | "알아서 잘" 만든 결과가 내가 원한 것과 다름 |
| **[하지 말 것]** | AI의 **작업 범위와 행동에 울타리**를 침 | AI가 요청하지 않은 파일을 잔뜩 만들고, 막히면 몰래 우회함 |
| **[확인]** | 내가 눈으로 검증할 **증거**를 요구 | "완료했습니다"라는 말만 남고 확인할 방법이 없음 |

특히 **[하지 말 것]**이 낯설게 느껴지실 겁니다. 이 칸은 제가 처음부터 넣은 게 아니라, **사고를 겪고 나서 추가한 칸**입니다. 라이브러리 3개만 요청했는데 AI가 22개를 적어 넣어 설치가 5분 넘게 걸린 적이 있고, 더 심각하게는 **AI가 주가를 못 가져오자 인터넷에서 대충 찾은 숫자를 코드에 적어 넣고 "완료했습니다"라고 보고한 적**이 있습니다.

**이 네 칸의 정식 이름과 작동 원리는 바로 다음 클립에서 제대로 배웁니다.** 지금은 "각 칸이 왜 있는지"만 이해하고 넘어가셔도 충분합니다.

### Step 4. 내 눈으로 확인할 체크리스트

AI가 "완료했습니다"라고 해도 **아직 끝난 게 아닙니다.** 아래 네 가지를 직접 확인하세요.

- [ ] **설치 완료**: 에러 없이 pandas, matplotlib, FinanceDataReader 세 개의 버전이 출력되었다.
- [ ] **표 출력**: 날짜/시가/고가/저가/종가/거래량 컬럼을 가진 **5행짜리** 표가 화면에 보인다.
- [ ] **파일이 하나뿐**: 폴더에 `check.py`와 `.venv` 말고 **내가 요청하지 않은 파일이 없다.**
- [ ] **숫자가 진짜다**: 포털에서 "삼성전자 주가"를 검색해, **표의 마지막 줄 종가와 실제 종가가 일치**한다.

## 자주 발생하는 문제 및 트러블슈팅

### 1. 진단 결과 "Python 없음"이라고 나올 때

정상입니다. 요즘 컴퓨터에는 Python이 기본으로 없습니다. Step 3의 `[만들 것]` 첫 줄에 아래를 추가하세요.

```prompt
uv를 사용해서 Python 3.12부터 설치해줘.
시스템에 이미 있는 python 명령어는 신뢰하지 말고 uv가 설치한 것만 사용해줘.
```

### 2. 설치가 되는 것 같더니 원인 모를 에러로 멈출 때 (Windows)

Microsoft Store 껍데기 Python에 걸린 경우입니다. 아래를 입력하세요.

```prompt
python 명령어가 WindowsApps 경로의 Microsoft Store 껍데기를 가리키고 있는지 확인해줘.
그렇다면 그건 무시하고, uv로 Python 3.12를 새로 설치한 뒤 가상환경을 다시 만들어줘.
```

### 3. 패키지 다운로드 중 타임아웃이 발생할 때

```prompt
패키지 다운로드 중 타임아웃이 발생했어.
설치 타임아웃 시간을 늘려서 다시 시도해줘.
```

### 4. 한글이 깨져서 표가 이상하게 보일 때 (Windows)

```prompt
출력에서 한글이 깨지고 있어. UTF-8 인코딩을 적용해서 다시 출력해줘.
```

### 5. 승인 버튼이 계속 뜰 때

Step 0-2의 모드 설정이 안 된 상태입니다. `Shift + Tab`을 눌러 `Edit automatically` 또는 `Auto`를 선택하세요. **이미 진행 중인 대화에서는 반영이 안 될 수 있으니, 모드를 바꾼 뒤 새 대화를 시작하시면 확실합니다.**
