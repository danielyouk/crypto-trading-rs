## 실습 — 실습 01: AI 도구 환경 구축

**오늘 만드는 것은 전체에서 어디인가**

앞으로 만들 트레이딩 시스템은 아무리 복잡해져도 결국 이 세 가지 위에 올라갑니다.

```
① 시세가 들어온다  →  ② 규칙이 판단한다  →  ③ 주문이 나간다
```

**①이 없으면 나머지는 존재할 수 없습니다.** 그래서 오늘은 ① 하나만, 가장 작게 확인합니다. 프로그래밍 입문의 첫 줄이 화면에 `Hello, World`를 찍는 것이라면, **우리의 첫 줄은 "시장아, 안녕?"** 입니다. 코드를 배우는 게 목적이 아니라 **진짜 시장 데이터가 내 화면까지 들어오는지 확인**하는 게 목적입니다.

오늘 만들 파일 이름이 `hello_market.py`인 이유가 그것입니다. 이건 시스템의 **심장박동을 확인하는 일**입니다.

### Step 1. 확장 설치와 자율권 모드 설정

#### 1-1. 편집기 준비 — 이 강의는 VS Code 기준입니다

> ✅ **아직 아무것도 안 깔려 있다면 [VS Code](https://code.visualstudio.com/)를 설치하세요.** 무료이고, 이 강의의 모든 화면이 VS Code 기준입니다.
>
> 이미 Cursor 같은 다른 편집기를 쓰고 계시다면 그대로 쓰셔도 됩니다. Claude Code 확장은 똑같이 동작합니다. 다만 화면 구성이 달라 안내와 다르게 보일 수 있습니다.

다운로드 페이지에 선택지가 여러 개 나오는데, **이것만 고르시면 됩니다.**

| | 고를 것 |
|---|---|
| **Windows** | **`User Installer`** 의 **`x64`** |
| **Mac** | 큰 파란 버튼(**`Universal`**) → 받은 파일을 **`응용 프로그램` 폴더로 드래그** |

> 💡 `System Installer`는 관리자 권한이 필요합니다. `Arm64`는 Copilot+ PC 같은 특수한 기기용이니, **헷갈리면 `x64`** 를 고르세요 — 반대로 고르면 아예 설치가 안 됩니다.

**잠깐 — 왜 앱이 아니라 확장을 쓰나**

Claude Code는 터미널, 데스크탑 앱, 편집기 확장 세 가지 얼굴을 갖고 있습니다. **셋 다 같은 엔진, 같은 요금제**를 씁니다. 그럼에도 이 강의가 확장을 고른 이유는 세 가지입니다.

> ⚠️ **오해 정정 두 가지**
> - **"터미널 설치는 Node.js를 따로 깔아야 한다"** — 예전 이야기입니다. 지금은 설치 파일 하나로 끝나며 Node.js가 필요 없습니다.
> - **"확장이 앱보다 토큰을 적게 쓴다"** — 사실이 아닙니다. 세 방식 모두 같은 엔진에 같은 사용량을 씁니다. 확장을 고르는 이유는 **비용이 아니라 검증 편의성**입니다.

**확장 설치 — 여기서부터가 오늘의 본론입니다**

1. VS Code를 실행합니다.
2. 왼쪽 사이드바의 **Extensions**(네모 블록 아이콘)를 클릭합니다.
3. 검색창에 **`Claude Code`**를 입력하고, Anthropic이 만든 확장을 **Install** 합니다.
4. 설치 후 나타난 Claude 아이콘을 클릭해 대화창을 열고, **로그인**합니다.

#### 1-2. 자율권 모드 설정 — AI에게 어디까지 맡길 것인가

프롬프트 입력창 **맨 아래에 현재 모드가 표시**되어 있습니다. 그걸 **클릭**하면 모드 목록이 뜹니다. (단축키 `Shift + Tab`으로도 열립니다.) 이건 **"AI가 뭘 할 때마다 나에게 물어볼 것인가"**를 정하는 스위치입니다.

| 모드 | 승인 없이 되는 것 | 승인을 계속 물어보는 것 |
|---|---|---|
| **Manual** | 없음 (파일 읽기만) | 편집, 명령 실행 전부 |
| **Plan** | 없음 — 고치지 않고 계획만 세워서 보고 | — |
| **Edit automatically** | **작업 폴더 안의 파일 편집**과 `mkdir`·`cp` 같은 파일 정리 명령 | **설치·실행 명령은 계속 물어봅니다** |
| **Auto** | **거의 전부.** 안전 검사(분류기)를 통과한 작업은 자동 진행 | 위험하다고 판단된 것만 |

**오늘은 `Auto`를 선택하세요.**

> ⚠️ **`Edit automatically`로는 부족합니다.** 이름 때문에 오해하기 쉬운데, 이 모드가 자동 승인하는 건 **파일 편집**입니다. 오늘 할 일 중 Python 설치, 가상환경 생성, 라이브러리 설치, 코드 실행은 전부 **명령 실행**이라 승인 버튼이 그대로 뜹니다. **`Auto`만이 그걸 없애줍니다.**

> 📌 **화면을 외우지 말고 목적을 기억하세요.** 편집기 종류, 운영체제, 확장 버전, 심지어 고른 모델에 따라 목록이 다르게 보입니다. **그래서 이 강의는 "몇 번째 항목을 고르세요"라고 말하지 않습니다.** 지금 우리가 하려는 건 "승인 버튼을 매번 안 누르게 만드는 것"이고, 그걸 해주는 항목을 **이름으로** 고르시면 됩니다. AI 도구는 화면이 자주 바뀝니다.
>
> **목록에 `Auto`가 없다면** `Edit automatically`를 고르고, 승인 창이 뜰 때마다 **`Yes, and don't ask again`(예, 다시 묻지 않기)** 을 누르세요. 처음 몇 번만 누르면 그 뒤로는 조용해집니다.

### Step 2. 작업 폴더 생성 및 열기

1. 원하는 위치(예: 바탕화면)에 **`ai-trading`** 폴더를 새로 만듭니다.
2. 편집기에서 `File` → `Open Folder`로 이 폴더를 엽니다.
3. Claude 대화창이 이 폴더를 작업 공간으로 인식했는지 확인합니다.

> 📌 **왜 폴더를 따로 만드나요?** AI가 만드는 파일이 다른 자료와 섞이지 않게 하기 위해서입니다. 뭔가 잘못돼도 이 폴더만 지우면 원상복구됩니다.

### Step 3. 진단 프롬프트 — 아무것도 설치하지 않고 상태만 확인

#### 그전에 — 왜 갑자기 파이썬 이야기가 나오나

우리가 만들 시스템은 **파이썬(Python)** 이라는 언어로 돌아갑니다. 주식 데이터를 가져오고 계산하는 도구가 이 언어에 가장 많이 만들어져 있기 때문입니다.

**여러분이 파이썬을 배우실 필요는 없습니다. 코드는 AI가 씁니다.** 다만 **그 코드가 실행되려면 컴퓨터에 파이썬이 깔려 있어야** 합니다. 요리로 치면 **레시피는 AI가 쓰고, 파이썬은 그 요리를 할 주방**입니다. 주방이 없으면 레시피가 아무리 좋아도 아무 일도 안 일어납니다.

그래서 오늘의 첫 질문은 이겁니다 — **"내 컴퓨터에 주방이 있나?"**

#### 진단 프롬프트

대화창에 아래를 입력합니다.

```prompt
아직 아무것도 설치하지 마. 진단만 해줘.

이 컴퓨터에서 파이썬이 실제로 실행되는지 확인해줘.
"설치돼 있다고 표시되는 것"이 아니라 "실제로 실행되는지"가 기준이야.

확인한 방법과 결과를 표 하나로 보여주고, 애매하면 애매하다고 말해줘.
```

**왜 이 단계가 따로 있을까요?** 한 번에 다 시키면, AI는 중간에 막혔을 때 멈추지 않고 **혼자 우회로를 찾습니다.** 그 우회가 잘못된 방향이면 우리는 한참 뒤에야 알아차립니다. 30초짜리 진단을 먼저 하면 갈림길이 눈에 보이고, 그 다음 요청이 훨씬 정확해집니다.

#### 가운데 한 줄이 오늘의 진짜 교훈입니다

```
"설치돼 있다고 표시되는 것"이 아니라 "실제로 실행되는지"가 기준이야.
```

**이 한 줄을 왜 넣었을까요?** Windows에는 **파이썬이 설치된 척하는 껍데기 프로그램**이 기본으로 들어 있습니다. 사람도 AI도 여기에 잘 속아서, "파이썬이 있다"고 판단하고 진행했다가 원인 모를 실패를 겪습니다. 실제로 이 강의를 준비하면서 여기서 10분을 날렸습니다.

그런데 **여러분이 가져가실 것은 그 껍데기 프로그램의 이름이 아닙니다.** 그건 Windows에만 있는 특수한 사정이고, 다음에 만날 함정은 또 다를 겁니다. 가져가실 것은 이 원칙입니다.

> 🎯 **"있다"가 아니라 "된다"를 물어보세요.**
>
> AI에게 정답을 미리 알려주는 게 아니라, **무엇을 기준으로 판단할지**를 알려주는 겁니다. 그러면 여러분이 모르는 함정도 AI가 대신 걸러냅니다.

이 원칙은 오늘 하루로 끝나지 않습니다. Step 5에서는 AI가 **"완료했습니다"** 라고 말한 것을 그대로 믿지 않고 포털 시세와 대조할 거고, Step 6에서는 AI가 쓴 코드를 **승인하기 전에** 직접 볼 겁니다. **전부 같은 원칙입니다.**

#### 진단 결과에 따라 갈리는 길

| 진단 결과 | 다음 Step 4에서 |
|---|---|
| Python **있음** | 아래 프롬프트를 그대로 사용 |
| Python **없음** | 아래 프롬프트의 `[만들 것]` 첫 줄에 **`uv를 사용해서 파이썬 3.12부터 설치해줘.`** 를 추가 |

> **`uv`** 는 **파이썬 설치와 라이브러리 관리를 대신해 주는 도구**입니다. 파이썬이 아예 없어도 uv가 알아서 깔아줍니다. 지금은 "그런 도구가 있다" 정도만 아시면 충분합니다.

### Step 4. 구축 프롬프트 — 네 칸으로 나눠 요청하기

```prompt
[맥락] 한국 주식 데이터를 분석하는 프로젝트를 시작할 거야.

[만들 것]
- 이 폴더 안에서만 쓰는 독립된 파이썬 환경을 만들어줘.
  내 컴퓨터 전체에는 아무것도 설치하지 마.
- 그 환경에 pandas, matplotlib, FinanceDataReader 3개를 설치해줘.
- hello_market.py 파일 하나를 만들어서, 삼성전자(005930)의 최근 5거래일 일봉
  (날짜/시가/고가/저가/종가/거래량)을 표로 출력하게 해줘.

[하지 말 것]
- 위에서 요청한 것 외에는 파일도 폴더도 만들지 마.
- 주가 숫자를 코드에 직접 적어넣지 마. 반드시 조회한 결과만 출력해.
- 중간에 실패하면 혼자 우회하지 말고, 에러 메시지를 그대로 보여주고 멈춰.

[확인] 다 끝나면 설치된 3개 라이브러리 버전과 5행짜리 표만 보여줘.
```

#### 이 네 칸은 무엇이고, 왜 필요한가

**복사해서 붙여넣기 전에 이 표를 먼저 보세요.** 앞으로 이 강의의 모든 프롬프트가 이 구조를 따릅니다.

| 칸 | 하는 일 | 이 칸이 없으면 |
|---|---|---|
| **[맥락]** | AI에게 지금 무슨 일을 하는 중인지 알려줌 | AI가 용도를 추측해서 엉뚱한 방향으로 감 |
| **[만들 것]** | 완성됐을 때의 **결과물 모습**을 선언 | "알아서 잘" 만든 결과가 내가 원한 것과 다름 |
| **[하지 말 것]** | AI의 **작업 범위와 행동에 울타리**를 침 | AI가 요청하지 않은 파일을 잔뜩 만들고, 막히면 몰래 우회함 |
| **[확인]** | 내가 눈으로 검증할 **증거**를 요구 | "완료했습니다"라는 말만 남고 확인할 방법이 없음 |

특히 **[하지 말 것]**이 낯설게 느껴지실 겁니다. 이 칸은 제가 처음부터 넣은 게 아니라, **사고를 겪고 나서 추가한 칸**입니다. 라이브러리 3개만 요청했는데 AI가 22개를 적어 넣어 설치가 5분 넘게 걸린 적이 있고, 더 심각하게는 **AI가 주가를 못 가져오자 인터넷에서 대충 찾은 숫자를 코드에 적어 넣고 "완료했습니다"라고 보고한 적**이 있습니다.

**이 네 칸의 정식 이름과 작동 원리는 바로 다음 클립에서 제대로 배웁니다.** 지금은 "각 칸이 왜 있는지"만 이해하고 넘어가셔도 충분합니다.

#### 왜 하필 이 종목, 이 기간, 이 라이브러리인가

프롬프트에 들어간 선택 하나하나에 이유가 있습니다. **이유를 알면 다음엔 여러분이 직접 바꿔 쓸 수 있습니다.**

| 선택 | 이유 |
|---|---|
| **삼성전자** | 누구나 포털에서 **1초 만에 실제 주가를 확인할 수 있는** 종목이라서. 오늘의 목적은 분석이 아니라 **대조**입니다. |
| **5거래일** | 화면에 한눈에 들어오면서, 눈으로 대조하기엔 충분한 최소량. 100줄이면 아무도 안 봅니다. |
| **라이브러리 3개** | 데이터 가져오기(FinanceDataReader) + 표로 다루기(pandas) + 나중에 그리기(matplotlib). **딱 필요한 최소 3개**라서, `[하지 말 것]`에 "더 설치하지 마"를 쓸 수 있습니다. |

#### 방금 생긴 `.venv` 폴더는 무엇인가

AI가 작업을 마치면 폴더에 **`.venv`** 라는 처음 보는 폴더가 하나 생겨 있을 겁니다. 프롬프트에 쓴 **"이 폴더 안에서만 쓰는 독립된 파이썬 환경"** 이 바로 저것입니다.

**왜 이게 필요한가 — 없으면 생기는 일**
라이브러리를 컴퓨터 전체에 깔면 이런 일이 생깁니다. A 프로젝트가 pandas 1.5를 쓰는데 B 프로젝트가 2.2를 요구합니다. B를 위해 버전을 올리면 **A가 조용히 망가집니다.** 그리고 A가 언제 망가졌는지는 몇 주 뒤에야 압니다.

**그래서 `.venv`가 하는 일**
`.venv`는 **이 폴더에서만 쓰는 전용 도구 상자**입니다. 여기 설치한 건 이 폴더 밖으로 나가지 않고, 밖에 있는 것도 여기 안 들어옵니다.

> ✅ **그래서 오늘 뭘 잘못 설치하셔도 괜찮습니다.** `.venv` 폴더 하나만 지우면 오늘 설치한 게 전부 사라지고 컴퓨터는 원래대로 돌아옵니다. **여러분 컴퓨터는 절대 더러워지지 않습니다.**

한 번 열어보세요. `.venv` 안쪽 **`site-packages`** 폴더에 방금 설치한 `pandas`가 실제로 들어 있습니다. (Windows는 `.venv` → `Lib` → `site-packages`, Mac은 `.venv` → `lib` → `python3.12` → `site-packages`) **"설치한 게 어디로 갔나"** 가 눈으로 해결됩니다.

> 📌 이름 앞에 점(`.`)이 붙은 폴더는 **"건드리지 마세요"** 라는 표시입니다. 직접 열어볼 일은 오늘 이 한 번뿐입니다.

### Step 5. 내 눈으로 확인할 체크리스트

AI가 "완료했습니다"라고 해도 **아직 끝난 게 아닙니다.** 아래 네 가지를 직접 확인하세요.

- [ ] **설치 완료**: 에러 없이 pandas, matplotlib, FinanceDataReader 세 개의 버전이 출력되었다.
- [ ] **표 출력**: 날짜/시가/고가/저가/종가/거래량 컬럼을 가진 **5행짜리** 표가 화면에 보인다.
- [ ] **파일이 하나뿐**: 폴더에 `hello_market.py`와 `.venv` 말고 **내가 요청하지 않은 파일이 없다.**
- [ ] **숫자가 진짜다**: 포털에서 "삼성전자 주가"를 검색해, **표의 마지막 줄 종가와 실제 종가가 일치**한다.

> 🔍 **마지막 항목이 오늘의 진짜 시험입니다.** 앞의 세 개는 화면만 보면 알 수 있지만, 마지막 하나는 **다른 창을 열어야만** 알 수 있습니다. 이 강의 전체를 관통하는 습관이니 지금 몸에 익히세요.

### Step 6. 승인 화면 직접 만나보기 — AI 코드를 내 손으로 고치기

지금까지는 **속도를 위해 AI에게 자율권을 줬습니다.** 이제 반대쪽을 한 번 경험해 봅시다. 이 강의에서 가장 중요한 습관이 여기서 만들어집니다.

**1)** 프롬프트 입력창 맨 아래의 모드 표시를 클릭해 **`Manual`** 로 바꿉니다.

**2)** 대화창에 입력합니다.

```prompt
hello_market.py에 최근 5일 종가의 평균을 계산해서
표 아래에 한 줄로 출력하는 코드를 추가해줘.
```

**3)** 이번엔 코드가 바로 바뀌지 않고 **좌우 비교 화면(diff)** 이 뜹니다.

이 화면이 **어디에** 열리는지가 헷갈리기 쉽습니다. Claude 대화창이 아니라, **가운데 편집기 영역에 새 탭으로** 열리고 그 탭 안이 다시 좌우로 쪼개집니다.

```
┌──────────┬────────────────────────────────────┬─────────────┐
│ 파일탐색기 │        편집기 영역 (가운데)          │ Claude 대화창 │
│          │ ┌──────────────┬─────────────────┐ │             │
│          │ │  원본         │  AI 제안        │ │  ← 항상     │
│          │ │  (왼쪽)       │  (오른쪽)       │ │    맨 오른쪽 │
│          │ │  읽기 전용     │  편집 가능      │ │             │
│          │ └──────────────┴─────────────────┘ │             │
└──────────┴────────────────────────────────────┴─────────────┘
                   ↑ diff는 여기 새 탭으로 열립니다
```

왼쪽이 지금 내 파일, 오른쪽이 AI가 제안한 것입니다. **초록색이 새로 추가될 줄**입니다.

**4) 여기가 오늘의 핵심입니다.** 승인 버튼을 누르기 전에, **오른쪽 칸에 커서를 놓고 직접 타이핑해서 고쳐보세요.**

예를 들어 출력 문구를 이렇게 바꿔봅니다.

```
평균 종가:        →   5일 평균 종가(원):
```

**AI가 쓴 코드는 읽기 전용이 아닙니다.** 승인 전에 내가 먼저 손댈 수 있습니다.

**5)** 이제 승인합니다. Claude는 **여러분이 손을 댔다는 사실을 인지합니다.** 자기가 제안한 그대로라고 착각하지 않고, 여러분이 고친 버전을 기준으로 다음 작업을 이어갑니다.

> 🎯 **방금 무슨 일이 있었나요?**
>
> AI가 초안을 쓰고, **사람이 최종 결정을 했습니다.** 이게 이 강의가 5개 파트 내내 지킬 자세입니다.
>
> 그리고 이제 아실 겁니다 — **`Auto`는 속도를 얻는 대신 이 화면을 포기하는 선택입니다. 공짜가 아닙니다.**
>
> 앞으로 **중요한 판단이 들어간 코드는 `Manual`로 내려서** 이 화면을 보세요. 설치나 반복 작업은 `Auto`로 올리고요. **모드를 왔다 갔다 하는 게 정상입니다.** 한 번 정하고 끝나는 설정이 아닙니다.

## 자주 발생하는 문제 및 트러블슈팅

### 1. 진단 결과 "Python 없음"이라고 나올 때

정상입니다. 요즘 컴퓨터에는 Python이 기본으로 없습니다. Step 4의 `[만들 것]` 첫 줄에 아래를 추가하세요.

```prompt
uv를 사용해서 Python 3.12부터 설치해줘.
시스템에 이미 있는 python 명령어는 신뢰하지 말고 uv가 설치한 것만 사용해줘.
```

### 2. 설치가 되는 것 같더니 원인 모를 에러로 멈출 때 (Windows)

Microsoft Store 껍데기 Python에 걸린 경우입니다. 아래를 입력하세요.

```prompt
python 명령어가 WindowsApps 경로의 Microsoft Store 껍데기를 가리키고 있는지 확인해줘.
그렇다면 그건 무시하고, uv로 Python 3.12를 새로 설치한 뒤 가상환경을 다시 만들어줘.
```

### 3. 패키지 다운로드 중 타임아웃이 발생할 때

```prompt
패키지 다운로드 중 타임아웃이 발생했어.
설치 타임아웃 시간을 늘려서 다시 시도해줘.
```

### 4. 한글이 깨져서 표가 이상하게 보일 때 (Windows)

```prompt
출력에서 한글이 깨지고 있어. UTF-8 인코딩을 적용해서 다시 출력해줘.
```

### 5. 승인 버튼이 계속 뜰 때

모드가 **`Auto`가 아닌 상태**입니다. `Edit automatically`로는 해결되지 않습니다 — 그 모드는 파일 편집만 자동 승인하고, 설치·실행 명령은 계속 물어보기 때문입니다.

프롬프트 입력창 아래 모드 표시를 클릭해 **`Auto`** 를 고르세요. 목록에 `Auto`가 없다면 `Edit automatically`를 고른 뒤 승인 창에서 **`Yes, and don't ask again`** 을 누르시면 됩니다. **이미 진행 중인 대화에서는 반영이 안 될 수 있으니, 모드를 바꾼 뒤 새 대화를 시작하시면 확실합니다.**

### 6. Step 6에서 좌우 비교 화면이 안 뜰 때

모드가 아직 `Auto` 또는 `Edit automatically`입니다. 이 두 모드는 **묻지 않고 바로 고치기 때문에** 비교 화면이 나타나지 않습니다. 모드를 **`Manual`** 로 바꾼 뒤 다시 요청하세요.
