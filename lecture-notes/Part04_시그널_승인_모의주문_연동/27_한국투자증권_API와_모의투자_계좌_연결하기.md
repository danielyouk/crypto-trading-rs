# 한국투자증권 API와 모의투자 계좌 연결하기

## 이번 클립에서 만들 것

한국투자증권 모의투자 계좌를 만들고 API 키를 받은 뒤, 내 계좌의 예수금(아직 주식을 사지 않은 현금)과 잔고를 프로그램으로 조회합니다.

> 💡 실제 돈이 아니라 가상의 돈이 들어 있는 **모의투자 계좌**로 진행하므로 금전적 위험이 없습니다.

- 화면 캡처로 따라 하는 모의투자 계좌와 API 키 발급
- 키를 코드와 떼어 `.env`에 보관하기
- **실습 15**: `kis_auth.py` 작성 및 잔고 조회

---

## 이론 핵심

### 1. 출입증을 받고, 요청마다 보여 줍니다

```text
[내 프로그램] ──> ① App Key + App Secret을 증권사에 보냄
              <── ② 24시간 쓰는 접근 토큰(출입증)을 받음
              ──> ③ 잔고·시세·주문을 요청할 때마다 출입증을 함께 보냄
```

**App Key·App Secret**은 증권사가 내 프로그램에 내주는 아이디와 비밀번호입니다.

---

### 2. 서버 주소와 거래 코드는 AI가 공식 자료에서 찾게 합니다

증권사 API는 잔고 조회, 현재가, 주문 같은 기능마다 **거래 코드**(기능을 부르는 이름표)가 있고, 모의투자와 실전은 서버 주소와 거래 코드가 다릅니다. AI가 기억하는 값은 예전 것일 수 있어서(주문 코드는 2025년에 바뀌었습니다), 프롬프트에는 값 대신 **"공식 자료에서 확인하고 출처를 알려 달라"**고 적습니다.

- 공식 자료: KIS Developers 첫 화면(캡처 5)의 [API 문서] 메뉴와 [GITHUB] 아이콘(공식 예제 코드)
- 내가 확인할 것: 출처가 이 두 곳인지, 서버 주소에 모의투자를 뜻하는 `vts`가 있는지, 거래 코드가 `V`로 시작하는지

---

### 3. 비밀 값은 `.env`에 따로 둡니다

키를 코드에 직접 적으면, 코드를 인터넷(GitHub 등)에 올릴 때 키도 함께 공개됩니다. 그래서 키는 `.env` 파일에만 적고 코드는 실행할 때 거기서 읽어 옵니다. `.gitignore` 파일에 `.env`를 적어 두면 코드를 올릴 때 `.env`는 빠집니다.

## 실습 — 실습 15: KIS API 인증 및 계좌 잔고 조회

### Step 1. 모의투자 계좌 만들고 API 키 발급받기 (웹 브라우저)

**모의투자 계좌**(가상의 돈으로 주문을 연습하는 계좌)를 먼저 만들고, 그 계좌번호로 **API 키**를 신청합니다. API 신청 화면이 모의투자 계좌번호를 넣으라고 하기 때문입니다.

| 순서 | 하는 곳 | 끝나면 손에 쥐는 것 |
|---|---|---|
| 1-1 ~ 1-3 | 한국투자증권 홈페이지 → 모의투자 | 모의투자 계좌번호 8자리 |
| 1-4 ~ 1-6 | KIS Developers 서비스 신청 | App Key, App Secret |

> 💡 **화면은 바뀔 수 있습니다.** 아래 캡처는 2026년 9월에 찍은 화면입니다. 증권사 홈페이지와 KIS Developers는 메뉴 이름, 버튼 위치, 신청 절차가 수시로 바뀝니다. 캡처와 다르면 같은 이름의 메뉴나 버튼을 찾고, 그래도 보이지 않으면 홈페이지 검색창에 '모의투자'나 'KIS Developers'를 검색하세요. 화면이 바뀌어도 이 단계에서 손에 쥐어야 할 것(모의투자 계좌번호 8자리, App Key, App Secret)은 같습니다.

> **준비물**: 한국투자증권 계좌와 홈페이지 로그인 ID. 없으면 '한국투자' 앱에서 비대면으로 먼저 만드세요. 한국투자증권의 Open API 공식 안내도 "계좌 개설 및 ID 연결"을 첫 단계로 둡니다. 계좌 개설은 앱 안내를 그대로 따르면 되므로 여기서는 다루지 않습니다.

### Step 2. `.env` 파일 직접 만들기

키는 AI에게 건네지 않고 **내 손으로 직접** 파일에 적습니다. 채팅창에 붙여 넣으면 대화 기록에 남기 때문입니다.

1. VS Code 왼쪽 탐색기에서 작업 폴더 바로 안에 `.env` 파일을 만듭니다.
2. 아래 내용을 붙여 넣고 값을 내 것으로 바꿔 저장합니다.

```env
# Step 1에서 복사한 App Key와 App Secret
KIS_APP_KEY=PSxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
KIS_APP_SECRET=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
# 모의투자 계좌번호 앞 8자리와 뒤 2자리(보통 01)
KIS_CANO=50123456
KIS_ACNT_PRDT_CD=01
# 모의투자 계좌라는 내 확인. True가 아니면 프로그램이 요청을 보내지 않음
KIS_IS_PAPER=True
```

**`KIS_IS_PAPER`는 안전장치입니다.** `True`일 때만 요청이 나가고, `False`로 바꾼다고 실전 서버로 넘어가지는 않습니다. 파일 한 줄로 진짜 돈이 오가게 되면 안전장치가 아니라 스위치이기 때문입니다.

## 자주 발생하는 문제

- **"유효하지 않은 AppKey입니다"(EGW00103) / "유효하지 않은 AppSecret입니다"(EGW00105) 에러**: 실전용 키와 모의투자용 키는 서로 다릅니다. KIS Developers 신청현황 표에서 **구분이 '모의투자계좌'인 줄**의 [복사] 버튼으로 가져온 키인지 확인하세요.
- **API 신청 때 "이미 등록된 계좌번호입니다."가 뜨는데 신청현황에는 없을 때**: KIS Developers 서비스 신청의 1단계 휴대폰 인증 화면에서 'ID변경 전 신청정보 삭제'를 한 뒤 다시 신청합니다. 신청정보 화면 아래 유의사항에 적힌 방법입니다.
- **접속 주소·포트 오류**: 모의투자는 `https://openapivts.koreainvestment.com:29443` (포트 29443)을 사용해야 합니다.
