## 이론 핵심

### 1. 증권사 Open API 인증 흐름

한국투자증권 Open API는 **먼저 출입증을 받고, 그 뒤 모든 요청에 그 출입증을 보여 주는** 방식입니다.

```text
[내 컴퓨터 / Python] 
   ──> ① App Key + App Secret을 증권사 인증 서버에 보냄 (데이터를 실어 보내는 요청: POST)
   <── ② 24시간 유효한 접근 토큰('access_token') 수신
   ──> ③ 시세·잔고·주문을 요청할 때마다 요청에 붙는 머리말(헤더)에 "Bearer 접근 토큰"을 적어 보냄
```

이렇게 주소마다 요청을 보내고 답을 받는 방식을 REST API라고 부르고, Bearer는 "이 출입증을 가진 사람의 요청"이라는 표시입니다. 이름은 외우실 필요 없습니다. **출입증 받기 → 요청마다 출입증 보여 주기** 흐름만 기억하시면 됩니다.

---

### 2. 서버 주소와 거래 코드는 AI가 공식 자료에서 찾게 합니다

증권사 API는 잔고 조회, 현재가, 주문 같은 기능마다 **거래 코드**(기능을 부르는 이름표)가 붙어 있고, 모의투자와 실전투자는 서버 주소와 거래 코드가 다릅니다. 이 값들은 외우거나 프롬프트에 적을 필요가 없습니다. 다만 AI가 기억하는 값은 예전 것일 수 있습니다. 실제로 한국투자증권의 주문 거래 코드는 2025년에 바뀌었습니다.

그래서 프롬프트에는 값 대신 **"공식 자료에서 확인해서 쓰고, 출처를 알려 달라"**고 적습니다. 공식 자료는 두 곳입니다.

- **KIS Developers의 API 문서**: KIS Developers 첫 화면(캡처 5) 위쪽의 [API 문서] 메뉴
- **한국투자증권 공식 GitHub 예제**: 같은 화면의 [GITHUB] 아이콘. 기능별 예제 코드가 모여 있습니다

AI가 알려 준 것 가운데 내가 확인할 것은 세 가지입니다. 출처가 이 두 곳인지, 서버 주소에 모의투자를 뜻하는 `vts`가 들어 있는지, 거래 코드가 모의투자용(대부분 `V`로 시작)인지입니다.

---

### 3. 보안 제1원칙: 비밀 값은 `.env`에 따로

API 키를 파이썬 코드 안에 직접 적어 두면, 나중에 코드를 인터넷(코드 공유 사이트인 GitHub 등)에 올렸을 때 키도 함께 공개되는 심각한 보안 사고가 납니다. 그래서 키는 `.env`에만 적고, 코드는 실행할 때 거기서 읽어 오게 합니다. 코드 변경 기록을 관리하는 도구(Git)를 쓴다면, `.gitignore`라는 파일에 `.env`를 적어 두어 코드를 올릴 때 `.env`는 따라 올라가지 않게 막습니다.

```text
ai-trading/
├── .env                  # [보안 절대 파일] 키와 계좌번호 보관. 내가 직접 만든다
├── .gitignore            # 코드를 올릴 때 .env는 빠지도록 막는 설정
├── kis_auth.py           # dotenv 라이브러리로 .env의 값을 읽어서 사용
```

### Step 2. `.env` 파일 직접 만들기

키는 AI에게 건네지 않고 **내 손으로 직접** 파일에 적습니다. 채팅창에 키를 붙여넣으면 그 순간 대화 기록에 남기 때문입니다. 그래서 다음 Step의 프롬프트는 `.env`가 이미 채워져 있다고 보고 시작합니다.

1. VS Code 왼쪽 탐색기에서 작업 폴더 바로 안에 새 파일을 만들고, 이름을 `.env`로 적습니다.
2. 아래 내용을 붙여 넣고 값을 내 것으로 바꾼 뒤 저장합니다. `#`으로 시작하는 줄은 설명이라 그대로 두셔도 됩니다.

```env
# Step 1에서 발급받은 App Key와 App Secret
KIS_APP_KEY=PSxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
KIS_APP_SECRET=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
# 계좌번호 앞 8자리 (종합계좌번호)
KIS_CANO=50123456
# 계좌번호 뒤 2자리 (상품코드). 주식 계좌는 보통 01
KIS_ACNT_PRDT_CD=01
# 이 계좌가 모의투자 계좌라는 내 확인. True가 아니면 코드가 요청을 보내지 않고 멈춤
KIS_IS_PAPER=True
```

**`KIS_IS_PAPER`는 안전장치입니다.** 코드는 이 값이 `True`일 때만 증권사에 요청을 보내고, 그 밖의 값이면 아무 요청도 보내지 않고 멈춥니다. 반대로 `False`로 바꾼다고 실전 서버로 넘어가지는 않습니다. 파일 한 줄만 바꿔서 진짜 돈이 오가게 된다면 그건 안전장치가 아니라 스위치이기 때문입니다. 이 확인은 `kis_auth.py`의 공용 요청 함수 안에 들어가므로, 이 함수로 요청을 보내는 코드는 모두 같은 확인을 거칩니다.

### Step 3. Claude Code에게 연동 모듈 작성 요청

Claude Code 대화창에 아래 프롬프트를 입력하세요.

```prompt
[맥락] 한국투자증권(KIS) 모의투자 Open API와 연동하여 계좌 잔고를 조회하는 모듈을 만들고 싶어. 작업 폴더의 .env 파일은 내가 직접 만들어서 KIS_APP_KEY, KIS_APP_SECRET, KIS_CANO, KIS_ACNT_PRDT_CD, KIS_IS_PAPER 값을 채워 두었어. 증권사 서버 주소, 접근 토큰을 받는 주소, 거래 코드(잔고 조회·주문 같은 기능마다 붙은 이름표)는 KIS Developers의 API 문서나 한국투자증권 공식 GitHub 예제(koreainvestment/open-trading-api)에서 확인해서 쓰고, 어디서 확인했는지 알려줘. 모의투자와 실전투자는 서버 주소와 거래 코드가 달라.

[만들 것] 다음 조건에 맞춰 파이썬 스크립트 'kis_auth.py'를 작성하고 실행해줘:
1. python-dotenv와 requests 라이브러리가 있는지 확인하고, 없으면 설치해줘.
2. 코드가 실행할 때 .env에서 위 다섯 값을 읽어 오도록 구현해줘. 빠졌거나 비어 있는 값이 있으면 그 키 이름만 알려주고 멈춰.
3. 이 계좌로 보내는 모든 API 요청이 거쳐 가는 공용 요청 함수를 kis_auth.py에 만들어줘. 이 함수는
   - KIS_IS_PAPER가 True이고 보내는 주소가 KIS 모의투자 서버일 때만 요청을 보내고, 아니면 아무것도 보내지 말고 이유를 알려주며 멈춰.
   - 모의투자 서버의 요청 한도(정해진 시간에 보낼 수 있는 요청 수)를 공식 자료에서 확인해, 그 한도를 넘지 않게 요청 사이에 간격을 두고 보내줘.
4. 공용 요청 함수로 모의투자 서버에 요청을 보내 접근 토큰(access_token, 로그인 뒤 증권사가 내주는 출입증)을 받아줘.
5. 받은 접근 토큰으로 주식 잔고 조회 API를 공용 요청 함수로 호출하여 내 계좌의 총 예수금(아직 주식을 사지 않은 현금), 총 평가금액, 총 손익률을 대화창에 요약 표로 출력해줘.

[하지 말 것]
- 공식 자료에서 확인하지 못한 서버 주소나 거래 코드를 기억이나 짐작으로 채우지 마. 찾지 못하면 멈추고 알려줘.
- .env 파일을 새로 만들거나 고치지 마. 열어서 내용을 읽거나 화면에 출력하지도 마. 값은 코드가 실행될 때만 읽어.
- App Key, App Secret, 계좌번호를 코드 안에 직접 적지 마.
- KIS_IS_PAPER 값에 따라 실전투자 서버로 바꿔 보내는 기능을 만들지 마. 이 강의는 끝까지 모의투자 서버만 사용해.
- 인증이나 조회에 실패하면 예수금 숫자를 지어내지 말고, 에러 코드와 메시지를 그대로 보여주고 멈춰.

[확인]
- 대화창에 내 모의투자 계좌의 예수금 요약표가 출력되어 정상 연결이 증명되었는지 확인해줘.
- 코드에 쓴 서버 주소와 거래 코드, 그리고 각각을 확인한 출처를 표로 보여줘.
- .env를 고치지 않은 채로 KIS_IS_PAPER가 True가 아닌 경우를 만들어 실행해서, 증권사에 요청을 보내지 않고 멈추는지 보여줘.
- 나중에 코드를 인터넷에 올리더라도 .env는 따라 올라가지 않게 막는 설정(Git을 쓴다면 .gitignore)에 .env가 들어 있는지 확인하고, 없으면 추가해줘.
```

### 내 눈으로 확인할 체크리스트

- [ ] `.env`는 내가 직접 만들었고, 대화창에 App Key·App Secret이 한 번도 나오지 않았다.
- [ ] 화면에 모의투자 계좌의 예수금(아직 주식을 사지 않은 현금)과 잔고 표가 출력되었다.
- [ ] `KIS_IS_PAPER`가 `True`가 아닐 때 요청을 보내지 않고 멈추는 것을 확인했다.
- [ ] AI가 쓴 서버 주소와 거래 코드의 출처가 KIS Developers 문서나 공식 GitHub 예제였다.

## 자주 발생하는 문제

- **"유효하지 않은 AppKey입니다"(EGW00103) / "유효하지 않은 AppSecret입니다"(EGW00105) 에러**: 실전용 키와 모의투자용 키는 서로 다릅니다. KIS Developers 신청현황 표에서 **구분이 '모의투자계좌'인 줄**의 [복사] 버튼으로 가져온 키인지 확인하세요.
- **API 신청 때 "이미 등록된 계좌번호입니다."가 뜨는데 신청현황에는 없을 때**: KIS Developers 서비스 신청의 1단계 휴대폰 인증 화면에서 'ID변경 전 신청정보 삭제'를 한 뒤 다시 신청합니다. 신청정보 화면 아래 유의사항에 적힌 방법입니다.
- **접속 주소·포트 오류**: 모의투자는 `https://openapivts.koreainvestment.com:29443` (포트 29443)을 사용해야 합니다.
