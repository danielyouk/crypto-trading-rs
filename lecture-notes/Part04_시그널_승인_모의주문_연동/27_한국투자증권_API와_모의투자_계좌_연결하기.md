- KIS Developers 포털에서 모의투자 계좌 등록 및 App Key·App Secret(증권사가 내 프로그램에 내주는 아이디와 비밀번호) 발급 3단계 가이드
- 인증 정보 보안의 절대 규칙: `.env` 파일 관리, 그리고 나중에 코드를 인터넷에 올리더라도 `.env`는 따라 올라가지 않게 막는 설정(`.gitignore`)
- 접근 토큰(`access_token`, 유효기간 약 24시간) 발급과 만료 전 자동 재발급 원리
- **실습 15**: `kis_auth.py` 작성 및 모의투자 계좌 잔고(예수금, 평가손익) 조회 검증. 평가손익은 지금 가격에 판다고 쳤을 때의 이익·손실로, 아직 확정된 것은 아닙니다

## 이론 핵심

### 1. 증권사 Open API 인증 흐름

한국투자증권 Open API는 **먼저 출입증을 받고, 그 뒤 모든 요청에 그 출입증을 보여 주는** 방식입니다.

```text
[내 컴퓨터 / Python] 
   ──> ① App Key + App Secret을 증권사 인증 서버에 보냄 (데이터를 실어 보내는 요청: POST)
   <── ② 24시간 유효한 접근 토큰('access_token') 수신
   ──> ③ 시세·잔고·주문을 요청할 때마다 요청에 붙는 머리말(헤더)에 "Bearer 접근 토큰"을 적어 보냄
```

이렇게 주소마다 요청을 보내고 답을 받는 방식을 REST API라고 부르고, Bearer는 "이 출입증을 가진 사람의 요청"이라는 표시입니다. 이름은 외우실 필요 없습니다. **출입증 받기 → 요청마다 출입증 보여 주기** 흐름만 기억하시면 됩니다.

---

### 2. 보안 제1원칙: 비밀 값은 `.env`에 따로

API 키를 파이썬 코드 안에 직접 적어 두면, 나중에 코드를 인터넷(코드 공유 사이트인 GitHub 등)에 올렸을 때 키도 함께 공개되는 심각한 보안 사고가 납니다. 그래서 키는 `.env`에만 적고, 코드는 실행할 때 거기서 읽어 오게 합니다. 코드 변경 기록을 관리하는 도구(Git)를 쓴다면, `.gitignore`라는 파일에 `.env`를 적어 두어 코드를 올릴 때 `.env`는 따라 올라가지 않게 막습니다.

```text
ai-trading/
├── .env                  # [보안 절대 파일] APP_KEY, APP_SECRET, CANO 등 보관
├── .gitignore            # 코드를 올릴 때 .env는 빠지도록 막는 설정
├── kis_auth.py           # dotenv 라이브러리로 .env의 값을 읽어서 사용
```

```env
# .env 파일 예시
KIS_APP_KEY=PSxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
KIS_APP_SECRET=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
KIS_CANO=50123456
KIS_ACNT_PRDT_CD=01
KIS_IS_PAPER=True
```

## 실습 — 실습 15: KIS API 인증 및 계좌 잔고 조회

### Step 1. 모의투자 API 키 발급 (웹 브라우저)
1. [한국투자증권 KIS Developers](https://apiportal.koreainvestment.com/)에 접속하여 로그인합니다.
2. 한국투자증권 홈페이지 → 트레이딩 → Open API → KIS Developers → **KIS Developers 서비스 신청하기**에서 모의투자 계좌로 앱을 등록하고 **App Key**와 **App Secret**을 발급받습니다.
3. 내 모의투자 계좌번호 8자리(CANO)와 상품코드 2자리(01)를 확인합니다.

---

### Step 2. Claude Code에게 연동 모듈 작성 요청

Claude Code 대화창에 아래 프롬프트를 입력하세요.

```prompt
[맥락] 한국투자증권(KIS) 모의투자 Open API와 연동하여 계좌 잔고를 조회하는 모듈을 만들고 싶어.

[만들 것] 다음 조건에 맞춰 파이썬 스크립트 'kis_auth.py'를 작성하고 실행해줘:
1. python-dotenv와 requests 라이브러리가 있는지 확인하고, 없으면 설치해줘.
2. 값을 채워 넣을 빈 칸만 있는 .env 파일 양식을 만들고, 내가 채워 넣은 KIS_APP_KEY, KIS_APP_SECRET, KIS_CANO, KIS_ACNT_PRDT_CD 값을 코드가 실행할 때 .env에서 읽어 오도록 구현해줘.
3. KIS 모의투자 서버(https://openapivts.koreainvestment.com:29443)의 출입증 발급 창구 주소(/oauth2/tokenP)로 요청을 보내 접근 토큰(access_token, 로그인 뒤 증권사가 내주는 출입증)을 받아줘.
4. 받은 접근 토큰으로 '주식 잔고조회' API(모의투자용 거래 코드 VTTC8434R)를 호출하여 내 계좌의 총 예수금(아직 주식을 사지 않은 현금), 총 평가금액, 총 손익률을 대화창에 요약 표로 출력해줘.
5. 이 계좌로 보내는 모든 API 요청이 직전 요청과 최소 1초 간격을 두도록 기다려 주는 공용 요청 함수를 kis_auth.py에 만들어 두고, 4번 조회도 이 함수로 보내줘. 모의투자 서버는 계좌당 초당 1회만 요청을 받아.

[하지 말 것]
- App Key, App Secret, 계좌번호를 코드 안에 직접 적지 마. 반드시 .env에서만 읽어.
- .env 파일의 내용을 화면에 출력하지 마. 나중에 코드를 인터넷에 올리더라도 .env는 따라 올라가지 않게 막는 설정(Git을 쓴다면 .gitignore)에 .env가 들어 있는지 확인해.
- 실전투자 서버 주소를 쓰지 마. 이 강의는 끝까지 모의투자 서버만 사용해.
- 인증이나 조회에 실패하면 예수금 숫자를 지어내지 말고, 에러 코드와 메시지를 그대로 보여주고 멈춰.

[확인] 대화창에 내 모의투자 계좌의 예수금 요약표가 출력되어 정상 연결이 증명되었는지, 그리고 'kis_auth.py'와 '.env' 파일이 생성되었는지 확인해줘.
```

### 내 눈으로 확인할 체크리스트

- [ ] `.env` 파일에 모의투자 키와 계좌번호가 저장되었다.
- [ ] `kis_auth.py`를 실행하니 접근 토큰(출입증)이 에러 없이 발급되었다.
- [ ] 화면에 모의투자 계좌의 예수금(아직 주식을 사지 않은 현금)과 잔고 표가 출력되었다.

## 자주 발생하는 문제

- **"유효하지 않은 AppKey/Secret" 에러 (EGW00133)**: 실전용 키와 모의투자용 키가 다릅니다. KIS Developers 포털에서 [모의투자] 탭에서 발급받은 키인지 확인하세요.
- **접속 주소·포트 오류**: 모의투자는 `https://openapivts.koreainvestment.com:29443` (포트 29443)을 사용해야 합니다.
