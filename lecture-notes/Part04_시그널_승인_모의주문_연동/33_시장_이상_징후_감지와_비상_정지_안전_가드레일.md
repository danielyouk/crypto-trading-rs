# 시장 이상 징후 감지와 비상 정지 안전 가드레일

## 이번 클립에서 만들 것

이 클립이 끝나면, 여러분은 증권사 API 응답 지연(Timeout), 네트워크 단절, 비정상적인 주가 급변(Flash Crash), 또는 시스템 버그로 인한 무한 주문 폭주(Order Spooling) 같은 치명적인 돌발 사태를 실시간으로 감지하고, **'원터치 비상 정지 킬 스위치(Kill-Switch)'**를 통해 1초 만에 전체 시스템을 안전 모드로 동결하는 비상 대응 인프라를 완성하게 됩니다.

> 💡 **나이트 캐피털(Knight Capital) 파산 사건의 교훈**: 2012년 미국의 대형 투자사 나이트 캐피털은 알고리즘 버그로 45분 만에 4억 4천만 달러(약 5,000억 원)의 무차별 주문이 나가 파산했습니다. 비상 정지 킬 스위치는 모든 시스템 트레이더의 **'비상 탈출 버튼'**입니다.

- **3대 시스템 비상 징후**: API 3회 연속 타임아웃, 비정상 호가 공백, 주문 빈도 초과(초당 5회 이상 발주 감지)
- **파일 기반 킬 스위치(`kill_switch.flag`)**의 원리와 작동 메커니즘
- 원격 또는 로컬에서 언제든지 킬 스위치를 트리거하는 긴급 스크립트(`kill_switch.py`)
- **실습 21**: 킬 스위치 발동 테스트 및 시스템의 즉각적인 안전 동결(Freeze) 검증

## 이론 핵심

### 1. 킬 스위치(Kill-Switch)의 작동 원리

복잡한 네트워크 통신이나 웹소켓이 끊겨도, **로컬 파일 시스템에 특정 플래그 파일(`kill_switch.flag`)이 존재하는지 검사하는 방식**이 가장 신뢰성 높은 비상 정지 기법입니다.

```text
[실행 루프 (매 초마다 감시)]
if os.path.exists("kill_switch.flag"):
    logger.critical("🚨 긴급 킬스위치 감지! 모든 신규 주문 즉각 차단 및 안전 종료!")
    sys.exit(1)
```

## 실습 — 실습 21: 비상 정지 킬 스위치 구축 및 테스트

Claude Code 대화창에 아래 프롬프트를 입력하세요.

```prompt
시스템의 안전을 보장하는 비상 정지 킬 스위치 모듈 'kill_switch.py'와 가드레일 모듈을 작성해줘. (Context)

다음 요구사항에 맞춰 파이썬 스크립트를 작성하고 실행해줘: (Deliverable)
1. 'kill_switch.py': 실행 시 'kill_switch.flag' 파일을 생성하고, 현재 계좌의 미체결 주문을 전량 취소하며 비상 정지 사유를 로그에 기록해줘.
2. 모든 무인 실행 스크립트(execute_orders.py, realtime_signals.py)의 최상단에 'kill_switch.flag' 존재 여부를 검사하는 가드레일 함수 'check_emergency_stop()'을 추가해줘.
3. 킬 스위치가 활성화되어 있을 때는 어떤 주문도 증권사로 나가지 않고 'EMERGENCY_STOPPED' 에러와 함께 즉시 종료되도록 테스트해줘.
4. 비상 상황 해제 명령어(플래그 삭제 함수)도 함께 제공해줘.

실행 완료 후 킬 스위치 생성 ➔ 발주 차단 ➔ 킬 스위치 해제 3단계 동작 검증 로그를 터미널에 보여줘. (Verification)
```
