# 사람 개입 없는 자동 하드 손절과 서킷브레이커 구현

## 이번 클립에서 만들 것

이 클립이 끝나면, 여러분은 장중 주가가 급락하거나 계좌에 예상치 못한 손실이 누적될 때, 사람의 승인이나 메신저 확인을 전혀 묻지 않고 코드 레벨에서 즉각(0.1초 이내) 시장가 전량 청산을 집행하는 **'2중 하드 안전망(개별 종목 -3% 무조건 하드 손절 + 일일 계좌 -2% 서킷브레이커)'**을 완벽하게 구현하게 됩니다.

> 💡 **위험 관리의 절대 법칙**: 손절은 생각하는 순간 늦습니다. "조금만 더 기다리면 반등하겠지"라는 인간의 나약한 희망 회로가 계좌를 파멸로 이끕니다. 하드 손절은 **사람의 감정이 개입할 틈을 0.001초도 주지 않는 기계의 절대 규율**이어야 합니다.

- **1차 안전망 (개별 종목 하드 손절)**: 평균 매수가 대비 -3.0% 도달 시 즉시 시장가 전량 매도
- **2차 안전망 (포트폴리오 일일 서킷브레이커)**: 오늘 하루 계좌 전체 손실이 -2.0% 도달 시, **보유 중인 모든 종목을 즉시 전량 매도하고 당일 시스템 매매를 강제 종료(Shutdown)**
- 사람이 개입하지 않는 완전 무인 안전 프로세스의 철학과 설계
- **실습 20**: `risk_guard.py` 작성 및 가상 급락 상황 시뮬레이션을 통한 즉시 강제 청산 테스트

## 이론 핵심

### 1. 2중 하드 안전망 아키텍처

```text
[상시 감시 루프 (0.5초 간격)]
│
├── [1차 감시: 개별 종목 수익률 체크]
│   └── 개별 종목 손실률 <= -3.0% ?
│       └── YES ➔ [즉시 실행] KIS API 시장가 전량 매도 발주 ➔ 텔레그램 긴급 알림 전송 (사람 질문 없음)
│
└── [2차 감시: 일일 포트폴리오 총 손익 체크]
    └── 당일 총 계좌 손실액 / 시작 자산 <= -2.0% ?
        └── YES ➔ [비상 서킷브레이커 발동]
                  ① 모든 보유 종목 시장가 즉시 전량 청산
                  ② 오늘 하루 모든 신규 매수 주문 차단 (Lock)
                  ③ 긴급 비상 로그 기록 및 시스템 안전 종료
```

## 실습 — 실습 20: 무인 하드 가드레일 모듈 가동

Claude Code 대화창에 아래 프롬프트를 입력하여 하드 손절 및 서킷브레이커 모듈을 구축하세요.

```prompt
사람 개입 없이 0.1초 만에 즉시 실행되는 하드 손절 및 포트폴리오 서킷브레이커 모듈 'risk_guard.py'를 작성해줘. (Context)

다음 요구사항에 맞춰 파이썬 스크립트를 작성하고 실행해줘: (Deliverable)
1. kis_auth.py를 통해 현재 보유 중인 주식 잔고와 각 종목별 평균 매입단가, 현재 평가손익률(%)을 조회해줘.
2. 1차 안전망: 개별 종목 평가손익률이 -3.0% 이하로 떨어진 종목이 발견되면, 확인 없이 즉시 KIS 주식 매도(TTTC0801U) API를 호출해 전량 시장가 매도해줘.
3. 2차 안전망: 오늘 시작 자산 대비 현재 총 평가손실이 -2.0% 이하로 도달하면, 'CIRCUIT_BREAKER_TRIGGERED' 상태를 선언하고 전 종목 시장가 청산 후 당일 매매 중단 플래그('lock.flag')를 생성해줘.
4. 안전망 발동 상황을 시뮬레이션하기 위해, 가상의 -3.5% 손실 상황을 입력했을 때 즉시 청산 주문 함수가 호출되는 테스트 로그를 터미널에 증명해줘.

실행 완료 후 터미널에 가드레일 감시 상태와 하드 손절 집행 로그를 확인시켜줘. (Verification)
```

---

### 내 눈으로 확인할 체크리스트

- [ ] 개별 종목 -3% 도달 시 사람 승인 없이 즉시 매도 함수가 호출되는 로직을 확인했다.
- [ ] 일일 포트폴리오 -2% 손실 시 전 종목 비상 청산 및 매매 잠금(`lock.flag`)이 정상 발동함을 확인했다.
- [ ] 무인 하드 손절이 내 자산을 보호하는 가장 강력한 방패임을 체감했다.
