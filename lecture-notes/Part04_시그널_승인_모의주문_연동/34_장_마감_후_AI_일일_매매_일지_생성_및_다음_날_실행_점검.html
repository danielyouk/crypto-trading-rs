예상 소요 시간: 약 20분
강의 유형: 실습 18 (실습 중심)

이번 클립에서 만들 것

이 클립이 끝나면, 여러분은 매일 오후 3시 40분 정규 주식 시장이 마감되었을 때 자동으로 실행되어, 당일의 총 체결 내역, 실현 손익, 미실현 평가손익, 슬리피지 비용을 정밀하게 분석하고, 내일 아침 개장 전 점검해야 할 사항까지 포함된 'AI 일일 매매 일지(daily_journal.md)'를 자동으로 생성하는 포스트-마켓(Post-Market) 자동화 파이프라인을 완성하게 됩니다.

💡 수강생 안심 안내: 매매 일지를 손으로 쓸 필요가 없습니다. KIS API에서 오늘 발생한 실제 체결 영수증 데이터를 긁어와 AI가 전문 퀀트 분석관의 어조로 일지를 작성하고 Markdown 문서로 깔끔하게 정리해 줍니다.

  • 장 마감 후 포스트-마켓 루틴(Post-Market Routine)의 중요성
  • KIS API 당일 체결 내역 조회(TTTC8001R) 및 일간 PnL(Profit & Loss) 분해 공식
  • AI 일일 매매 일지의 4대 핵심 구조: 1. 오늘 계좌 총 요약 (시작 자산, 마감 자산, 일일 수익률 %) 2. 종목별 체결 내역 (진입가, 청산가, 실현 손익, 슬리피지 추정) 3. 전략별 성과 기여도 (추세추종 vs 돌파 vs 모멘텀 vs 페어) 4. 내일 아침 실행 전 점검 사항 및 기준 가격 예고
  • 실습 22: daily_journal.py 실행 및 docs/daily_journal_YYYYMMDD.md 자동 생성

1. 일일 손익(PnL)의 정확한 분해 공식

$$ \text{Daily Total PnL} = \text{Realized PnL (실현 손익)} + \Delta \text{Unrealized PnL (평가손익 변동)} - \text{Total Friction Costs (비용)} $$

실습 — 실습 22: AI 일일 매매 일지 자동 생성기 구동

Claude Code 대화창에 아래 프롬프트를 입력하세요.

AI 프롬프트 템플릿 (목표 중심) 
장 마감 후 당일 매매 결과를 종합 분석하여 일일 매매 일지를 자동 작성하는 'daily_journal.py' 모듈을 완성해줘. (Context)

다음 요구사항에 맞춰 파이썬 스크립트를 작성하고 실행해줘: (Deliverable)
1. KIS API를 통해 당일 체결 내역과 현재 잔고 평가액을 조회해줘.
2. 오늘의 시작 자산 대비 총 손익(원, %), 실현 손익, 보유 종목별 평가손익을 집계해줘.
3. 체결된 주문들의 슬리피지(주문 당시 시세 vs 실제 체결단가 차이)를 추정 계산해줘.
4. 분석 결과를 바탕으로 전문적인 마크다운 형식의 일일 매매 일지를 'docs/daily_journal_20260824.md' 파일로 저장해줘.
5. 대화창에는 오늘 하루의 핵심 성과 요약 카드(Total PnL, Win Rate, Key Trades)를 출력해줘.

실행 완료 후 화면에 요약 카드를 출력하고 생성된 일지 마크다운 파일 내용을 확인시켜줘. (Verification)

내 눈으로 확인할 체크리스트

  • docs/daily_journal_YYYYMMDD.md 파일이 정상 생성되었다.
  • 일지에 오늘 계좌의 일간 수익률과 종목별 손익 내역이 빠짐없이 기록되었다.
  • 내일 장 시작 전 확인해야 할 전략별 기준가가 정리된 것을 확인했다.
