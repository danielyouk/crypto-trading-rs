# 시장의 실시간 가격 데이터를 받아오기

## 이번 클립에서 만들 것

증권사에서 **지금 가격**을 받아 오는 시세 모듈(`market_data.py`)을 만들고, 신호 스크립트(`generate_signals.py`)가 쓰는 **날짜별 가격**도 증권사에서 받도록 바꿉니다.

- 가격을 받는 방식과 요청 한도
- 신호에 쓰는 가격도 증권사에서 받는 이유
- **실습 16**: `market_data.py` 작성, 신호 스크립트를 증권사 가격으로 바꾸기

---

## 이론 핵심

### 1. 정해진 간격으로 물어봅니다

이 강의는 프로그램이 증권사에 "지금 얼마야?"라고 주기적으로 묻는 방식(**폴링**)을 씁니다. 가격이 바뀔 때마다 증권사가 알려 주는 방식(웹소켓)도 있지만, 연결이 끊겼는지 지켜보는 코드가 따로 필요합니다. 전략이 종가로 판정하므로 묻는 방식으로 충분합니다.

증권사는 정해진 시간에 받을 수 있는 요청 수를 제한합니다(**요청 한도**). 모의투자는 계좌당 1초에 1번입니다(2026년 4월 기준). 한도를 넘기면 요청이 거절되므로 요청 사이에 간격을 둡니다. 이 간격은 증권사로 가는 요청이 모두 거쳐 가는 `kis_auth.py`가 맡습니다.

---

### 2. 신호에 쓰는 가격도 증권사에서 받습니다

지금까지 신호 스크립트는 공개 데이터 라이브러리(FinanceDataReader)로 가격을 받았습니다. 매일 운영할 때는 출처마다 새 날짜가 들어오는 때가 달라, 며칠 전 가격으로 신호가 나올 수 있습니다. 주문을 넣는 증권사에서 날짜별 가격(**일봉**: 하루의 시가·고가·저가·종가를 한 줄로 적은 것)도 받으면 이 문제가 줄어듭니다.

> ⚠️ 예를 들어 FinanceDataReader에서 KOSPI 지수를 `'^KS11'`로 받으면 매일 갱신된 값을 받지만, `'KS11'`로 받으면 갱신이 몇 주씩 늦은 저장본을 읽을 때가 있습니다.

---

## 실습 — 실습 16: 시세 모듈 만들기

Claude Code 대화창에 아래 프롬프트를 입력하세요.

> 📁 **공유 파일**: 이 실습은 `market_data.py`를 만들고, `generate_signals.py`가 증권사 가격을 `price_cache/kis_종목코드.csv`로 저장해 쓰게 바꿉니다.

```prompt
[맥락] 내가 매매하는 종목들의 지금 시세를 증권사에서 받아 오는 모듈을 만들고 싶어. 작업 폴더의 kis_auth.py에 만들어 둔 인증과 요청 기능을 그대로 가져다 쓴다.

[만들 것] 파이썬 스크립트 'market_data.py'를 작성하고 실행해줘:
1. 종목코드를 넣으면 지금 시세(현재가, 시가, 고가, 저가, 등락률, 거래량)를 돌려주는 함수를 만들어줘. 뒤에 만들 프로그램들도 이 함수를 가져다 쓸 거야.
2. 아래 6개 종목을 차례로 조회해 [종목명 / 용도 / 현재가 / 시가 / 고가 / 저가 / 등락률 / 거래량] 표로 보여줘.
   - KODEX 200 (069500) — 추세추종
   - TIGER 미국나스닥100 (133690), KODEX 미국채10년선물 (305080), KODEX 단기채권PLUS (214980) — 듀얼 모멘텀
   - KB금융 (105560), 하나금융지주 (086790) — 페어 스위칭

[하지 말 것]
- 거래 코드(기능마다 붙은 이름표)를 짐작으로 쓰지 마. KIS Developers 문서나 한국투자증권 공식 GitHub 예제(koreainvestment/open-trading-api)에서 모의투자용을 확인하고 출처를 알려줘.
- 증권사로 가는 요청은 모두 kis_auth.py를 거쳐서 보내. 연결 기능을 새로 만들거나 kis_auth.py를 고치지 마.
- 조회에 실패한 종목의 가격을 지어내지 마. 실패로 표시해.

[확인] 시세 표가 조회 시각과 함께 나왔는지 확인해줘. 증권사 앱의 현재가와는 내가 대조한다.
```

### 이어서: 신호 스크립트가 증권사 가격을 쓰게 바꾸기

같은 대화창에 이어서 입력하세요.

```prompt
[맥락] 작업 폴더의 generate_signals.py는 가격을 FinanceDataReader로 받아. 신호에 쓰는 날짜별 가격(일봉)도 증권사에서 받게 바꾸고 싶어. 작업 폴더의 kis_auth.py, market_data.py, generate_signals.py를 쓴다.

[만들 것]
1. market_data.py에 일봉(날짜별 시가·고가·저가·종가·거래량)을 받는 함수를 더해줘. 종목은 수정주가(액면분할 등을 반영해 고친 가격)로, KOSPI 지수도 받을 수 있게 해줘.
2. generate_signals.py가 가격을 이 함수로 받게 바꿔줘. 받은 가격은 'price_cache' 폴더에 'kis_종목코드.csv'로 저장하고, 다음부터는 빠진 날짜만 받아.
3. 날짜 없이 실행하면 기준일을 한국 시각으로 정하게 해줘. 장 마감(15:30) 뒤면 오늘, 그 전이나 휴장일이면 직전 거래일이야. 장중의 오늘 가격은 쓰지 마.
4. 날짜 없이 실행한 뒤, 종목별 [마지막 날짜 / 증권사 종가 / FinanceDataReader 종가] 비교표와 신호 표를 보여줘.

[하지 말 것]
- 거래 코드(기능마다 붙은 이름표)를 짐작으로 쓰지 마. KIS Developers 문서나 한국투자증권 공식 GitHub 예제(koreainvestment/open-trading-api)에서 모의투자용을 확인하고 출처를 알려줘.
- 전략 규칙, 입력값, 신호 파일 형식은 바꾸지 마.
- 받지 못한 가격을 다른 값으로 채우지 마. 멈추고 알려줘.

[확인] 비교표와 신호 표가 나왔는지, 'signals_기준일.json'과 'signals.json'이 그 기준일로 저장됐는지 확인해줘.
```
