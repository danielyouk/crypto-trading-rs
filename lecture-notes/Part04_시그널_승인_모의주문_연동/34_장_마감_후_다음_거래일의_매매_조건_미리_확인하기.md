# 장 마감 후 다음 거래일의 매매 조건 미리 확인하기

## 이번 클립에서 만들 것

장이 끝난 뒤 두 가지를 정리하는 **일지**(`daily_journal.py`)를 만듭니다. 오늘 주문이 계획대로 됐는지, 그리고 가격이 어디까지 가면 신호가 바뀌는지입니다.

- 오늘 체결과 보유 확인
- 신호가 바뀌는 조건 미리 보기
- **실습 22**: `daily_journal.py` 작성 및 오늘 자 일지 생성

---

## 이론 핵심

### 1. 오늘 계획대로 됐나

주문을 보냈다고 끝이 아닙니다. 주문한 만큼, 예상한 가격에 체결됐는지 보고, 지금 보유가 목표와 같은지 봅니다. 다르다면 매수를 승인하지 않았거나, 일부만 체결됐거나, 안전장치가 팔았을 수 있습니다. 일지는 기록에서 그 이유를 찾아 함께 적습니다.

---

### 2. 신호가 바뀌려면 얼마나 남았나

신호 파일은 "지금 신호가 무엇인가"만 말해 줍니다. 일지는 "신호가 바뀌려면 얼마나 남았는가"를 보여 줍니다.

```text
[신호가 바뀌는 조건]  (숫자는 예시)
추세추종     지금 보유.  종가가 91,500원 아래로 내려가면 매도 신호 (지금보다 -14.6%)
페어 스위칭  지금 KB금융. Z가 +1.5를 넘으면 하나금융지주로 교체 (지금 Z -0.24)
듀얼 모멘텀  다음 판정일까지 3거래일. 지금 1위는 KODEX 200
```

기준에서 멀면 당분간 주문이 없을 가능성이 높고, 가까우면 다음 장 마감 후 주문 목록을 꼭 확인해야 합니다.

---

## 실습 — 실습 22: 장 마감 후 일지 만들기

Claude Code 대화창에 아래 프롬프트를 입력하세요.

> 📁 **공유 파일**: 이 프롬프트는 신호 파일, 주문 목록, `approvals_log.json`, `orders_history.json`, `stopped_positions.json`을 읽고, 일지를 `docs/daily_journal_YYYYMMDD.md`로 저장합니다. 먼저 `generate_signals.py`와 `prepare_orders.py`를 차례로 실행해 두세요.

```prompt
[맥락] 장 마감 후에 오늘 주문이 계획대로 됐는지 확인하고, 신호가 바뀌는 조건을 미리 정리한 일지를 만들고 싶어. 작업 폴더의 kis_auth.py, generate_signals.py와 그동안 쌓인 파일(signals_날짜.json, orders_날짜.json, approvals_log.json, orders_history.json, stopped_positions.json)을 쓴다.

[만들 것] 파이썬 스크립트 'daily_journal.py'를 작성하고 실행해줘:
1. 오늘 체결: 'orders_history.json'의 오늘 주문을 증권사 체결 내역과 대조해 [종목 / 매수·매도 / 주문 수량 / 체결 수량 / 예상 가격 / 체결 가격 / 차이(%)] 표를 만들어줘. 오늘 주문이 없으면 '오늘 주문 없음'으로 적어.
2. 잔고: 종목별 [보유 수량, 평균 매수가, 현재가, 평가손익]과 [예수금, 총자산]을 적고, 보유 수량을 직전 거래일 신호 파일의 목표와 비교해줘. 다르면 승인 기록, 체결 표, 손절 기록에서 이유를 찾아 적어. 'lock.flag'가 있으면 맨 위에 '매수 중단 중'이라고 적어.
3. 다음 거래일 주문: 오늘 날짜의 주문 목록이 있으면 주문과 승인 상태를 옮겨 적어줘.
4. 신호가 바뀌는 조건: generate_signals.py의 규칙을 그대로 써서 추세추종(200일선까지 남은 %), 페어 스위칭(지금 Z와 ±1.5까지 거리), 듀얼 모멘텀과 시장 국면(다음 판정일), 조정 비중(지금 쓰는 값과 오늘 계산한 값의 차이)을 적어줘.
5. 'docs/daily_journal_YYYYMMDD.md'로 저장하고, 대화창에 세 줄 요약(오늘 체결 / 다음 거래일 주문과 승인 대기 건수 / 기준에 가장 가까운 신호)을 보여줘.

[하지 말 것]
- 거래 코드(기능마다 붙은 이름표)를 짐작으로 쓰지 마. KIS Developers 문서나 한국투자증권 공식 GitHub 예제(koreainvestment/open-trading-api)에서 모의투자용을 확인하고 출처를 알려줘.
- 읽고 기록만 해. 주문을 내거나 다른 파일을 바꾸지 마.
- 조회에 실패한 값을 추정해서 채우지 마. '조회 실패'로 적어.
- 손익이 왜 그렇게 나왔는지 원인을 분석하지 마.

[확인] 세 줄 요약과 저장된 일지 경로를 보여줘.
```
