# 승인된 정책에 따라 증권사 API로 자동 모의주문 실행하기

## 이번 클립에서 만들 것

이 클립이 끝나면, **주말에 승인된 `weekly_policy.json` 정책에 따라 평일 장중에 조건이 맞으면 한국투자증권 Open API를 통해 자동으로 모의주문이 발주되는 무인 실행 엔진**이 완성됩니다.

- 시스템이 `weekly_policy.json`을 읽고 실시간/일봉 시세를 감시
- 진입 조건(예: Z-Score 돌파 등) 만족 시 증권사 API로 매수 주문 자동 전송
- 모의투자 계좌에 실제로 매수 체결이 이루어지고 주문 번호가 기록되는 화면 확인

### 안전 발주를 위한 사전 검증 3대 원칙

1. **주문 한도 검증**: 1회 주문 금액이 `weekly_policy.json`에 정의된 최대 허용한도를 넘지 않는가?
2. **잔고 상태 확인**: 현재 예수금이 주문 필요 금액보다 충분한가?
3. **중복 발주 방지**: 이미 당일 체결되었거나 미체결된 주문이 존재하는가?

## 따라 해보기 — 정책 기반 자동 모의주문 파이프라인

Claude Code에게 승인된 정책 파일을 바탕으로 자동 주문을 실행하는 스크립트를 요청합니다.

```prompt
weekly_policy.json 파일을 읽어서 조건이 충족되었을 때
한국투자증권 모의투자 계좌로 자동으로 매수 주문을 발주하는 스크립트를 작성해줘.
1회 최대 주문 한도와 예수금을 먼저 확인하고, 중복 발주가 일어나지 않도록 안전 검증을 포함해줘.
테스트 모드로 1주 매수 주문을 전송하고, 체결 결과와 주문 번호가 로그에 출력되는 것을 보여줘.
```

### 내 눈으로 확인할 체크리스트

- [ ] `weekly_policy.json` 파일의 설정을 정확히 로드하여 실행 기준을 파악했다
- [ ] 주문 발주 전 예수금과 1회 최대 주문 한도를 체크하는 안전 로직이 동작한다
- [ ] 한국투자증권 모의투자 API로 정상 주문이 전송되어 주문 번호(ODNO)가 발급되었다
- [ ] 한국투자증권 HTS/MTS 모의투자 잔고에 실제로 매수 내역이 반영되었다

## 자주 발생하는 문제

- **장 운영 시간 외 주문 에러**: 정규 장 시간이 아닐 경우 모의투자 API에서 주문 거부 에러가 반환될 수 있습니다. 이때는 예약 주문 또는 장 운영 시간에 맞춰 테스트하세요.
- **모의투자 예수금 부족**: 모의투자 계좌에 잔고가 충분한지 이전 클립 잔고 조회 스크립트로 먼저 확인하세요.

```prompt
모의투자 주문 API 호출 시 반환된 에러 코드를 분석해줘.
정규장 시간 여부와 예수금 잔고를 확인하고 정상 처리되도록 점검해줘.
```
