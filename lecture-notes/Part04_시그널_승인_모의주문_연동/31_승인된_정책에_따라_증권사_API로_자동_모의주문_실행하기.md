# 승인된 정책에 따라 증권사 API로 자동 모의주문 실행하기

## 이번 클립에서 만들 것

이 클립이 끝나면, 여러분은 승인된 주간 정책(`weekly_policy.json`)과 실시간 시그널(`signals.json`)을 읽어들여, 조건이 충족되었을 때 **한국투자증권 모의투자 API를 통해 실제 주식 매수/매도 주문을 자동으로 전송하고, 체결 영수증(주문번호, 체결가, 체결수량)을 받아 기록하는 '무인 자동 발주 엔진(`execute_orders.py`)'**을 완성하게 됩니다.

> 💡 **수강생 안심 안내**: 승인되지 않은 정책(`status != "ACTIVE"`)이거나 유효기간이 지난 정책인 경우, 발주 엔진은 스스로 안전하게 멈추며 절대로 임의로 주문을 넣지 않습니다.

- KIS 국내주식 주문(현금매수 `TTTC0802U` / 현금매도 `TTTC0801U`) API 규격 이해
- 주문 유형: 시장가(01) 주문 vs 지정가(00) 주문의 장단점 및 알고리즘 적용 기준
- 중복 주문 방지(Idempotency / Order Deduplication)를 위한 주문 상태 저장소(`orders_history.json`) 설계
- **실습 19**: `execute_orders.py` 실행을 통한 KIS 모의투자 계좌 실제 1주 매수/매도 체결 테스트

## 이론 핵심

### 1. 무인 자동 발주 파이프라인 (Execution Flow)

```text
[1. 사전 정책 검증] ──> weekly_policy.json이 ACTIVE 상태인지 & 유효기간 내인지 확인
         ↓
[2. 시그널 읽기]    ──> signals.json에서 BUY/SELL 신호 및 목표 수량 확인
         ↓
[3. 중복 주문 검사] ──> 이미 오늘 동일 종목으로 발주된 이력이 있는지 orders_history.json 대조
         ↓
[4. KIS API 주문]  ──> POST /uapi/domestic-stock/v1/trading/order-cash 전송
         ↓
[5. 체결 확인 & 로깅]──> 주문번호(ODNO) 수신, 체결 결과 저장 및 텔레그램 및 화면 브리핑
```

---

### 2. KIS 주식 주문 API 필수 파라미터

| 파라미터명 | 의미 | 예시값 | 설명 |
|---|---|---|---|
| `CANO` | 종합계좌번호 8자리 | `"50123456"` | `.env`에서 로드 |
| `ACNT_PRDT_CD` | 계좌상품코드 2자리 | `"01"` | 보통 주식 계좌 01 |
| `PDNO` | 종목코드 6자리 | `"069500"` | KODEX 200 등 |
| `ORD_DVSN` | 주문구분 | `"01"` | **"01": 시장가 (즉시 체결)**, "00": 지정가 |
| `ORD_QTY` | 주문 수량 | `"10"` | 문자열 형태의 정수 주수 |
| `ORD_UNPR` | 주문 단가 | `"0"` | 시장가 주문 시에는 "0" 전달 |

## 실습 — 실습 19: 무인 자동 주문 발주 모듈 실행

Claude Code 대화창에 아래 프롬프트를 입력하세요.

```prompt
승인된 weekly_policy.json을 준수하여 KIS 모의투자 계좌로 자동 주문을 전송하는 'execute_orders.py' 모듈을 완성해줘. (Context)

다음 요구사항에 맞춰 파이썬 스크립트를 작성하고 실행해줘: (Deliverable)
1. weekly_policy.json의 정책 상태가 'ACTIVE'이고 오늘 날짜가 유효기간 내인지 먼저 검증해줘. (비정상 시 즉각 중단)
2. signals.json을 읽고, BUY 신호가 발생한 첫 번째 종목(또는 테스트용 1주)에 대해 KIS 주식 현금매수(TTTC0802U) API를 호출해줘.
3. 주문 성공 시 반환되는 주문번호(ODNO)와 체결 메시지를 확인하고, 'orders_history.json'에 [주문시간, 종목코드, 주문유형, 주문수량, 주문번호]를 기록해줘.
4. 중복 발주를 방지하기 위해 이미 발주 완료된 신호는 재주문되지 않도록 필터링해줘.
5. 대화창에 체결 영수증 요약표를 출력해줘.

실행 완료 후 화면에 모의투자 주문 체결 영수증을 출력하여 성공을 증명해줘. (Verification)
```

---

### 내 눈으로 확인할 체크리스트

- [ ] `weekly_policy.json`의 승인 상태를 검증한 뒤 발주 프로세스가 안전하게 시작되었다.
- [ ] KIS 모의투자 API로부터 정상 응답(`rt_cd == "0"`, 주문번호 발급)을 받았다.
- [ ] `orders_history.json`에 오늘의 주문 이력이 정확하게 기록되었다.
- [ ] 한국투자증권 MTS/HTS 모의투자 화면에서 해당 종목의 체결 내역을 눈으로 확인했다.
