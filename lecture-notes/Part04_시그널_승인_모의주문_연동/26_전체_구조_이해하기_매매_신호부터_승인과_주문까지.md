# 전체 구조 이해하기: 매매 신호부터 승인과 주문까지

## 이번 클립에서 만들 것

이번 클립에서는 새 프로그램을 만들지 않습니다. 앞에서 뽑은 매매 신호가 실제 주문이 되기까지, Part 4에서 만들 시스템이 **장 마감 후 신호 계산과 승인 → 다음 날 개장 주문 → 장중 안전장치** 순서로 어떻게 이어지는지 지도를 봅니다.

> 💡 지금 증권사 계좌를 켤 필요는 없습니다. 증권사 연결은 다음 클립에서 합니다.

- 하루가 어떤 순서로 돌아가는가
- 사람이 하는 일과 프로그램이 하는 일의 구분
- 신호 파일과 실제 주문 사이에 비어 있는 것

## 이론 핵심

### 1. 하루의 흐름

우리가 운용하는 세 전략(추세추종, 듀얼 모멘텀, 페어 스위칭)은 모두 **장 마감 뒤 그날 종가로 판정이 끝납니다.** 그래서 다음 날 장이 열리기 전에 무엇을 몇 주 사고팔지가 모두 정해지고, 하루는 세 구간으로 나뉩니다.

```text
[장 마감 후]  신호 계산 → 주문 목록 → 승인
  오늘 종가로 세 전략의 신호와 목표 수량을 계산하고, 계좌의 실제 보유 수량과 비교해
  내일 낼 주문 목록을 만듭니다. 사람은 이 목록을 보고 매수 주문을 승인하거나 거절합니다.
        ↓
[다음 날 개장]  주문
  매도 주문과 승인된 매수 주문을 프로그램이 증권사로 보냅니다.
        ↓
[장중]  안전장치
  손절 기준에 닿으면 사람에게 묻지 않고 청산합니다.
```

사람이 하는 일은 **장 마감 후의 승인 한 가지**입니다. 다음 날 개장 전까지만 하면 되고, 주문 목록이 비어 있는 날은 확인만 하고 끝납니다. 대부분의 날이 그렇습니다.

이 흐름과 별개로, 프로그램이 한 일을 알려 주는 **보고** 두 가지가 있습니다. 장 마감 후 일지는 오늘 주문이 제대로 체결됐는지와 신호가 바뀌는 조건을 정리하고, 이메일은 그 일지와, 프로그램이 나 없이 한 일(체결 결과, 손절 실행, 오류)을 알려 줍니다. 둘 다 승인의 단계가 아니라, 이미 일어난 일을 알려 주는 것입니다.

---

### 2. 사람이 하는 일과 프로그램이 하는 일

| 일 | 누가 | 이유 |
|---|---|---|
| 신호 계산, 주문 목록 만들기 | 프로그램 | 규칙대로 계산하면 되는 일 |
| **매수 주문** | **사람이 승인한 뒤** 프로그램이 주문 | 위험을 늘리는 주문. 승인이 없으면 그날은 사지 않음 |
| 매도 주문 | 프로그램 (승인 없이) | 위험을 줄이는 주문 |
| 손절, 하루 손실 한도 | 프로그램 (승인 없이) | 급락 때 사람의 답을 기다리면 늦음 |

**위험을 늘리는 일은 사람이 확인하고, 위험을 줄이는 일은 기계가 바로 합니다.** 매수는 사람이 승인하지 않으면 나가지 않으므로, 아무것도 하지 않는 쪽이 늘 안전한 쪽입니다.

매수 주문은 장 마감 뒤에 정해지고, 사람은 그 주문 목록 파일을 열어 값을 확인한 뒤 승인 상태를 고쳐 둡니다. 다음 날 개장 전까지만 하면 되고, 개장 때 주문이 자동으로 나갑니다. 시스템에 익숙해진 뒤에는 승인 상태를 고치지 않아도 프로그램이 매수를 모두 승인해 내보내는 **자동 방식**으로 바꿀 수 있습니다.

---

### 3. 신호 파일만으로는 주문을 낼 수 없습니다

앞에서 만든 신호 파일(`signals.json`)의 종목별 **순주문**은 직전 거래일 신호 파일의 목표 수량과 비교한 값입니다. 계좌에 실제로 몇 주가 있는지는 모릅니다. 직전 파일이 없으면 보유를 0으로 보고 목표 수량 전체를 순주문으로 적습니다. 이 신호를 실제 주문으로 옮기려면 아래 빈칸을 채워야 하고, Part 4가 그 일을 합니다.

| 비어 있는 것 | Part 4에서 만들 것 |
|---|---|
| 계좌에 실제로 몇 주가 있는가 | **증권사 연결**: 모의투자 계좌 인증과 잔고 조회 |
| 신호에 쓴 가격이 최신인가 | **시세 받기**: 현재가와, 신호에 쓰는 날짜별 가격을 증권사에서 받기 |
| 실제 보유와 비교하면 무엇을 사고팔아야 하나 | **주문 목록**: 신호를 실제 보유 수량과 비교해 낼 주문 정하기 |
| 이 매수를 정말 낼 것인가 | **승인**: 주문 목록을 보고 매수 주문을 승인하거나 거절 |
| 내가 없을 때 프로그램이 무엇을 했나 | **알림**: 그날 일지와 체결 결과, 손절 실행, 오류를 이메일로 보고 |
| 주문을 누가 보내고 체결을 어떻게 확인하나 | **주문 실행**: 매도와 승인된 매수를 증권사로 보내고 체결 확인 |
| 장중 급락은 누가 막나 | **안전장치**: 장중 급락 때 묻지 않고 청산 |
| 오늘 계획대로 됐나 | **장 마감 후 확인**: 오늘 체결 확인, 신호가 바뀌는 조건 미리 보기 |
| 매일 같은 시간에 누가 돌리나 | **자동 실행**: 장 마감 후 작업과 개장 작업을 매일 정해진 시각에 실행 |

단계마다 프로그램을 하나씩 따로 만들고 따로 확인합니다. 프로그램 이름과 세부 내용은 만들어 가면서 정합니다.
