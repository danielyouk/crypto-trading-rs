# (advanced) 주식시장 운영 시간에 맞춰 시스템을 자동으로 실행하기

## 이번 클립에서 만들 것

지금까지 만든 프로그램을 내가 켜지 않아도 **장 운영 시간에 맞춰 저절로 돌게** 합니다. 장 마감 후 작업과 개장 작업을 실행 파일로 만들어, 컴퓨터의 예약 실행 기능(윈도우 **작업 스케줄러**, Mac **launchd**)에 등록합니다.

- 하루에 두 번 실행하는 이유
- 윈도우와 Mac에서 예약 실행 등록하기
- **실습 23**: 장 마감 후 작업과 개장 작업 만들기 및 점검 실행

---

## 이론 핵심

### 1. 하루에 두 번 실행합니다

```text
[평일 17:00] 장 마감 후 작업: 신호 → 주문 목록 → 일지
        ↓
[사람]       다음 날 개장 전까지 주문 목록에서 매수를 승인하거나 거절
        ↓
[평일 08:50] 개장 작업: 시작 총자산 기록 → 09:00 매도와 승인된 매수 → 15:30까지 장중 안전장치
```

- **17:00**: 장은 15:30에 끝나지만 종가가 데이터에 반영되기까지 시간이 걸려 여유를 둡니다.
- **08:50**: 장이 열리기 전에 계좌 총자산을 찍어 두어야 그날 손실을 잴 수 있습니다. 주문은 09:00에 보냅니다. 모의투자에는 저녁에 주문을 맡겨 두는 **예약주문**이 없어서, 장이 열릴 때 프로그램이 직접 보냅니다.
- 전날 주문 목록이 없으면(전날 작업이 돌지 않았으면) 개장 작업은 그 자리에서 전날 종가로 목록을 만들어 **매도만** 보내고, 그 사실을 실행 기록에 남깁니다. 빠진 매수는 그날 저녁 목록에 다시 올라옵니다.

---

### 2. 윈도우와 Mac에서 예약 실행하기

예약 실행에는 **실행 파일**을 등록합니다. 작업 폴더로 옮겨 간 뒤 그 폴더 가상환경의 파이썬으로 프로그램을 돌리는 몇 줄짜리 파일입니다. 예약 실행은 터미널과 달리 작업 폴더와 가상환경을 잡아 주지 않아서 이렇게 적어 둡니다.

| | 윈도우 | Mac |
|---|---|---|
| 예약 실행 기능 | 작업 스케줄러 (`schtasks` 명령) | launchd (`launchctl` 명령) |
| 실행 파일 | `.bat` | `.sh` |
| 예약 설정이 저장되는 곳 | 작업 스케줄러 라이브러리 | `~/Library/LaunchAgents` 폴더의 `.plist` 파일 |

윈도우에서 평일 17:00에 실행 파일을 돌리는 등록 명령은 이런 모양입니다. Mac은 같은 내용을 `.plist` 파일에 적어 등록합니다.

```bat
schtasks /create /tn "AI트레이딩 장 마감 후" /tr "C:\ai-trading\run_after_close.bat" /sc weekly /d MON,TUE,WED,THU,FRI /st 17:00
```

> ⚠️ 예약 시각에 컴퓨터가 **꺼져 있으면 그날은 실행되지 않습니다.** 오늘 자 일지가 만들어지지 않았다면 실행 기록(`logs/run_YYYYMMDD.log`)을 확인하세요. Mac은 작업 폴더가 '문서'나 '데스크탑' 안에 있으면 권한 문제로 예약 실행이 막힐 수 있습니다.

**실행 방식**은 처음에는 '승인'으로 둡니다. 몇 주 동안 주문 목록이 규칙대로 만들어지는 것을 확인했다면 '자동'으로 바꿔도 됩니다. 자동 방식에서도 내가 '거절'로 고친 매수는 나가지 않습니다.

## 실습 — 실습 23: 장 운영 시간에 맞춰 실행되는 작업 만들기

Claude Code 대화창에 아래 프롬프트를 입력하세요.

> 📁 **공유 파일**: 이 프롬프트는 앞에서 만든 프로그램들을 불러 쓰고, 실행 기록을 `logs/run_YYYYMMDD.log`에, 등록 안내를 `docs/scheduler_setup.md`에 저장합니다. 같은 날짜의 주문 목록이 이미 있으면 덮어쓰지 않으므로, 고쳐 둔 승인 상태는 그대로 남습니다.

```prompt
[맥락] 작업 폴더의 프로그램들(generate_signals, prepare_orders, daily_journal, approve_orders, execute_orders, risk_guard)을 거래일마다 장 운영 시간에 맞춰 저절로 돌게 하고 싶어. 먼저 파일들이 하는 일과 실행 방법, 그리고 내 컴퓨터 종류(윈도우, Mac)를 확인해줘.

[만들 것]
1. 'run_after_close.py'(평일 17:00): 오늘이 휴장일이면 아무것도 하지 않고 끝내. 아니면 generate_signals.py → prepare_orders.py → daily_journal.py를 차례로 실행해. 가격이 오늘 종가까지 오지 않았으면 주문 목록을 만들지 말고 기록에 남겨. 같은 날짜 주문 목록이 이미 있으면 그대로 둬.
2. 'run_market_open.py'(평일 08:50): 오늘이 휴장일이면 아무것도 하지 않고 끝내. 아니면 장이 열리기 전에 risk_guard.py로 시작 총자산을 기록하고 09:00까지 기다려. 그다음 실행 방식('승인' 기본, '자동')에 따라 approve_orders.py를 그대로 또는 자동 방식으로 돌린 뒤 execute_orders.py로 주문을 보내고, 15:30까지 risk_guard.py 점검을 되풀이해. 전날 주문 목록이 없으면 그 자리에서 전날 종가로 만들어 매도만 보내(이 목록의 매수는 승인하지 마).
3. 두 스크립트는 어느 폴더에서 실행해도 작업 폴더의 파일을 쓰고, 출력과 에러를 'logs/run_YYYYMMDD.log'에 남겨. 한 단계가 실패하면 기록하고, 그 결과가 필요한 뒤 단계만 건너뛰어(안전장치는 늘 돌려).
4. 내 컴퓨터에 맞는 실행 파일 두 개(윈도우 '.bat', Mac '.sh')와, 평일 17:00·08:50 예약을 등록·확인·삭제하는 방법을 담은 'docs/scheduler_setup.md'를 만들어줘.
5. 점검 실행도 만들어줘. 점검 실행은 시각을 기다리지 않고 바로 끝까지 돌되, 주문은 보내지 않고 기록만 남겨. 이번에는 두 스크립트를 점검 실행으로만 돌려줘.

[하지 말 것]
- 예약 실행에 직접 등록하지 마. 등록은 내가 안내 문서를 보고 한다.
- '승인' 방식에서 매수를 대신 승인하지 마.
- 주문은 execute_orders.py의 주문 보내기로만 보내고, 기존 프로그램 파일은 고치지 마.

[확인] 점검 실행 기록에 두 작업의 단계가 순서대로 남았는지, 실행 파일 두 개와 'docs/scheduler_setup.md'가 생겼는지, 점검 실행을 어떻게 돌리는지 보여줘.
```

### 내 눈으로 확인할 체크리스트

- [ ] 점검 실행에서 두 작업이 순서대로 돌았고, 실제 주문은 나가지 않았다.
- [ ] `docs/scheduler_setup.md`를 보고 평일 17:00과 08:50 예약을 등록한 뒤, 등록 목록에서 두 개를 확인했다.
