# 설정한 조건에 따라 매매 신호 만들기

## 이번 클립에서 만들 것

이 클립이 끝나면, 여러분은 실시간으로 수신되는 주가 데이터와 4대 퀀트 전략의 룰셋을 실시간으로 대조하여, **"지금 이 순간 어떤 종목을 몇 주 매수/매도해야 하는지"를 0.1초 만에 판정하는 '실시간 매매 시그널 판정기(`realtime_signals.py`)'**를 완성하게 됩니다.

> 💡 **수강생 안심 안내**: 복잡한 주문 수량 계산(내 계좌의 가용 예수금 대비 20% 비중 산정, 호가 단위 반올림 등)을 사람이 손으로 계산할 필요가 없습니다. 알고리즘이 내 계좌 잔고를 실시간으로 조회하여 정확한 '목표 주문 주수'까지 완벽하게 계산해 냅니다.

- 실시간 시세 ➔ 기술적 지표 갱신 ➔ 조건문 판정 ➔ 목표 수량 산출의 4단계 실시간 시그널 파이프라인
- **포지션 사이징(Position Sizing)**: 계좌 총 예수금 대비 종목별 자산 배분 비중(%)을 실제 주문 주수(Shares)로 환산하는 공식
- 매수 신호(BUY), 매도 신호(SELL), 관망(HOLD) 상태 머신 관리
- **실습 17**: 실시간 시그널 엔진 구동 및 `signals.json` 실시간 갱신 테스트

## 이론 핵심

### 1. 실시간 시그널 판정 및 주문 수량 계산 공식

$$\text{Target Capital} = \text{Total Equity} \times \text{Allocation Weight} \quad (\text{예: 1억 원 } \times 20\% = 2,000\text{만 원})$$

$$\text{Order Quantity (주수)} = \left\lfloor \frac{\text{Target Capital}}{\text{Current Price}} \right\rfloor \quad (\text{현재가로 나눈 뒤 소수점 버림})$$

```text
[실시간 시그널 판정 흐름]
1. 계좌 잔고 조회: 총 예수금 50,000,000원 확인
2. KODEX 레버리지 실시간 시세 조회: 현재가 18,500원
3. 변동성 돌파 조건 검사: 현재가(18,500원) >= 목표가(18,400원) ➔ BUY 신호 발생!
4. 주문 수량 산출: (5,000만 원 * 30%) / 18,500원 = 810주 매수 결정
5. 하드 손절가 계산: 진입가 18,500원 * (1 - 0.03) = 17,945원 설정
```

## 실습 — 실습 17: 실시간 매매 시그널 엔진 구동

Claude Code 대화창에 아래 프롬프트를 입력하세요.

```prompt
실시간 시장 데이터와 계좌 잔고를 바탕으로 매매 신호와 정확한 주문 수량을 산출하는 'realtime_signals.py'를 작성해줘. (Context)

다음 요구사항에 맞춰 파이썬 스크립트를 작성하고 실행해줘: (Deliverable)
1. kis_auth.py를 통해 모의투자 계좌의 현재 주문 가능 예수금을 실시간 조회해줘.
2. 4대 전략 대상 종목들의 실시간 현재가를 market_data.py로 조회해줘.
3. 다음 조건에 따라 종목별 신호를 판정해줘:
   - 추세추종 (KODEX 200): 현재가가 200일선 상단이면 BUY, 하단이면 SELL/HOLD
   - 변동성 돌파 (KODEX 레버리지): 현재가가 당일 목표가($\text{Open} + \text{Range} \times 0.5$) 이상이면 BUY
4. BUY 신호가 뜬 종목에 대해 할당 비중(예: 예수금의 25%)에 맞춰 '정확한 매수 주문 수량(주수)'과 '하드 손절가(-3%)'를 계산해줘.
5. 산출된 결과를 'signals.json' 파일로 저장하고, 대화창에 깔끔한 시그널 대시보드 표를 출력해줘.

실행 완료 후 화면에 시그널 대시보드를 출력하고 정상 판정 여부를 보여줘. (Verification)
```
