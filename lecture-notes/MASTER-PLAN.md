## 1. 강의 철학 (모든 노트에 일관되게 반영)

1. **제로코드에 가깝게** — 코드를 직접 작성하지 않는다. 수강생은 목표를 프롬프트로 전달하고, 결과 화면(차트·표·알림·동작)을 눈으로 확인한다.
2. **생각 → 요청 → 확인 → 개선 루프** — ① 끝나면 뭐가 보여야 하는지 생각 ② 결과 모습이 담긴 목표만 프롬프트로 전달 ③ 사람이 화면을 직접 확인(확인을 AI에게 시키지 않음) ④ 부족하면 후속 프롬프트.
3. **강사와 수강생의 결과는 다를 수 있다** — 프롬프트의 속성상 생성 코드가 다를 수 있다. 코드 동일 여부가 아니라 **체크리스트 기준으로 결과가 맞는지**를 본다.
4. **인간 개입형 하이브리드** — 매수는 사람이 승인, 빠른 손절은 규칙이 실행. 100% 자동수익 환상을 깬다.
5. **얼마나 버는가만큼 얼마나 덜 잃는가** — MDD·거래비용·과최적화를 항상 함께 본다.
6. **이론이 절반** — 이론을 제대로 이해해야 문제가 생겼을 때 스스로 수정할 수 있다. 각 클립의 절반가량은 이론에 배정한다.

### 클립 메타데이터 — `curriculum.json`

노트 파일에는 메타데이터를 넣지 않는다 (마크다운 미리보기가 지저분해지므로).
클립별 메타데이터는 `curriculum.json`에 파일명(stem)을 키로 중앙 관리한다:

```json
"04_첫_실습_주식_데이터를_불러와_차트로_확인하기": {
  "part": 1,
  "part_title": "AI와 함께 시작하는 트레이딩 시스템 만들기",
  "part_folder": "Part01_AI트레이딩_시스템_이해",
  "chapter": 2,
  "chapter_title": "AI 코딩 도구로 첫 결과물 만들기",
  "clip": 3,
  "clip_num": 4,
  "title": "첫 실습: 주식 데이터를 불러와 차트로 확인하기",
  "filename": "04_첫_실습_주식_데이터를_불러와_차트로_확인하기",
  "duration": 20,
  "practice": "실습 02"
}
```

`practice`가 없는 클립은 빈 문자열. 노트/스크립트 파일은 `# 제목` H1으로 시작하는
순수 마크다운이며, HTML 빌드 시 첫 H1은 페이지 템플릿의 제목으로 대체된다.
클립 제목·시간을 바꿀 때는 `curriculum.json`과 노트의 H1을 함께 수정한다.

### 노트 섹션 구성 (수강생용, 고정)

1. `## 이번 클립에서 만들 것` — 완성 화면/결과물 기준 목표. "이 클립이 끝나면 ~가 보입니다" 형식.
2. `## 이론 핵심` — 클립의 절반을 차지하는 이론. 소제목 2~4개.
3. `## 실습` — 실습 번호 명시. **프롬프트 템플릿**(```prompt 코드블록) + **내 눈으로 확인할 체크리스트**(`- [ ]` 목록). 실습 없는 클립은 "따라 해보기" 또는 생략.
4. `## 자주 발생하는 문제` — 강사와 결과가 다를 수 있는 지점 + 후속 프롬프트 예시.
5. `## 다음 클립 예고` — 1~2문장.

### 프롬프트 템플릿 형식

프롬프트는 언어 태그 `prompt`의 코드블록으로 작성한다 (HTML에서 복사 버튼과 함께 강조 렌더링):

````
```prompt
한국 주식 삼성전자(005930)의 최근 3년 일봉 데이터를 불러와서
이동평균선(20일, 60일)이 포함된 차트를 그려줘.
완성되면 차트 이미지 파일 경로를 알려줘.
```
````

프롬프트에는 항상 **결과 모습이 담긴 목표**를 포함한다 (조건 나열 금지, 확인은 사람이 한다).

### 강사 스크립트 구성 (강사용)

같은 프런트매터 + 말하기 원고: `## 도입 멘트` / `## 진행 흐름` (시연 타이밍 포함, 분 단위 배분) / `## 강조 포인트` / `## 마무리 멘트`.

## 4. HTML 빌드 & 나만의 교재 커스터마이징

- 빌더: `lecture-notes/build.py` (또는 루트에서 `runners/build_lecture_notes.py`)
- 실행: `python build.py` (또는 `python runners/build_lecture_notes.py`)
- 출력: `lecture-notes/partXX/*.html` (마크다운 파일과 같은 폴더에 1:1로 나란히 생성) + `lecture-notes/index.html`
- 디자인: **화면 좌측 절반 폭(≈760px) 최적화** — 우측에 Claude Code/Cursor를 띄우고 따라하는 시나리오. 프롬프트 블록 복사 버튼, 체크리스트 스타일, 이전/다음 클립 내비게이션.
- 강사 스크립트(`scripts/`)는 빌드 대상에서 제외.
- **수강생 커스터마이징**: 수강생이 각 `.md` 파일에 자신만의 관심 종목이나 백테스트 메모를 적고 `python build.py`를 실행하면 즉시 자신만의 웹북이 업데이트됩니다.

## 5. 운영 방식

- 43개 노트+스크립트는 **초안으로 일괄 생성**되어 있다. 각 클립 촬영 전에 해당 노트를 개별적으로 다듬는다.
- 노트 수정 후 빌더를 다시 실행하면 HTML이 갱신된다.
- 실습 번호와 클립 매핑은 진행하며 조정될 수 있다 (특히 Part 4의 카톡·이메일 알림 클립).
