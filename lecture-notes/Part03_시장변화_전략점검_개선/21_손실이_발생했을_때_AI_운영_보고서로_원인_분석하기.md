# 손실이 발생했을 때 AI 운영 보고서로 원인 분석하기

## 이번 클립에서 만들 것

이 클립이 끝나면, 여러분은 시스템에서 손실이나 드로다운이 발생했을 때 감정적으로 흔들리는 대신, AI 에이전트(Claude Code)에게 원인 분해를 지시하여 **'체계적인 AI 전략 손실 진단 보고서(Strategy Loss Diagnosis Report)'**를 Markdown 파일로 자동 생성하는 퀀트 거버넌스 루틴을 체득하게 됩니다.

> 💡 **수강생 안심 안내**: 손실이 났을 때 "전략이 틀렸다"고 무작정 코드를 뜯어고치면 안 됩니다. 손실의 원인이 **'정상적인 시장 환경 비용(통계적 분산)'**인지, **'전략 설계상의 취약점(구조적 결함)'**인지 객관적으로 분해해야 합니다.

- 손실 원인 2분법: **외생적 시장 요인(Market Regime)** vs **내생적 모델 결함(Model Flaw)**
- AI에게 손실 구간 데이터를 전달하고 구조화된 진단서를 요청하는 프롬프트 엔지니어링
- **AI 운영 보고서의 4대 핵심 구성 요소**:
  1. 손실 구간 시계열 및 매매 내역 요약
  2. 시장 국면(변동성, 추세 강도) 분석
  3. 손실을 유발한 구체적 매매 패턴(잦은 진입, 윗꼬리 청산 등)
  4. 3가지 구체적 전략 개선안(파라미터 조정, 보조 필터 추가, 현금 비중 확대)
- **실습 10**: Claude Code를 통한 `docs/strategy_loss_diagnosis.md` 자동 생성 및 검토

### 2. AI 손실 진단서 표준 포맷 (`strategy_loss_diagnosis.md`)

```markdown
# 퀀트 전략 손실 원인 진단 보고서

## 1. 개요 및 손실 지표
- 분석 대상 전략: KODEX 200 추세추종
- 손실 발생 기간: 2021-08 ~ 2022-09 (MDD -14.2%)

## 2. 세부 원인 진단 (Root Cause Analysis)
- 시장 요인: KOSPI 3,300 ➔ 2,150 계단식 장기 하락 국면
- 시스템 요인: 반등 시마다 200일선 일시 돌파 후 재추락 ➔ 총 8회 연속 손절 발생

## 3. 권장 개선 조치 (Action Items)
1. [필터 강화] 단순 200일선 돌파가 아니라 200일선 + 1.5% 이상 상향 시에만 매수
2. [변동성 제어] ATR(20) 기반 포지션 사이징 적용
```

## 실습 — 실습 10: AI 손실 진단 보고서 자동 생성

Claude Code 대화창에 아래 프롬프트를 입력하여 손실 구간에 대한 전문 보고서를 작성하게 하세요.

```prompt
추세추종 전략의 2021~2022년 최대 손실 구간에 대한 AI 손실 원인 진단 보고서를 작성해줘. (Context)

다음 분석을 수행하고 보고서를 마크다운 파일로 생성해줘: (Deliverable)
1. 당시 KOSPI 지수의 움직임과 추세추종 전략의 매매 체결 내역(진입일, 청산일, 손익률)을 대조해줘.
2. 손실이 집중된 원인을 [시장 환경적 요인]과 [전략 알고리즘적 한계]로 명확히 분해해줘.
3. 이 손실을 방어하기 위해 적용할 수 있는 2가지 구체적인 개선안(예: 돌파 버퍼 필터, 20일 거래량 필터)을 제안해줘.
4. 전체 보고서를 'docs/strategy_loss_diagnosis.md' 파일로 저장해줘.

실행 완료 후 터미널에 보고서 핵심 요약(Core Takeaway) 3줄을 출력하고 파일 경로를 알려줘. (Verification)
```
