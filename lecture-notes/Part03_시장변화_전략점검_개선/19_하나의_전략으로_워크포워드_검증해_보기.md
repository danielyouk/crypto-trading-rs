# 하나의 전략으로 워크포워드 검증해 보기

## 이번 클립에서 만들 것

이 클립이 끝나면, 여러분은 한국 대표 ETF(KODEX 200 / KODEX 레버리지)를 대상으로 **'단일 전략의 5단계 롤링 워크포워드(WFA) 종합 백테스트'**를 완전히 실행하고, 각 윈도우별 최적 파라미터의 전이 과정과 **실제 최종 WFE(워크포워드 효율성) 수치를 직접 계산 및 시각화**하게 됩니다.

> 💡 **수강생 안심 안내**: 복잡한 롤링 루프 코딩을 직접 작성하지 않아도 됩니다. 우리는 Claude Code에게 **"3년 학습창 + 1년 검증창 롤링 WFA 엔진"**을 요청하고, 산출된 윈도우별 성과표와 이어 붙인 순수익 곡선의 건전성을 판별합니다.

- **실습 08**: 2017~2026년 8월 31일 대상 5-Fold 롤링 워크포워드 엔진 구동
- In-Sample 최적 파라미터 탐색(Grid Search) vs Out-of-Sample 실전 적용
- 5개 Out-of-Sample 구간의 누적 자산 성장 곡선 이어 붙이기(Stitched Equity Curve)
- **Fold별 인샘플 CAGR vs 아웃샘플 CAGR 대조 및 최종 WFE(%) 산출**
- 일반 백테스트 곡선 vs 워크포워드(WFA) 곡선 비교를 통한 현실적 수익 기대치 정립

## 이론 핵심

### 1. 워크포워드 엔진의 구체적 실행 단계

```text
[Fold 1] 
1. In-Sample(2017~2019): 이동평균 기간 N=[50, 100, 150, 200] 중 샤프 지수 1위 파라미터 N* 선택 ──> (예: N*=150)
2. Out-of-Sample(2020): N*=150을 2020년 1월 1일~12월 31일에 적용하여 실제 수익률 기록 (2020년 데이터는 학습에 전혀 쓰이지 않음)

[Fold 2] 
1. In-Sample(2018~2020): 샤프 지수 1위 파라미터 재학습 ──> (예: N*=200)
2. Out-of-Sample(2021): N*=200을 2021년 1년 동안 적용하여 실제 수익률 기록

... (Fold 3, Fold 4, Fold 5 순차 실행)
```

---

### 2. 파라미터 안정성(Stability)의 발견

WFA를 실행해 보면, 좋은 전략은 In-Sample 기간이 바뀌어도 최적 파라미터가 크게 튀지 않고 일정한 범위($N=150 \sim 200$) 안에서 머무는 것을 확인할 수 있습니다. 반면 불안정한 전략은 $N=20 \to N=180 \to N=45$처럼 극단적으로 요동칩니다.

## 실습 — 실습 08: 추세추종 5-Fold 워크포워드 검증 실행

Claude Code 대화창에 아래의 표준 WFA 백테스트 프롬프트를 입력하세요.

```prompt
KODEX 200(069500) 대상 추세추종 전략의 5-Fold 워크포워드(WFA) 종합 검증을 수행해줘. (Context)

다음 요구사항에 맞춰 파이썬 WFA 백테스트 스크립트를 작성하고 실행해줘: (Deliverable)
1. 2017-01-01부터 2026-08-31까지의 KODEX 200 일봉 데이터를 불러와줘.
2. 3년 In-Sample + 전진 Out-of-Sample의 5개 Fold로 분할해줘:
   - Fold 1: IS(2017~2019) ➔ OOS(2020)
   - Fold 2: IS(2018~2020) ➔ OOS(2021)
   - Fold 3: IS(2019~2021) ➔ OOS(2022)
   - Fold 4: IS(2020~2022) ➔ OOS(2023)
   - Fold 5: IS(2021~2023) ➔ OOS(2024~2026.08)
3. 각 Fold의 In-Sample에서 이동평균선 파라미터 후보군(SMA 60, 100, 120, 150, 200) 중 최고 샤프 지수를 낸 최적 파라미터를 선정하고, 해당 파라미터로 Out-of-Sample 1년을 매매(왕복 0.25% 거래비용 차감)하게 해줘.
4. 5개 Fold의 IS CAGR, OOS CAGR, 선정된 최적 파라미터, 각 Fold별 WFE(%)를 비교하는 Markdown 표를 대화창에 출력해줘.
5. 상단에는 5개 OOS 구간을 이어 붙인 '최종 WFA 실전 누적 수익률 곡선'과 200일 고정 일반 백테스트 곡선을 겹쳐 그리고, 하단에는 Fold별 WFE 막대그래프를 그린 2-패널 차트를 'wfa_single_strategy_result.png'로 저장해줘.

실행 완료 후 전체 WFA 평균 WFE(%)와 실전 배포 적격 여부(WFE >= 60%)를 판정해줘. (Verification)
```

---

### 내 눈으로 확인할 체크리스트

- [ ] 5개 Fold별로 In-Sample에서 선택된 최적 이동평균 파라미터 목록을 확인했다.
- [ ] Out-of-Sample 구간만 이어 붙인 최종 WFA 수익률 곡선이 일반 백테스트보다 다소 보수적이지만 여전히 견고한 우상향을 그리는 것을 확인했다.
- [ ] 전체 평균 WFE가 60% 이상으로 측정되어 실전 배포 요건을 통과했는지 확인했다.
