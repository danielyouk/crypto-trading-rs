# 하나의 전략으로 워크포워드 검증해 보기

## 이번 클립에서 만들 것

이 클립이 끝나면, 여러분은 한국 대표 ETF인 **KODEX 200**을 대상으로 클립 18에서 그린 **훈련 → 검증 → 적용 8단계 워크포워드(WFA)**를 실제로 돌리고, 매년 어떤 파라미터가 뽑혔는지, 검증을 통과했는지, 그 결과 적용 구간을 이어 붙인 성적이 고정 200일선과 비교해 어땠는지를 직접 확인하게 됩니다. 클립 제목 그대로 **전략 하나**만 다룹니다.

> 💡 **수강생 안심 안내**: 복잡한 롤링 루프 코딩을 직접 작성하지 않아도 됩니다. 우리는 Claude Code에게 **"훈련 2년 + 검증 1년 + 적용 1년 롤링 WFA 엔진"**을 요청하고, 산출된 Fold별 결정표와 이어 붙인 곡선을 읽습니다.

- **실습 08**: 2016~2026년 8월 31일 대상 8-Fold 훈련·검증·적용 워크포워드 엔진 구동
- 훈련 구간 1등 고르기 → 검증 구간에서 상대 WFE 60% 확인 → 적용 구간 운용
- 8개 적용 구간의 누적 자산 성장 곡선 이어 붙이기(Stitched Equity Curve)
- 이어 붙인 워크포워드 곡선 vs 고정 200일선 곡선 비교를 통한 현실적 수익 기대치 정립

## 이론 핵심

### 1. 워크포워드 엔진의 구체적 실행 단계

```text
[Fold 1]
1. 훈련(2016~2017): 이동평균 기간 N=[60, 100, 120, 150, 200] 중 샤프 지수 1위 N* 선택 ──> (예: N*=150)
2. 검증(2018): N*와 200일선을 둘 다 돌려, 200일선보다 앞선 폭이 훈련 때의 60% 이상 남았는지 확인 (상대 WFE)
3. 적용(2019): 통과했으면 N*, 못 했으면 200일선으로 1년 운용하고 수익률 기록 (2019년 데이터는 고르거나 확인하는 데 전혀 쓰이지 않음)

[Fold 2]
1. 훈련(2017~2018) ──> 2. 검증(2019) ──> 3. 적용(2020)

... (Fold 3 ~ Fold 7 순차 실행, 매년 한 칸씩 밀기)

[Fold 8] 훈련(2023~2024) ──> 검증(2025) ──> 적용(2026-01-01 ~ 2026-08-31, 8개월)
```

> 💡 **마지막 Fold만 8개월인 이유**: 데이터가 2026년 8월 31일에서 끝나기 때문입니다. Fold별 적용 결과는 연 수익률로 환산하지 말고 그 구간의 누적 수익률로 읽으세요. 8개월 수익률을 연 수익률로 바꾸면 부풀려집니다.

**후보가 5개뿐인 이유**: 클립 17에서 5일~250일 50개를 다 열어 두니, 그 3년에만 맞은 5일선이 1등으로 뽑혔습니다. 여기서는 추세추종에서 흔히 쓰는 기간 5개로 후보를 미리 좁힙니다. 후보를 논리 있는 값으로 좁히는 것 자체가 과최적화를 막는 첫 번째 장치입니다.

---

### 2. 파라미터 안정성(Stability)의 발견

WFA를 실행해 보면, 좋은 전략은 훈련 구간이 바뀌어도 최적 파라미터가 크게 튀지 않고 일정한 범위($N=150 \sim 200$) 안에서 머무는 것을 확인할 수 있습니다. 반면 불안정한 전략은 후보군의 양 끝을 오가며 $N=60 \to N=200 \to N=100$처럼 요동칩니다.

## 실습 — 실습 08: 추세추종 8-Fold 워크포워드 검증 실행

Claude Code 대화창에 아래의 표준 WFA 백테스트 프롬프트를 입력하세요.

```prompt
[맥락] KODEX 200(069500) 대상 추세추종 전략을 훈련 → 검증 → 적용 8-Fold 워크포워드(WFA)로 검증하고 싶어.

[만들 것] 다음 조건에 맞춰 파이썬 WFA 백테스트 스크립트 'wfa_single_strategy.py'를 작성하고 실행해줘:
1. 2016-01-01부터 2026-08-31까지의 KODEX 200 일봉 데이터를 불러와줘. (200일선 계산을 위한 워밍업 기간을 포함해 충분히 불러와줘.)
2. 훈련 2년 → 검증 1년 → 적용 1년을 1년씩 밀며 8개 Fold로 나눠줘:
   - Fold 1: 훈련(2016~2017) ➔ 검증(2018) ➔ 적용(2019)
   - Fold 2: 훈련(2017~2018) ➔ 검증(2019) ➔ 적용(2020)
   - Fold 3: 훈련(2018~2019) ➔ 검증(2020) ➔ 적용(2021)
   - Fold 4: 훈련(2019~2020) ➔ 검증(2021) ➔ 적용(2022)
   - Fold 5: 훈련(2020~2021) ➔ 검증(2022) ➔ 적용(2023)
   - Fold 6: 훈련(2021~2022) ➔ 검증(2023) ➔ 적용(2024)
   - Fold 7: 훈련(2022~2023) ➔ 검증(2024) ➔ 적용(2025)
   - Fold 8: 훈련(2023~2024) ➔ 검증(2025) ➔ 적용(2026-01-01 ~ 2026-08-31)
3. 규칙은 "당일 종가가 N일 이동평균선 위면 다음 거래일 시가에 보유, 아래면 현금"이고, 매매마다 왕복 0.05%(ETF라 거래세 없음)를 차감해줘. 후보는 N = 60, 100, 120, 150, 200일이야.
4. 각 Fold에서:
   - 훈련 구간 샤프 지수 1위 N*를 골라줘.
   - 상대 WFE = (검증 구간 CAGR − 같은 기간 200일선 CAGR) ÷ (훈련 구간 CAGR − 같은 기간 200일선 CAGR) × 100을 계산해줘.
   - 상대 WFE가 60% 이상이면 적용 구간에 N*를 쓰고, 아니거나 N*가 200일이면 200일선을 써줘.
5. Fold별로 [N*, 훈련 CAGR(N*/200일선), 검증 CAGR(N*/200일선), 상대 WFE, 적용한 파라미터, 적용 구간 누적 수익률(적용한 파라미터/200일선)]을 Markdown 표로 대화창에 출력해줘. 표 아래에는 적용 구간을 이어 붙인 전체(2019-01-01 ~ 2026-08-31)의 CAGR·MDD·샤프·현금 비중을 [워크포워드], [고정 200일선], [단순 보유(참고)] 세 줄로 나란히 적어줘.
6. 상단에는 이어 붙인 워크포워드 누적 수익률 곡선, 같은 기간 고정 200일선 곡선, 단순 보유 곡선(참고, 회색 점선)을 겹쳐 그리고, 워크포워드가 현금으로 있던 구간을 옅은 음영으로 표시해줘. 하단에는 Fold별 상대 WFE 막대(60% 기준선 표시)를 그려 2-패널 대화형 Plotly 차트 'wfa_single_strategy_result.html' 파일로 저장해줘. 제목·부제·범례·주석 글자가 서로 겹치거나 곡선·막대에 가려지지 않게 배치하고, 긴 설명은 차트에 넣지 말고 대화창에 적어줘. 값이 너무 커서 축을 벗어나는 막대는 축을 늘리지 말고 막대 위에 숫자만 적어줘.

[하지 말 것]
- N*는 훈련 구간만으로 골라. 검증 구간에서 후보를 다시 고르지 마. 검증은 N*를 확인하는 데만 써.
- 적용 구간 데이터는 고르거나 확인하는 데 한 줄도 쓰지 마.
- 신호 당일 종가로 즉시 체결하지 말고, 반드시 익일 시가에 체결되도록 해.
- 결과가 나쁘게 나온 Fold를 빼거나 후보·기준(60%)을 바꿔 다시 돌리지 마. 나온 대로 보고해.
- 8개월짜리 마지막 적용 구간을 연 수익률로 환산해 표에 넣지 마. 누적 수익률로 적어.
- 화면을 멈추게 만드는 대화형 창을 띄우지 말고 단독 실행 가능한 HTML 파일(fig.write_html)로 직접 저장해.

[확인] 대화창에 8개 Fold 결정표와 [워크포워드 / 고정 200일선 / 단순 보유] 전체 성과 세 줄이 출력되었는지, 그리고 대화형 차트 파일 'wfa_single_strategy_result.html'이 2-패널로 정상 저장되었는지 확인해줘. 차트를 열었을 때 글자끼리 겹치는 곳이 있으면 고쳐서 다시 저장해줘.
```

### 내 눈으로 확인할 체크리스트

- [ ] 8개 Fold별로 훈련 1등(N*)이 무엇이었고, 그중 몇 번이 검증을 통과했는지 확인했다.
- [ ] 검증에서 탈락한 Fold가 있다면, 그 Fold의 적용 구간에서 N*를 그대로 썼다면 어땠을지 표의 숫자로 짐작해 봤다.
- [ ] 생성된 `wfa_single_strategy_result.html`을 브라우저로 열어, 이어 붙인 워크포워드 곡선과 고정 200일선 곡선이 어디서 얼마나 벌어지는지 확인했다.
- [ ] 곡선이 평평하게 누운 구간이 현금 음영과 겹치는지 확인하고, 그 기간에 단순 보유 곡선은 어떻게 움직였는지 비교했다.
- [ ] 워크포워드가 고정 200일선보다 나은지, 비슷한지, 못한지를 전체 성과 두 줄로 판정했다. 어느 쪽이 나오든 그대로 기록했다.
