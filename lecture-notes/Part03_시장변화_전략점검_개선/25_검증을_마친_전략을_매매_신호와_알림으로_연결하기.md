## 실습 — 실습 14: 실전 시그널 생성기 모듈 구축

Claude Code 대화창에 아래 프롬프트를 입력하여 실전 시그널 생성 파이썬 모듈을 완성하세요.

```prompt
Part 2와 3에서 검증된 전략들을 통합하여 매일 아침 매매 신호를 생성하는 'generate_signals.py' 모듈을 완성해줘. (Context)

다음 요구사항에 맞춰 파이썬 스크립트를 작성하고 실행해줘: (Deliverable)
1. FinanceDataReader를 통해 4대 전략 대상 종목들의 최근 250거래일 데이터를 최신 시점으로 불러와줘.
2. 현재 시장 국면(상승/하락/횡보)을 진단하고, 4대 전략(추세, 돌파, 모멘텀, 페어)의 오늘 진입/청산/유지 신호를 계산해줘.
3. 총 투자 가능 자산(예: 1,000만 원)을 기준으로 종목별 목표 매수 수량(주수)과 필수 안전 손절가(-3% 하드 손절)를 산출해줘.
4. 산출된 전체 신호를 'signals.json' 파일로 저장해줘.
5. 대화창에는 운영자가 한눈에 확인할 수 있는 '오늘의 매매 실행 브리핑 요약표'를 깔끔하게 출력해줘.

실행 완료 후 화면에 시그널 표를 출력하고 'signals.json' 파일 내용을 확인시켜줘. (Verification)
```

### 내 눈으로 확인할 체크리스트

- [ ] `generate_signals.py`가 에러 없이 실행되어 최신 주가 기반으로 신호를 산출했다.
- [ ] 화면에 오늘 매수/매도해야 할 종목, 진입 가격, 목표 주문 수량, 손절가가 명확히 출력되었다.
- [ ] 프로젝트 루트에 구조화된 `signals.json` 파일이 생성된 것을 확인했다.
