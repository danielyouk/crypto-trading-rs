## 이번 클립에서 만들 것

이 클립이 끝나면, 매일 아침 컴퓨터 앞에 앉지 않아도 **장 시작 전에 시스템이 자동으로 켜지고, 장 마감 후 정리 작업까지 하고 스스로 꺼지는** 운영 체계가 완성됩니다.

- Windows 작업 스케줄러에 등록된 시작·종료 작업
- 아침에 "시스템 시작" 알림, 저녁에 "시스템 종료 + 다음 거래일 시나리오" 알림이 자동으로 도착

## 이론 핵심

### 수동 실행의 함정

시스템이 아무리 좋아도 **켜는 것을 잊으면 그날은 없는 시스템**입니다. 사람의 기억력에 기대는 운영은 반드시 구멍이 납니다. 실행 자체를 자동화하면, 사람은 "켜기"가 아니라 "판단"에만 집중할 수 있습니다. 이것이 파이널 프로젝트의 마지막 조각입니다.

### Windows 작업 스케줄러

Windows에 내장된 **작업 스케줄러**는 "매일 몇 시에 이 프로그램을 실행하라"를 등록해 두는 도구입니다. 우리가 등록할 작업은 두 개입니다.

| 작업 | 시각(예시) | 하는 일 |
|---|---|---|
| 장 시작 준비 | 평일 08:50 | 시스템 시작 → 계좌·시세 연결 → "시작됨" 알림 |
| 장 마감 정리 | 평일 15:40 | 시스템 종료 → 로그 정리 → 다음 거래일 시나리오 알림 |

등록 자체도 AI에게 시킬 수 있습니다. 다만 **등록이 됐는지, 실제로 그 시각에 돌았는지는 여러분이 작업 스케줄러 화면과 알림으로 확인**합니다.

### 자동 실행일수록 시작 알림이 중요하다

자동화의 역설: 사람이 안 켜니까, **켜졌는지도 모르게 됩니다**. 그래서 시작 작업의 마지막은 반드시 "시스템 시작됨, 계좌 연결 정상" 알림이어야 합니다. 아침 알림이 안 왔다면 그 자체가 "뭔가 잘못됐다"는 신호입니다. 알림이 침묵하는 시스템은 고장을 알 방법이 없습니다.

## 실습 19 — 장 운영 시간에 맞춘 자동 실행 등록

```prompt
내 트레이딩 시스템을 Windows 작업 스케줄러에 등록해줘.
평일 오전 8시 50분에 시스템이 자동 시작되어 계좌 연결과 시세 수신을 확인한 뒤
"시스템 시작: 계좌 연결 정상"이 텔레그램으로 와야 하고,
평일 오후 3시 40분에는 시스템을 종료하면서
"시스템 종료 + 다음 거래일 시나리오" 알림이 와야 해.
등록이 끝나면 작업 스케줄러에서 두 작업이 보이는 화면을 확인할 수 있게 해주고,
지금 시작 작업을 수동으로 한 번 실행해서 시작 알림이 오는 것까지 보여줘.
```

### 내 눈으로 확인할 체크리스트

- [ ] Windows 작업 스케줄러 화면에 시작·종료 작업 두 개가 등록되어 있다
- [ ] 시작 작업을 수동 실행하면 "시스템 시작: 계좌 연결 정상" 알림이 온다
- [ ] 종료 작업을 수동 실행하면 종료 + 다음 거래일 시나리오 알림이 온다
- [ ] (다음 거래일 아침) 손대지 않았는데 8시 50분에 시작 알림이 실제로 도착했다

## 자주 발생하는 문제

강사와 여러분의 등록 방식(명령어·경로)은 다를 수 있습니다. 작업 스케줄러 화면에 작업이 보이고, 정해진 시각에 알림이 오면 정상입니다.

- **경로 문제**: 스케줄러가 실행하는 환경은 여러분이 쓰던 터미널과 달라서, 프로그램·폴더 경로를 못 찾는 오류가 가장 흔합니다.
- **컴퓨터가 꺼져 있거나 절전 모드**: 스케줄러는 컴퓨터가 켜져 있어야 동작합니다. 절전 해제 설정이 필요할 수 있습니다.
- **주말·휴장일**: 평일 조건만으로는 공휴일에도 실행됩니다. 휴장일에는 시작 후 "오늘은 휴장일" 알림만 보내고 종료하게 할 수 있습니다.

```prompt
작업 스케줄러에서 수동 실행하면 되는데, 정해진 시각에는 시스템이 안 켜져.
작업의 실행 결과 코드와 실행 조건(절전, 로그인 여부)을 확인해서
매일 아침 자동으로 켜지도록 고쳐줘.
```

```prompt
공휴일에도 시스템이 켜졌어. 시작할 때 오늘이 휴장일인지 확인해서,
휴장일이면 "오늘은 휴장일입니다" 알림만 보내고 바로 종료하게 해줘.
```
