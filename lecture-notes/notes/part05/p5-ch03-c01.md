## 이번 클립에서 만들 것

이 클립이 끝나면, 내 시스템이 **한 달에 AI 비용을 얼마나 쓰는지** 파악하고, 그 비용을 줄이는 세 가지 방법을 내 운영 방식에 적용할 수 있습니다.

- 내 사용 패턴에 맞는 과금 방식(API 종량제 vs 정액제) 판단 기준
- 작업 종류별로 모델을 나눠 쓰는 역할 분담표

## 이론 핵심

### 비용 구조부터 이해하기

AI 사용 비용은 크게 두 갈래입니다.

| 방식 | 과금 | 어울리는 경우 |
|---|---|---|
| API Key (종량제) | 사용한 토큰만큼 | 자동화된 일일 보고서·분석처럼 호출량이 예측되는 작업 |
| 정액제 (예: Claude Code Max) | 월 고정 요금 | 대화하며 개발·개선하는 작업이 많은 경우 |

우리 시스템은 두 가지를 병행합니다 — 매일 자동으로 도는 보고서·분석은 API, 전략을 개선하고 기능을 추가하는 대화형 작업은 정액제 도구가 자연스럽습니다.

### 비용 절감의 세 가지 지렛대

1. **캐시 활용** — 매일 반복되는 프롬프트(보고서 양식, 전략 설명 등)는 캐시가 적용되게 구성하면 같은 내용을 매번 새로 과금하지 않습니다.
2. **저가 모델 혼용** — 모든 작업에 최고 모델이 필요하지 않습니다. 표 정리·요약 같은 단순 작업은 저가 모델로 충분합니다.
3. **호출 횟수 자체 줄이기** — 장중에 불필요하게 AI를 부르지 않도록, AI 호출이 필요한 시점(장 마감 후 분석 등)을 미리 정해둡니다.

### 모델별 역할 분담

| 작업 | 필요 수준 | 모델 |
|---|---|---|
| 일일 보고서 표 정리·요약 | 낮음 | 저가 모델 |
| 손실 원인 분석·개선안 생성 | 높음 | 상위 모델 |
| 전략 개발·기능 추가 (대화형) | 높음 | 정액제 코딩 도구 |

## 따라 해보기

내 시스템의 비용 구조를 직접 점검해 보세요.

```prompt
내 트레이딩 시스템에서 AI를 호출하는 지점을 전부 찾아서,
각 지점의 하루 호출 횟수·사용 모델·예상 월 비용을 표로 정리해줘.
저가 모델로 바꿔도 되는 지점이 있다면 표시하고,
바꿨을 때 예상 절감액도 보여줘.
```

- [ ] 내 시스템의 AI 호출 지점과 월 예상 비용을 숫자로 안다
- [ ] 저가 모델로 내려도 되는 작업을 한 가지 이상 찾았다
- [ ] 종량제와 정액제 중 내 패턴에 맞는 조합을 정했다

## 자주 발생하는 문제

비용 추정치는 강사와 다르게 나올 수 있습니다. 모델 가격은 수시로 바뀌고 사용량도 사람마다 다르므로, 정확한 금액보다 **어디서 많이 쓰는지 순위**를 파악하는 것이 목적입니다.

- 비용 표가 실제 청구액과 크게 다를 때:

```prompt
예상 비용이 실제 청구 내역과 달라. 최신 모델 가격표를 기준으로
다시 계산하고, 계산에 사용한 단가를 표에 함께 표시해줘.
```
