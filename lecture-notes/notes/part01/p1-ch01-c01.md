## 이번 클립에서 만들 것

이 클립이 끝나면, 우리가 이 강의에서 완성할 **트레이딩 시스템의 전체 모습**이 머릿속에 그려집니다. 직접 만드는 것은 다음 클립부터지만, 오늘은 완성된 시스템이 실제로 돌아가는 장면을 데모로 봅니다.

- 시그널 발생 → 텔레그램 알림 → 사람이 승인 → 모의주문 실행 → 일일 리포트 생성
- 이 모든 과정에서 **코드를 한 줄도 직접 작성하지 않았다**는 점

## 이론 핵심

### 100% 자동수익은 없다

완전 자동매매로 꾸준한 수익을 내는 시스템은 전문 퀀트에게도 어려운 영역입니다. 이 강의가 지향하는 것은 **인간 개입형 하이브리드 시스템**입니다.

| 역할 | 담당 |
|---|---|
| 데이터 수집·시그널 생성·보고서 작성 | 시스템(AI) |
| 매수 승인 여부 판단 | **사람(나)** |
| 빠른 대응이 필요한 손절 | 미리 정한 규칙 |

### 코딩이 아니라 사고 방식을 배운다

이 강의에서 우리가 반복할 작업 루프는 네 단계입니다.

1. **생각** — 이 작업이 끝나면 화면에 뭐가 보여야 하지?
2. **요청** — 결과 모습이 담긴 목표를 프롬프트로 전달
3. **확인** — 사람이 눈으로 화면을 직접 확인 (AI에게 확인을 시키지 않음)
4. **개선** — 부족하면 후속 프롬프트

강사와 여러분의 결과 코드는 다를 수 있습니다. 중요한 것은 코드가 아니라 **차트·표·알림·동작이 목표와 맞는지**입니다.

### 앞으로 5개 파트의 여정

1. Claude Code로 첫 결과물 만들기 (지금)
2. 4가지 투자 전략을 이해하고 백테스트로 검증
3. 워크포워드로 실전처럼 점검하고 손실 후 개선
4. 증권사 API 연동 — 시그널→승인→모의주문
5. 매일의 결과 분석과 안전한 운영

## 실습

이번 클립은 데모 시청이 중심입니다. 강의를 보며 아래 항목을 확인해 보세요.

- [ ] 시그널이 발생했을 때 텔레그램 알림이 어떤 형태로 오는지 보았다
- [ ] 사람이 승인 버튼을 누른 뒤에만 모의주문이 실행되는 것을 확인했다
- [ ] 장 마감 후 일일 리포트에 어떤 내용이 담기는지 보았다

## 자주 발생하는 문제

> 이 클립은 시청만 하므로 실습 오류는 없습니다. 다만 "나도 저걸 만들 수 있을까?"라는 의문이 드는 것이 정상입니다. 다음 4개 클립을 통과하면 첫 차트가 여러분 화면에 뜹니다.
