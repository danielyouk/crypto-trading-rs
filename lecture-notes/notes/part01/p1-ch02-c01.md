## 이번 클립에서 만들 것

이 클립이 끝나면 여러분 컴퓨터에 다음이 준비됩니다.

- Claude Code(또는 Cursor)가 설치되어 대화창이 열린 상태
- 주식 데이터를 다룰 수 있는 Python 환경 (설치도 AI에게 시킵니다)
- 앞으로 강의 내내 사용할 작업 폴더 하나

## 이론 핵심

### 도구는 둘 중 하나면 충분하다

| 도구 | 형태 | 특징 |
|---|---|---|
| Claude Code | 터미널 기반 | 이 강의의 기본 도구 |
| Cursor | 에디터 기반 | 화면 구성이 익숙하면 선택 |

두 도구 모두 같은 방식(프롬프트로 목표 전달)으로 동작하므로, 강의는 Claude Code 기준으로 진행하되 Cursor 사용자도 그대로 따라올 수 있습니다.

### 비용은 투명하게

- API Key 방식: 쓴 만큼 과금 — 캐시를 활용하면 비용이 크게 줄어듭니다
- 정액제(Claude Pro/Max): 한도 내 사용 — 이 강의 분량은 한도 안에서 충분합니다

### 환경 설정도 프롬프트로 한다

Python, FinanceDataReader 같은 라이브러리 설치를 우리가 직접 하지 않습니다. **설치조차 AI에게 요청**하고, 우리는 설치가 끝났는지 화면으로 확인합니다. 이것이 이 강의의 첫 번째 사고 전환입니다.

## 실습 — 실습 01

작업 폴더를 만들고 Claude Code를 연 뒤, 아래 프롬프트를 입력하세요.

```prompt
지금부터 한국 주식 데이터를 분석하는 프로젝트를 시작할 거야.
Python 환경을 준비하고, 한국 주식 데이터를 불러올 수 있는
FinanceDataReader 라이브러리를 설치해줘.
설치가 끝나면 삼성전자(005930)의 어제 종가를 출력해서
환경이 정상 동작하는지 보여줘.
```

### 내 눈으로 확인할 체크리스트

- [ ] 설치 과정이 에러 없이 끝났다는 메시지를 보았다
- [ ] 삼성전자의 어제 종가 숫자가 화면에 출력되었다
- [ ] 출력된 종가가 포털 검색 결과와 대략 일치한다

## 자주 발생하는 문제

여러분 컴퓨터의 상태(기존 Python 유무, 운영체제)가 저와 다르므로 **설치 과정의 화면은 저와 다르게 보이는 것이 정상**입니다. 중요한 것은 마지막 체크리스트 3개가 통과되는지입니다.

설치 중 에러가 보이면 그대로 복사해서 후속 프롬프트를 보내세요.

```prompt
아래 에러가 발생했어. 원인을 설명하고 해결한 다음,
다시 삼성전자 어제 종가를 출력해줘.
[에러 메시지 붙여넣기]
```
