이론 핵심

파이프라인 여섯 단계

Part 2~3에서 검증한 전략이 실제 주문으로 이어지려면 여섯 단계가 연결되어야 합니다.

단계 하는 일 만드는 클립
① 계좌 연결 한국투자증권 모의투자 계좌 인증 ch01-c02
② 실시간 가격 감시 종목의 현재가 수신 ch01-c03
③ 시그널 엔진 전략 조건 충족 시 매수 후보 생성 + 로그 ch01-c04
④ 알림 텔레그램으로 승인·거절 버튼 전송 ch02-c01~02
⑤ 승인·주문 사람이 승인하면 모의주문 실행 ch02-c03
⑥ 위험 관리 손절 무응답 시 규칙이 자동 실행 ch02-c04

매수는 사람이, 손절은 규칙이

이 시스템의 핵심 원칙은 인간 개입형 하이브리드입니다.

  • 매수: 반드시 사람이 알림을 보고 승인해야 주문이 나갑니다. 승인 전에는 어떤 주문도 실행되지 않습니다.
  • 손절: 빠른 대응이 필요하므로, 알림에 일정 시간 응답이 없으면 미리 정한 규칙이 자동으로 실행합니다.

매수와 손절의 처리 방식이 왜 다른지가 이 파트 전체를 관통하는 질문입니다.

왜 모의투자부터 시작하는가

Part 4~5의 모든 주문은 모의투자 계좌에서 실행됩니다. 실제 돈이 나가는 실전 계좌는 시스템이 충분히 검증된 뒤(Part 5)에만 고려합니다. 모의투자는 실전과 동일한 API 구조를 쓰기 때문에, 여기서 완성한 시스템은 그대로 실전으로 옮길 수 있습니다.

이번 클립은 설계도 이해가 중심입니다. 강의를 보며 아래 항목을 확인해 보세요.

  • 매수와 손절의 처리 방식이 왜 다른지 설명할 수 있다
