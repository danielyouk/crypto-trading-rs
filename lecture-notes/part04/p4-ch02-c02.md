# 카카오톡과 이메일로 매매 알림 받아보기

## 이번 클립에서 만들 것

이 클립이 끝나면, 텔레그램 외에 **카카오톡과 이메일로도 같은 매매 알림**이 도착합니다.

- 카카오톡 "나에게 보내기"로 매수 신호 메시지 수신
- 이메일로 같은 내용의 알림 수신
- 채널별 역할 분담: 승인은 텔레그램, 기록·백업은 이메일

## 이론 핵심

### 알림 채널마다 성격이 다르다

| 채널 | 강점 | 한계 | 우리의 용도 |
|---|---|---|---|
| 텔레그램 | 인라인 버튼으로 즉시 응답 | 앱 설치 필요 | **승인·거절 (주 채널)** |
| 카카오톡 | 가장 자주 보는 앱 | 버튼 응답 불가, 발송 제약 | 신호 인지 보조 |
| 이메일 | 기록이 남고 검색 가능 | 즉시성 낮음 | 일일 기록·백업 |

핵심은 **승인 기능은 텔레그램에만 둔다**는 것입니다. 카카오톡·이메일은 "신호가 났다"는 사실을 놓치지 않게 돕는 보조 채널입니다. 승인 관문이 여러 개면 어디서 승인했는지 꼬입니다.

### 카카오톡 알림의 현실적인 제약

카카오톡은 텔레그램처럼 자유로운 봇을 열어주지 않습니다. 개인이 쓸 수 있는 현실적인 방법은 카카오 개발자 사이트에서 앱을 만들고 **"나에게 보내기" API**를 쓰는 것입니다. 이 방식은 내 계정으로 나에게만 보낼 수 있고, 토큰을 주기적으로 갱신해야 하는 번거로움이 있습니다. 그래서 이 강의는 카카오톡을 필수가 아닌 **선택 확장**으로 둡니다.

### 이메일은 가장 오래된, 가장 확실한 백업

이메일 발송은 API 승인 절차가 없고, 지메일 등의 **앱 비밀번호**만 있으면 됩니다(이 비밀번호도 `.env`로 관리). 즉시 확인용은 아니지만, 알림이 메일함에 차곡차곡 쌓이므로 나중에 "그날 무슨 신호가 있었지?"를 검색할 수 있는 기록 보관소가 됩니다.

## 따라 해보기

이번 클립은 실습 15의 선택 확장입니다. 원하는 채널만 추가해 보세요.

```prompt
매수 신호가 발생하면 텔레그램 알림과 함께, 같은 내용을 내 이메일로도 보내줘.
이메일 계정 정보는 .env 파일에 저장해 뒀어.
테스트 신호를 발생시켜서 메일함에 "매수 신호" 제목의 메일이 도착한 것을 보여줘.
```

- [ ] 테스트 신호 발생 시 이메일(또는 카카오톡)에 같은 내용의 알림이 도착했다
- [ ] 승인·거절 버튼은 여전히 텔레그램에만 있다
- [ ] 이메일 앱 비밀번호가 채팅이나 코드에 노출되지 않았다

## 자주 발생하는 문제

강사와 여러분의 결과가 가장 크게 갈릴 수 있는 클립입니다. 카카오 API는 심사·설정 화면이 자주 바뀌므로, 막히면 카카오톡은 건너뛰고 이메일만 붙여도 시스템 완성에는 지장이 없습니다.

- **카카오 토큰 만료**: "나에게 보내기" 토큰은 유효기간이 짧아 갱신 처리가 필요합니다.
- **이메일 인증 실패**: 계정 비밀번호가 아니라 **앱 비밀번호**를 써야 하는 경우가 대부분입니다.

```prompt
이메일 발송에서 인증 오류가 났어. 오류 메시지를 보여주고,
앱 비밀번호 방식으로 로그인하도록 확인해서 고쳐줘.
```
