# 한국투자증권 API와 모의투자 계좌 연결하기

## 이번 클립에서 만들 것

이 클립이 끝나면, 여러분의 트레이딩 시스템이 **한국투자증권 모의투자 계좌에 연결**되고, 화면에 계좌 잔고가 표로 나타납니다.

- KIS Developers에서 앱키·앱시크릿 발급 완료
- 모의투자 계좌 개설 완료
- 시스템이 접근토큰을 발급받아 계좌 잔고를 조회하는 화면

## 이론 핵심

### KIS Developers와 오픈 API

한국투자증권은 개인 투자자에게 **KIS Developers**라는 오픈 API를 제공합니다. 홈페이지에서 신청하면 두 가지 열쇠를 받습니다.

- **앱키(App Key)**: 나를 식별하는 공개 아이디 성격의 값
- **앱시크릿(App Secret)**: 비밀번호 성격의 값 — 절대 외부에 노출하면 안 됩니다

시스템은 이 두 값으로 **접근토큰**을 발급받고, 토큰을 붙여서 잔고 조회·시세 조회·주문 같은 요청을 보냅니다. 토큰은 유효기간이 있어 만료되면 재발급해야 하는데, 이 재발급도 AI가 만든 코드가 자동으로 처리하게 합니다.

### 모의투자 서버와 실전 서버는 주소가 다르다

같은 API라도 모의투자와 실전투자는 **서버 주소와 계좌번호가 다릅니다**. 우리는 Part 4~5 내내 모의투자 서버만 사용합니다. 실전 서버 주소가 코드에 들어가 있지 않은지 확인하는 것도 체크리스트에 포함됩니다.

### 보안 원칙: 키는 .env 파일로만 관리한다

이 강의에서 가장 중요한 보안 규칙입니다.

- 앱키·앱시크릿·계좌번호는 **채팅창이나 코드에 절대 그대로 붙여넣지 않습니다.**
- 프로젝트 폴더의 `.env` 파일에만 저장하고, 코드는 그 파일을 읽어 쓰도록 AI에게 요청합니다.
- `.env` 파일은 git 같은 공유 도구에 올라가지 않도록 제외 처리합니다.

AI에게 키를 채팅으로 알려주면 대화 기록에 남습니다. "키는 .env에서 읽어라"라고만 말하면 됩니다.

## 실습 12 — 모의투자 계좌 연결하고 잔고 확인하기

먼저 KIS Developers에서 앱키·앱시크릿을 발급받고 모의투자 계좌를 개설한 뒤, 두 값을 `.env` 파일에 직접 입력해 두세요. 그다음 AI에게 요청합니다.

```prompt
프로젝트 폴더의 .env 파일에 한국투자증권 모의투자용 앱키, 앱시크릿, 계좌번호를
저장해 두었어. 이 값을 읽어서 모의투자 계좌에 연결하고 계좌 잔고를 표로 보여줘.
연결에 성공하면 계좌번호 끝 4자리와 예수금이 화면에 보여야 해.
앱키나 앱시크릿 값 자체는 화면에 출력하지 마.
```

### 내 눈으로 확인할 체크리스트

- [ ] 화면에 계좌번호 끝 4자리와 예수금(모의투자 초기 자금)이 표로 보인다
- [ ] 앱키·앱시크릿 값이 화면 어디에도 출력되지 않았다
- [ ] `.env` 파일이 프로젝트에 있고, 키를 채팅창에 붙여넣은 적이 없다
- [ ] 접근토큰 발급에 성공했다는 메시지(또는 로그)를 확인했다

## 자주 발생하는 문제

강사와 여러분의 AI가 생성한 코드는 다를 수 있습니다. 코드가 같은지가 아니라 **체크리스트의 화면이 나오는지**를 보세요. 이 클립에서 특히 자주 발생하는 문제는 다음과 같습니다.

- **앱키·앱시크릿 오타**: 복사할 때 앞뒤 공백이 섞이면 인증에 실패합니다. `.env` 값을 다시 확인하세요.
- **모의투자/실전 서버 혼동**: 실전 서버 주소로 요청하면 모의투자 키로는 인증이 거부됩니다.
- **토큰 만료·발급 제한**: 접근토큰은 발급 횟수 제한이 있어, 너무 자주 재발급하면 일시적으로 거부될 수 있습니다.

결과가 다르면 이렇게 후속 요청을 하세요.

```prompt
계좌 연결에서 인증 오류가 났어. 오류 메시지를 그대로 보여주고,
모의투자 서버 주소를 쓰고 있는지, .env의 키를 제대로 읽었는지 확인해서 고쳐줘.
```

```prompt
접근토큰을 매번 새로 발급하지 말고, 유효한 토큰이 있으면 재사용하도록 바꿔줘.
바꾼 뒤에도 잔고 표가 똑같이 보여야 해.
```
