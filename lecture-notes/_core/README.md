# AI 알고리즘 트레이딩 강의 교재 & 빌드 가이드

> **"수강생 여러분만의 살아있는 투자 전략 핸드북을 만드세요."**
> 
> 이 폴더는 단순한 정적 교재가 아니라, 여러분이 강의를 들으며 직접 수정하고 백테스트 결과를 덧붙여 나만의 웹북으로 빌드할 수 있는 **Docs-as-Code(코드형 문서)** 환경입니다.

## 1. 폴더 구조 (수강생 배포용 깔끔한 구조)

폴더를 열었을 때 복잡한 설정 파일 없이 **전체 목차 파일**과 **5개 Part 폴더**가 가장 먼저 보입니다. 마크다운 원본(`.md`)과 웹 교재(`.html`)는 각 한국어 Part 폴더 안에 나란히 위치합니다.

```
lecture-notes/
├── 00_AI트레이딩_전체교재_목차.html               # 🌟 전체 교재 목차 (브라우저로 더블클릭)
│
├── Part01_AI트레이딩_시스템_이해/                # Part 1: AI와 함께 시작하는 트레이딩 시스템

│   ├── 01_코딩을_몰라도_나만의_트레이딩_시스템을_만들_수_있을까.html

├── Part02_4대_투자전략_백테스트/                 # Part 2: 4가지 투자 전략 백테스트

    └── template/                              # 웹 교재 HTML/CSS 템플릿
```

## 2. 교재 열람 방법 (브라우저로 바로 보기)

별도의 웹 서버나 복잡한 설치 없이, **`lecture-notes/00_AI트레이딩_전체교재_목차.html`**을 크롬이나 엣지 브라우저로 더블클릭해서 열면 됩니다.

- **화면 배치 추천**: 모니터 **좌측 절반에 HTML 교재**를 띄우고, **우측 절반에 Claude Code / Cursor**를 띄워 실습하세요.
- **프롬프트 복사**: 교재 안의 프롬프트 블록 우측 상단 `[프롬프트 복사]` 버튼을 누르면 AI에게 보낼 명령어가 클립보드에 바로 복사됩니다.
- **체크리스트**: 강의를 들으며 `[ ]` 체크박스를 직접 클릭하여 실습 완성을 점검할 수 있습니다.
- **오프라인 동작**: 모든 스타일시트와 로고가 단일 HTML 내에 안전하게 탑재되어 있어 인터넷 연결 없이도 완벽하게 열람할 수 있습니다.

## 3. 수강생을 위한 나만의 교재 커스터마이징 & 빌드 방법

수강생 여러분은 제공된 마크다운(`.md`) 파일을 나만의 노트로 자유롭게 발전시킬 수 있습니다:

1. **관심 종목 변경**: `Part02_4대_투자전략_백테스트/09_추세추종_전략을_과거_데이터로_검증하기.md`의 프롬프트 템플릿에 삼성전자 대신 자신이 관심 있는 종목(예: SK하이닉스, 현대차 등)을 적어두기.
2. **실습 결과 및 메모 기록**: 직접 돌려본 백테스트 CAGR, MDD 수치나 개인적인 깨달음을 각 `.md` 파일 하단에 자유롭게 추가.
3. **나만의 프롬프트 보관**: AI와 대화하며 가장 효과적이었던 후속 프롬프트를 노트에 정리.

### ⚡ 1초 만에 HTML 다시 빌드하기

`.md` 파일을 수정한 뒤, AI 대화창에 `"교재 HTML을 다시 빌드해줘"`라고 요청하거나 다음 명령을 실행하면 모든 HTML 웹 페이지가 즉시 새로고침됩니다:

```bash
# lecture-notes 폴더 안에서 실행할 때
python _core/build.py

# 또는 프로젝트 루트 폴더에서 실행할 때
python runners/build_lecture_notes.py
```

빌드가 끝나면 브라우저에서 `F5(새로고침)`만 누르면 여러분이 추가한 나만의 메모와 백테스트 수치가 깔끔한 웹북으로 반영됩니다.
