## 이론 핵심

### 1. 공적분(Cointegration) 페어 발굴 알고리즘

단순히 두 종목을 눈대중으로 고르는 것이 아니라, 파이썬의 통계 패키지(`statsmodels`)를 활용해 잔차(Residual)의 정상성을 수학적으로 검정(ADF Test)합니다.

```text
[후보군 선정] ──> 동일 섹터 내 시가총액 상위 종목 쌍 (예: KB금융 vs 신한지주, 현대차 vs 기아)
      ↓
[회귀분석]   ──> Price_A = alpha + beta * Price_B + Residuals
      ↓
[ADF 검정]   ──> 잔차(Residuals)의 p-value < 0.05 판정
                  • p < 0.05 ➔ 공적분 성립 (페어트레이딩 적격)
                  • p >= 0.05 ➔ 무늬만 상관관계 (페어트레이딩 탈락)
```

## 실습 — 실습 07: 금융 섹터 페어 발굴 및 백테스트 실행

Claude Code 대화창에 아래의 페어트레이딩 백테스트 프롬프트를 입력하세요.

```prompt
한국 금융지주 대표 종목(KB금융 vs 신한지주)을 대상으로 페어트레이딩 백테스트를 수행해줘. (Context)

다음 요구사항에 맞춰 파이썬 스크립트를 작성하고 실행해줘: (Deliverable)
1. FinanceDataReader를 사용해 KB금융(105560)과 신한지주(055550)의 최근 5년(2019~2024) 일봉 데이터를 수집해줘.
2. 두 종목의 가격 비율(KB금융/신한지주)을 구하고 60일 롤링 윈도우 Z-Score를 산출해줘.
3. 롱 온리(Long-Only) 상대가치 페어 스위칭 전략 백테스트:
   - $Z \le -1.5$: KB금융이 극단적 저평가 상태 ➔ KB금융 100% 매수 보유
   - $Z \ge +1.5$: 신한지주가 극단적 저평가 상태 ➔ 신한지주 100% 매수 보유
   - $-0.5 < Z < +0.5$: 균형 상태 ➔ 기존 포지션 유지 또는 50:50 분할
   - 포지션 교체 시 편도 0.15% 거래비용 차감.
4. 개별 종목 단순 보유(KB금융 B&H, 신한지주 B&H)와 페어 스위칭 전략의 CAGR, MDD, 샤프 지수, 총 거래 횟수를 비교하는 표를 대화창에 출력해줘.
5. 상단에는 누적 수익률 비교 곡선, 하단에는 Z-Score 및 매매 체결 구간을 표시한 차트를 'pair_trading_backtest_result.png'로 저장해줘.

실행 완료 후 화면에 성과 비교표를 출력하고 차트 저장 경로를 알려줘. (Verification)
```

## Part 2 종합 결산: 4대 핵심 퀀트 전략 비교 요약
