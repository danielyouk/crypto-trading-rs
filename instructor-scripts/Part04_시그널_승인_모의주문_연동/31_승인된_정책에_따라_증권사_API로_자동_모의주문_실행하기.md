# 승인된 정책에 따라 증권사 API로 자동 모의주문 실행하기

## 도입 멘트 (2분)

지난 클립에서 우리가 주말에 승인한 `weekly_policy.json` 정책 파일이 만들어졌습니다. 이번 클립에서는 이 정책 파일을 실행 엔진에 주입하여, 평일 장중에 조건이 맞으면 한국투자증권 Open API를 통해 자동으로 모의주문이 발주되는 무인 실행 파이프라인을 구축합니다.

## 진행 흐름

- (0~2분) 도입: 주간 정책 파일(`weekly_policy.json`)과 실행 엔진의 연결 개념
- (2~6분) 이론: 안전 발주를 위한 사전 검증 3단계
  - 1회 주문 한도 확인 → 예수금 확인 → 중복 발주 방지 필터
- (6~14분) **모의주문 실행 시연**:
  - 스크립트 실행 후 `weekly_policy.json` 파싱
  - 테스트 조건 충족 시 모의투자 계좌로 1주 매수 API 호출
  - 반환된 주문 번호(ODNO) 및 체결 로그 화면 확인
- (14~18분) 한국투자증권 MTS/HTS 모의투자 잔고 화면 대조
  - 화면에 뜬 주문 번호와 모의투자 계좌의 실제 체결 내역 일치 확인
- (18~18분) 마무리 + 다음 클립 예고 (자동 하드 손절 및 서킷브레이커)

## 강사 멘트 & 강조 포인트

- **수강생 안심 멘트**: "모든 주문은 '모의투자 계좌'에서 100% 가상 머니로 실행됩니다. 실전 계좌 연결은 Part 5에서 모든 검증이 끝난 후 다루므로 안심하고 테스트하세요."
- **핵심 메시지**: "기계는 망설이지 않습니다. 우리가 사전에 합의한 조건이 발생하면 정확히 계산된 수량만큼 증권사로 주문을 쏩니다."

## 마무리 멘트 (1분)

내 코드가 증권사 서버와 통신하여 실제 계좌에 모의주문을 체결시켰습니다. 다음 클립에서는 이 시스템의 생명선인 '무인 하드 손절과 서킷브레이커'를 달아 안전성을 완성하겠습니다.
