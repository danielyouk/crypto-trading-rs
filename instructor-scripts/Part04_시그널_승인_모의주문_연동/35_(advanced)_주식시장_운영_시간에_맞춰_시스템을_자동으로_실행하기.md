# (advanced) 주식시장 운영 시간에 맞춰 시스템을 자동으로 실행하기

## 도입 멘트 (2분)

시스템은 완성됐는데, 매일 아침 여러분이 켜야 한다면 그건 반쪽짜리 자동화입니다. 켜는 것을 잊은 날, 시스템은 없는 것과 같으니까요. 오늘은 파이널 프로젝트의 마지막 조각, Windows 작업 스케줄러로 장 시작과 마감에 맞춰 시스템이 스스로 켜지고 꺼지게 만듭니다.

## 진행 흐름

- (0~2분) 도입
- (2~6분) 이론: 수동 실행의 함정 — 사람의 기억력에 기대는 운영은 반드시 구멍이 남
  - 등록할 두 작업: 08:50 시작(연결 확인 + 시작 알림), 15:40 정리(종료 + 시나리오 알림)
- (6~9분) 이론: 자동화의 역설 — 안 켜니까 켜졌는지도 모른다
  - 시작 알림 = 생존 신호. "아침 알림이 안 온 것 자체가 경고"
- (9~16분) **실습 19 시연**: 프롬프트 입력 → AI가 스케줄러 등록
  - 작업 스케줄러 화면을 직접 열어 두 작업이 등록된 것을 눈으로 확인
  - 시작 작업 수동 실행 → "시스템 시작: 계좌 연결 정상" 알림 도착
  - 종료 작업 수동 실행 → 종료 + 다음 거래일 시나리오 알림
- (16~19분) 자주 발생하는 문제 (경로 문제, 절전 모드, 휴장일 실행) + 후속 프롬프트 시연
- (19~20분) 마무리: 파이널 프로젝트 완성 선언

## 강조 포인트

- (advanced) 클립임을 안내 — 여기까지 안 해도 수동 실행으로 운영 가능, 부담 낮추기
- "다음 날 아침 알림이 실제로 왔는지"가 최종 체크리스트 — 촬영 시 실제 다음 날 알림 스크린샷을 준비해 보여줄 것
- 스케줄러 실행 환경은 백그라운드 환경이라 화면에 즉시 보이지 않을 수 있음(경로 문제) — 로그 파일에 남은 오류 메시지를 AI에 그대로 전달하는 습관 재강조
- Part 4 전체 회고 30초: 계좌 연결부터 자동 운영까지의 여정을 한 장으로

## 마무리 멘트 (1분)

축하합니다. 신호 생성부터 승인, 모의주문, 자동 손절, 자동 실행까지 — 파이널 프로젝트가 완성됐습니다. Part 5에서는 이 시스템이 매일 만들어내는 결과를 분석하고, 실전 전환 전에 필요한 안전장치를 더하겠습니다.
