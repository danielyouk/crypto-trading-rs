# 네 가지 전략의 수익률과 위험을 같은 기준으로 비교하기

## 도입 멘트 (2분)

Part 2를 마치신 것을 축하드립니다. 여러분 손에는 이제 퀀트 금융의 4대 핵심 전략 백테스트 결과가 모두 쥐어져 있습니다. 그런데 이 네 가지 전략, 그대로 나란히 비교하면 공정할까요? Part 2에서는 각 전략의 메커니즘을 보여드리기 위해 지수 ETF, 레버리지, 해외 자산배분, 개별 주식 페어처럼 서로 다른 자산으로 검증했습니다. 오늘은 이 네 전략을 동일한 시험대(2018~2026년 공통 구간, 동일 자본금, 동일 거래비용) 위에 올려놓고 공정하게 실력을 겨뤄보겠습니다. 그리고 넷을 한 계좌에서 25%씩 섞었을 때 어떤 마법이 일어나는지 직접 확인해 보겠습니다.

## 진행 흐름

- (0~2분) 도입: Part 2 결과물 회고 + "공정한 비교의 링에 올리기"
- (2~6분) 이론: 공정한 비교의 3조건 (동일 기간·동일 자금·동일 비용)
  - Part 2는 약 10년으로 맞췄으나, 앙상블에 들어가는 미국채 ETF(305080)가 2018년에 상장되어 공통 기간을 2018-01-01 ~ 2026-08-31(약 8.5년)로 통일함을 설명
  - 초기 자본 1,000만 원, 왕복 거래비용 0.25% 고정
- (6~11분) 이론: 수익률과 두 가지 위험 비교 잣대 (샤프 지수 vs 칼마 비율) + 다각화와 히트맵
  - CAGR 하나만 보면 안 되는 이유: -50% 손실은 원금 회복에 +100%가 필요
  - 일상적 출렁임의 위험: **샤프 지수** (승차감)
  - 최악 폭락의 위험: **칼마 비율** (CAGR ÷ |MDD|, 클립 07의 1번÷2번 나눗셈)
  - 세상에 모든 시장을 이기는 단일 전략은 없다 ➔ 4대 전략 25% 앙상블로 묶어 독립 베팅 수 $N$을 늘리는 원리
- (11~16분) **시연**: AI에게 통합 비교 대시보드 요청 ➔ 5행 성과표와 2패널 차트 확인
  - 5행 성과표(추세, VBO, 듀얼, 페어, 앙상블)에서 수익률 1위와 MDD 최소 전략이 서로 다름을 화면에서 짚기
  - 앙상블 행을 주목: 개별 전략보다 MDD가 얕아지고, **샤프 지수와 칼마 비율이 개별 전략 어느 것보다 높게 도약**함을 확인
  - 상단 차트: 울퉁불퉁한 개별 전략 곡선 대비 앙상블의 매끄러운 우상향 확인
  - 하단 차트: 전략 간 상관계수 히트맵에서 추세추종·페어·듀얼 간 상관이 낮음을 시각적으로 확인
- (16~18분) 마무리: "단일 전략 올인 대신 앙상블 분산이 해답이다. 그런데 성과가 너무 좋아 보이는 전략은 의심해야 한다" ➔ 다음 클립(과최적화) 복선

## 강조 포인트

- 시연 전에 반드시 "이 표에서 뭐가 보여야 하는지" 먼저 말하게 할 것 (생각→요청→확인 루프 습관화)
- 수강생 숫자가 강사와 다를 수 있음을 시연 중 한 번 언급 — 기준이 같은지가 핵심
- 수익률 1위 전략(예: 레버리지 VBO 등)을 칭찬하지 말 것. 다음 클립의 과최적화 및 리스크 복선으로 남겨둘 것
- 칼마 비율을 새 이론으로 어렵게 포장하지 말 것. "이미 배운 1번(CAGR)을 2번(MDD)으로 나눈 가성비"라고 편안하게 전달
- 앙상블에서 샤프 지수가 상승하는 모습을 보여주며, 클립 07에서 배운 다각화 공식이 실전에서 입증되었음을 자연스럽게 강조

## 마무리 멘트 (1분)

비교표에서 네 전략을 섞은 앙상블이 위험을 획기적으로 낮추는 것을 확인했습니다. 그런데 만약 어떤 전략 하나가 혼자서 연 50%에 MDD -3%처럼 비현실적으로 완벽하게 나온다면 기뻐해야 할까요? 좋아 보일수록 의심해야 합니다. 다음 클립에서는 "과거에만 잘 맞는 가짜 전략"을 골라내는 방법, 과최적화 이야기를 해보겠습니다.
