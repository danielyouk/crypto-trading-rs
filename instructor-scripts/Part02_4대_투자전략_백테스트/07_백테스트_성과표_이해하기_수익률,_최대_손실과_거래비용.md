# 백테스트 성과표 이해하기: 수익률, 최대 손실과 거래비용

## 도입 멘트 (2분)

"이 전략, 10년에 300% 벌었습니다." 유튜브에서 이런 말을 들으면 어떤 숫자를 물어봐야 할까요? 저라면 수익률은 안 물어봅니다. "그 10년 중 최악의 순간에 몇 % 잃고 있었나요?"를 묻습니다. 오늘은 성과표에서 진짜 봐야 할 숫자들 — CAGR, MDD, 거래비용 — 을 읽는 법을 배웁니다. Part 2 실습 내내 쓸 공통 언어입니다.

## 진행 흐름 (총 약 26~28분)

- (0~2분) **도입**: "300% 벌었다"에 되물어야 할 진짜 질문 ("최악의 순간에 몇 % 잃고 있었나요?")
- (2~8분) **이론: 4대 핵심 지표 매트릭스와 수계산**
  - **풀네임과 의미**: CAGR(Compound Annual Growth Rate), MDD(Maximum Drawdown), Sharpe Ratio, Win Rate / Payoff
  - **CAGR 수계산**: 1,000만 ➔ 3년 뒤 1,728만(72.8% 증가) 시 복리 20.0% 계산 (산술평균 24.3% 왜곡 및 +50%/-50% 변동성 손실 설명)
  - **CAGR vs Sharpe 산술평균의 의문 해소**:
    * 자산 최종 잔고는 복리(곱셈)이므로 **CAGR(기하평균)**만 진실
    * 샤프 지수는 확률분포의 평균/표준편차 비율을 재는 **통계적 모형**이며, 일간 단위에서는 산술평균과 기하평균 차이가 사실상 0
- (8~13분) **이론: Sharpe Ratio의 직관적 공식과 데이터 비대칭성**
  - **공식의 본질**: $\text{Sharpe} = \frac{R_{\text{연}} - R_{f,\text{연}}}{\sigma_{\text{연}}} = \frac{r_{\text{일}} \times 252 - R_{f,\text{연}}}{\sigma_{\text{일}} \times \sqrt{252}} = \frac{r_{\text{일}} - r_{f,\text{일}}}{\sigma_{\text{일}}} \times \sqrt{252}$
  - **데이터 비대칭성과 $\sqrt{252}$ 복구**:
    * 주가 수익률($r_{\text{일}}$)은 매일 들어오지만, 국채 금리($R_f$)는 연 단위(3%)이므로 연간 기준($\times 252$)으로 단위를 통일
    * 분산은 원래 제곱($\sigma^2$) 개념이므로 기간을 252일로 확장할 때는 $\sqrt{252}$로 원상 복구
    * 약분 결과 $\frac{252}{\sqrt{252}} = \sqrt{252}$가 되어 일간 샤프에 $\sqrt{252}$만 곱하면 끝남을 직관적으로 설명
  - **3변수 정리**: $R$(일간 평균 $\times 252$), $R_f$(연 3.0%), $\sigma$(일간 표준편차 $\times \sqrt{252}$)
  - **Sharpe 수계산**: 직관적 수계산 ((15% - 3%) / 10% = 1.2) 및 파이썬 3줄 코드 설명
  - **전략 유형별 현실적 샤프 지수 기준 해설**:
    * 단일 지수/단순 보유: 0.3~0.5 (S&P 500 장기도 0.4~0.5)
    * 단일 자산 추세추종(클립 08~09): 0.4~0.7 (독립 베팅 횟수가 적어 1.0 미만이 정상이며, 하락장 방어가 본질)
    * 멀티에셋 자산배분(클립 12~13): 0.7~1.1 (비상관 자산 분산으로 변동성 축소)
    * 시장중립 페어트레이딩(클립 14~15): 1.0~1.5 (베타 제거, 순수 알파 추출)
    * 4대 전략 융합 포트폴리오(Part 3): 1.2~1.6 달성
    * **단일 지수 전략에서 1.5 이상 나오면 과최적화(오버피팅)나 아직 모르는 값을 신호에 쓴 버그(시점 오류)를 먼저 의심할 것** 강조
- (14~19분) **이론: MDD의 진실과 비대칭 복리의 함정**
  - **HWM(High-Water Mark)**: 과거 전 기간 최고가 기준 계산
  - **30년 MDD의 현실**: 지수 단순보유(-50~-55%) vs 단일 퀀트(-20~-30% 선 방어) vs 다중 자산배분(-15% 이내)
  - **비대칭 복리**: -50% 손실 시 원금 회복에 +100% 필요 (투자자가 바닥에서 포기하는 원인)
  - 전략 A(CAGR 25%, MDD -65%) vs 전략 B(CAGR 18%, MDD -22%) 비교
- (19~22분) **이론: 거래비용(0.3%)의 보이지 않는 공포**
  - 수수료 + 증권거래세 + 슬리피지의 합산 효과
  - 연간 200회 매매 시 60%의 수익률이 증발하는 회전율의 법칙
- (22~27분) **화면 시연**: Claude Code로 가상 백테스트 및 2-패널 차트 생성
  - 프롬프트(4블록: 맥락/만들 것/하지 말 것/확인) 입력
  - Gross vs Net 성과 비교표 및 `backtest_metric_demo.png` 언더워터 플롯 확인
- (27~28분) **체크리스트 점검 및 마무리**

## 강조 포인트

- **CAGR과 샤프 $R_p$의 모순 없는 분담**: "내 돈이 몇 배 되었는가(자산 성장)"는 CAGR, "그 과정의 위험 대비 효율"은 샤프 지수
- **샤프 연율화는 약분의 원리로 30초 내 설명**: $R_{\text{연}}$은 252배, $\sigma_{\text{연}}$은 $\sqrt{252}$배이므로 $\frac{252}{\sqrt{252}} = \sqrt{252}$가 되어 일간 샤프에 $\sqrt{252}$만 곱하면 끝난다는 직관적 전달
- **현실적인 MDD 기준치**: 단일 주식 전략으로 30년 MDD -15%는 비현실적. S&P500의 -50%를 -20~-30%로 방어하는 것이 단일 퀀트의 실질적 성공 기준임을 안내
- 거래비용 0.3%는 이후 4대 전략 백테스트 프롬프트에 기본 조건으로 계속 들어감을 예고
