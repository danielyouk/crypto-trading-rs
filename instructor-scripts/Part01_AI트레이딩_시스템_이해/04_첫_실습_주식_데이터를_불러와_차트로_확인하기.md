# 첫 실습: 주식 데이터를 불러와 차트로 확인하기

## 도입 멘트 (1분)

오늘은 여러분 손으로 첫 결과물을 만듭니다. 끝나면 여러분 화면에 직접 만든 일봉 차트가 떠 있을 겁니다. 지난 클립에서 배운 4칸 골격(맥락-만들 것-하지 말 것-확인)을 그대로 씁니다.

## 진행 흐름

- (0~1분) 도입
- (1~7분) 이론: 일봉 데이터 구조 (시가/고가/저가/종가/거래량) — 실제 데이터 표를 띄워놓고 설명
- (7~10분) 이론: 이동평균선 — 잔떨림을 걸러 추세를 본다, Part 2 추세추종의 예고편임을 언급
- (10~16분) **시연: 실습 02** — 프롬프트 입력부터 차트 완성까지 실시간
  - **4칸 프롬프트 구조 설명**:
    * `[맥락]`: "한국 주식 추세 분석을 위한 전문 2-패널 차트 제작"
    * `[만들 것]`: "삼성전자 3년 일봉 + 20/60/120 이평선 + 거래량 막대(상승 빨강/하락 파랑) + 한글 폰트 + 고해상도 PNG 저장"
    * `[하지 말 것]`: "불필요한 파일 생성 금지, 가짜 주가 하드코딩 금지, 화면 멈추는 plt.show() 창 띄우지 말고 파일로 바로 저장, 오류 시 우회 금지"
    * `[확인]`: "파일 경로와 최근 5일치 종가·이평선 요약 표 출력"
  - 중간에 AI가 생성하는 코드가 흘러가면: "이 코드를 일일이 읽을 필요 없습니다. 우리는 결과를 검증합니다."
  - 완성된 차트를 열고 체크리스트 4개를 하나씩 화면에서 확인
- (16~18분) 변형 시연: 종목을 바꿔서 다시 요청 — 프롬프트 한 줄만 바꾸면 된다는 것
- (18~20분) 흔한 문제 소개 (한글 폰트 깨짐 등) + 마무리

## 강조 포인트

- 체크리스트 확인 장면을 충분히 천천히 — "확인은 사람이 한다"의 첫 실전
- 포털 종가와 대조하는 습관: 데이터가 맞는지 의심하는 것도 트레이더의 기본기
- 수강생 차트가 강의 화면과 다르게 생겨도 성공이라는 것을 명시적으로
