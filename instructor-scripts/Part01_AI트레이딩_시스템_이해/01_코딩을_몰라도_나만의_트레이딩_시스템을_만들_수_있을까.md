# 코딩을 몰라도 나만의 트레이딩 시스템을 만들 수 있을까?

## 도입 멘트 (2분)

안녕하세요, 다니엘입니다. 반갑습니다. 

이 강의를 클릭하신 분들은 대부분 비슷한 고민을 안고 오셨을 겁니다. "코딩도 모르고 퀀트도 잘 모르는데, 내가 정말 나만의 자동매매 시스템을 만들 수 있을까?"

오늘 첫 시간에는 복잡한 설정이나 문법 강의를 하지 않습니다. 증권사 계좌를 개설하거나 API 키를 준비할 필요도 전혀 없습니다. 

오늘은 우리가 5개 파트를 거치며 완성하게 될 **'2-Tier 하이브리드 AI 트레이딩 시스템의 3D 조감도(시뮬레이션 데모)'**를 화면으로 먼저 보여드리고, 어떤 구조와 원리로 돌아가는지 그 청사진을 명확히 보여드리겠습니다.

---

## 진행 흐름

### 1. [0~2분] 오프닝 & 강의의 본질 선언
- 강사 소개 및 엔지니어링 배경(기계공학 엔지니어 → AI 데이터 사이언티스트 → 80명 규모 AI 에이전트 리딩 & 벤치마킹 프로젝트 리드).
- "이 강의는 코딩을 외우는 강의가 아닙니다. 투자 아이디어를 시스템으로 설계하고 검증하는 **사고의 방식(Thinking Process)**을 배우는 과정입니다."

### 2. [2~8분] 완성 시스템 시뮬레이션 조감도 시연 (6분)
- **화면 구성**: 강의 자료의 2-Tier 아키텍처 다이어그램 및 시뮬레이션 애니메이션(`03_paper_approval.gif`) 화면 송출.
- **단계별 설명 포인트 (2-Tier 풀 사이클)**:
  - **Tier 1 (주간 전략 거버넌스)**: 주말 30분, Claude Code와 지난 1주일간의 시장 국면과 전략 성과를 복기하고, 다음 주 실행할 매매 정책(`weekly_policy.json`)을 수강생(사람)이 최종 승인.
  - **Tier 2 (일간 무인 자동 실행)**: 평일 장중에는 사람이 개입하지 않고, 승인된 조건 부합 시 증권사 API로 자동 모의주문 발주.
  - **무인 하드 안전망**: 개별 종목 -3% 또는 포트폴리오 -2% 손실 시, 사람에게 묻지 않고 0.1초 만에 즉각 강제 손절 집행.
  - **Post-Market 일일 저널**: 장 마감 후 AI가 체결 내역과 손익을 분석해 일일 매매 일지 자동 작성.
- **수강생 안심 멘트**: "수강생 여러분, 지금 당장 증권사 계좌나 API를 연동할 필요는 전혀 없습니다. Part 1부터 3까지는 주식 데이터 분석과 전략 검증에 집중하고, 모의계좌 연동은 **Part 4에서 클릭 몇 번으로 아주 쉽게 함께 만들 것**입니다. 오늘은 전체 조감도만 편안하게 확인하시면 됩니다."

### 3. [8~13분] 개념 설명: 단순계 vs 복잡계 — 엔지니어링과 AI 현장에서 겪은 진실 (교수식 브리핑)
- **강사의 실제 경험담 (엔지니어링의 반전)**:
  - 기계공학을 학교에서 배울 때는 어렵지 않고 수식대로 움직이는 것 같았으나, 실제 현장에서 개발해 보니 예상치 못한 수많은 변수가 발생하는 **전형적인 복잡계(Complex System)**였음.
  - 오히려 초기의 단순 코딩이나 데이터 분석은 입력에 따라 결과가 나오는 **단순계(Simple System)**처럼 느껴져 편안했음.
  - 하지만 최근 80명 규모의 AI 에이전트 협업 프로젝트를 리딩하면서 현대의 개발 역시 다시 **거대한 복잡계**로 돌아왔고, AI로 모든 것을 자동화하는 것은 결코 쉽지 않음을 체감함.
- **AI 벤치마킹 프로젝트(GDPval 등)의 최신 교훈**:
  - 장표 분석이나 문서 요약 같은 단순계 업무는 AI가 이미 사람이나 전문가보다 월등히 잘함.
  - 하지만 복잡계로 갈수록 AI 단독으로 인간을 대체할 수 없음.
- **금융시장 = 복잡계 중의 복잡계 (The Ultimate Complex System)**:
  - ① 비선형적 인과관계: 작은 나비의 날갯짓이 대폭락으로 이어짐.
  - ② 다중 인과관계의 얽힘: 수많은 참여자의 심리와 매크로 변수가 상호 피드백.
  - ③ 인과관계 규칙 자체의 진화: 과거 패턴을 학습하는 순간 시장 규칙이 바뀌어 과거 최적 모델이 붕괴함.
  - ④ 숨겨진 인과관계와 끊임없는 예외/블랙스완의 발생.
- **결론: 2-Tier 하이브리드 아키텍처의 필연성**:
  - 일주일에 30분, 거시적 시장 국면 판단과 전략 정책 승인은 사람(CIO)이 담당.
  - 장중 지치지 않는 계산과 규율 있는 자동 실행은 기계 엔진이 담당.
  - 돌발 급락에 대한 손절은 감정을 배제한 코드 레벨의 무조건 규칙이 0.1초 만에 집행.

### 4. [13~18분] 패러다임 전환: 코더에서 시스템 아키텍트로
- 문법 암기식 코딩 학습의 좌절과 한계 지적.
- **생각 → 요청 → 확인 → 개선 4단계 루프** 설명:
  - "코드가 강사와 똑같은지 보지 마세요. 화면에 차트가 제대로 나왔는지만 보세요."
  - 확인을 AI에게 맡기면 안 되는 이유 (AI의 과도한 자기 확신).
- **5개 파트 완주 로드맵 브리핑**:
  - Part 1: 환경과 첫 차트 → Part 2: 4대 전략 백테스트 → Part 3: 워크포워드 검증 → Part 4: 2-Tier 정책 승인 & 자동 API 연동 → Part 5: 일일 운영 루틴.

### 5. [18~20분] 마무리 및 다음 클립 안내
- "컴퓨터와 아이디어만 있으면 충분합니다."
- 다음 클립: Claude Code 설치 및 첫 주식 차트 출력 실습.
