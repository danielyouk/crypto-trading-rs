# 실습 준비: AI 코딩 Claude Code 도구 설치와 기본 환경 설정

## 도입 멘트 (1분)

지난 클립에서 완성품을 보셨죠. 오늘부터 그걸 만들 도구를 손에 쥡니다. 설치라고 하면 벌써 머리가 아픈 분 계실 텐데, 오늘 보여드릴 핵심은 "설치조차 AI에게 시킨다"는 겁니다.

## 진행 흐름

- (0~1분) 도입
- (1~5분) 이론: AI 코딩 환경 중심 진행 — 어떤 AI 도구(Cursor, Claude Desktop, Codex 등)를 써도 '목표 선언과 검증 루프'라는 핵심 원리는 동일하며, 실습은 가장 강력한 AI 코딩 환경으로 일원화하여 진행함을 안내
- (5~8분) 이론: 비용 구조 투명 공개 — API Key 종량제 vs 정액제, 월 예상 비용 화면으로 보여주기
- (8~15분) **시연: 실습 01** — 작업 폴더 생성 → Claude Code 설치 → 첫 프롬프트로 Python 환경 + FinanceDataReader 설치 → 삼성전자 종가 출력까지 실시간 진행
  - 설치 로그가 흘러가는 동안: "이 화면을 다 이해할 필요 없습니다. 우리는 마지막 결과만 확인합니다"
- (15~17분) 체크리스트 확인 — 포털에서 삼성전자 종가 검색해서 대조하는 모습 시연
- (17~18분) 마무리 + 예고

## 강조 포인트

- 설치 화면이 수강생마다 다르다는 것을 시연 중 최소 2번 언급
- 에러가 나도 당황하지 말고 "에러를 복사해서 붙여넣는다"가 유일한 대응임을 예고 (다음다음 클립에서 자세히)
- 비용 얘기는 숨기지 말고 실제 청구 화면 캡처로 보여줄 것
