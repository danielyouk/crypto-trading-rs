# 실습 준비: AI 코딩 도구 실행과 기본 환경 설정

## 촬영 전 준비 (카메라 밖)

- [ ] 편집기(Cursor 또는 VS Code)에서 Claude Code 확장을 **미리 지운 상태**로 시작 — 설치 장면을 실제로 보여줘야 함
- [ ] 바탕화면에 `ai-trading` 폴더가 **없는 상태** 확인
- [ ] 브라우저에 포털 주식 시세 탭을 미리 열어 두기 (Step 4 대조용)
- [ ] `Shift + Tab` 모드 목록을 미리 한 번 열어 **내 화면에 Auto가 있는지 없는지 확인** — 멘트가 달라짐
- [ ] 만약 Auto가 안 보이면 `Ctrl+Shift+P` → `Reload Window` 한 번 시도

## 도입 멘트 (1분)

지난 클립에서 완성품을 보셨죠. 오늘부터 그걸 만들 도구를 손에 쥡니다. 설치라고 하면 벌써 머리가 아픈 분 계실 텐데, 오늘의 핵심은 **"설치조차 AI에게 시킨다"**는 겁니다. 우리가 직접 하는 건 클릭 몇 번뿐입니다.

## 구간별 상세

### (1~3분) 이론 압축

- 전통 코딩 vs AI 코딩 비교 카드 — **30초 안에 넘어갈 것.** 지난 클립에서 이미 다룬 내용
- 확장을 쓰는 이유 세 가지 중 **②번(diff로 나란히 보여줌)만 강조.** 나머지는 언급만
  - 멘트: "이게 왜 중요하냐면, 오늘 마지막에 보실 사건 때문입니다"
- **오해 정정 두 가지를 반드시 짚을 것**
  - "터미널 설치는 Node.js를 깔아야 한다" → 옛날 이야기
  - "확장이 토큰을 덜 쓴다" → 사실 아님. 같은 엔진, 같은 요금제
  - 멘트: "인터넷에 옛날 정보가 많아서 미리 정리하고 갑니다"

### (3~6분) Step 0 — 확장 설치와 모드 설정

- Extensions에서 `Claude Code` 검색 → Install → 로그인까지 실시간
- `Shift + Tab`으로 모드 목록 열기
- **⚠️ 가장 중요한 멘트 — 반드시 할 것**
  > "제 화면에는 모드가 N개 보이는데, 여러분 화면에는 다를 수 있습니다. 실제로 제 노트북과 이 컴퓨터가 같은 버전인데도 목록이 달랐습니다.
  > 그래서 제가 '위에서 세 번째를 고르세요'라고 말하지 않겠습니다. **이름으로 찾으세요.**
  > 우리가 하려는 건 '승인 버튼을 매번 안 누르게 만드는 것'이고, `Edit automatically`나 `Auto` 중 보이는 걸 고르시면 됩니다."
- 이어서 원칙 한 문장:
  > "AI 도구는 화면이 자주 바뀝니다. **화면을 외우지 말고 목적을 기억하세요.** 이 강의 내내 반복될 이야기입니다."

### (7~9분) Step 2 — 진단 프롬프트

- 입력 전에 **왜 진단을 따로 하는지** 먼저 설명 (30초)
  > "한 번에 다 시키면 AI가 막혔을 때 멈추지 않고 혼자 우회로를 찾습니다. 그게 오늘 마지막에 보실 사고의 원인이었습니다."
- Windows 껍데기 Python 줄을 짚으며:
  > "이 줄이 왜 이렇게 구체적이냐면, 제가 여기서 10분을 날렸기 때문입니다. Windows에는 Python인 척하는 껍데기가 기본으로 들어 있는데 AI도 여기 속습니다."
#### ⚠️ 촬영자 화면과 수강생 화면이 갈리는 지점

**촬영용 컴퓨터에는 Python이 이미 있어서 "있음"이 나오지만, 수강생 대부분은 "없음"이 나옵니다.**
별도 촬영 없이 **말로 안내**하고 넘어갑니다. 교재의 갈림길 표를 화면에 띄운 채 이렇게 말하세요.

> "제 화면에는 'Python 있음'이라고 나왔는데, **여러분 화면에는 '없음'이라고 나올 가능성이 더 높습니다. 그게 정상입니다.** 요즘 컴퓨터에는 Python이 기본으로 안 깔려 있거든요.
>
> 없다고 나와도 하실 일은 딱 한 줄 추가하는 것뿐입니다. 다음 프롬프트의 `[만들 것]` 맨 위에 **`uv를 사용해서 Python 3.12부터 설치해줘.`** 이 한 줄만 넣으시면, `uv`라는 도구가 Python까지 알아서 깔아 줍니다.
>
> 그래서 진단을 먼저 한 겁니다. **내 컴퓨터가 어느 쪽인지 알고 요청하면, 한 줄만 바꾸면 됩니다.** 모르고 요청하면 AI가 혼자 헤맵니다."

- 이 멘트 뒤에 **교재 갈림길 표를 3초 이상 화면에 고정**할 것 (수강생이 캡처할 시간)
- "없음" 화면을 억지로 재현하려 하지 말 것 — 시간만 쓰고 실익이 없음

### (9~15분) Step 3 — 구축 프롬프트

- **프롬프트를 붙여넣기 전에 네 칸 표부터 보여줄 것.** 각 칸 30초씩, 총 2분
  > "복사만 하고 넘어가면 다음 프로젝트에서 못 씁니다. 왜 이 칸들이 있는지만 이해하고 가세요."
- `[하지 말 것]` 칸에서 시간을 더 쓸 것 — 가장 낯선 개념
  > "라이브러리 3개만 요청했는데 AI가 22개를 설치한 적이 있습니다. 그래서 이 줄이 생겼습니다."
- 실행. **설치 로그가 흘러가는 구간은 편집으로 압축**하되, 그 위에 자막:
  > "여러분 화면은 다르게 흘러갑니다. 마지막 결과만 확인하면 됩니다"
- 결과가 나오면 `[확인]` 칸이 요구한 것(버전 3개 + 5행 표)이 실제로 나왔는지 짚기

### (15~18분) Step 4 — 대조와 훅 ★하이라이트

1. 체크리스트 앞의 세 항목을 화면에서 빠르게 확인
2. **폴더를 열어 파일이 `check.py` 하나뿐인지 눈으로 보여줄 것** (울타리가 작동한 증거)
3. **브라우저를 켜서 포털 시세와 종가를 직접 대조** — 이 장면이 오늘의 핵심
   > "AI가 '완료했습니다'라고 해도 아직 끝난 게 아닙니다. 앞의 세 개는 화면만 봐도 알지만, 이건 **다른 창을 열어야만** 알 수 있습니다."
4. 다음 클립 훅 걸기 (여기서 자세히 설명하지 말 것 — 30초)
   > "제가 이 프롬프트를 만들 때 실제로 사고가 있었습니다. AI가 주가를 못 가져오자 인터넷에서 찾은 숫자를 코드에 적어 넣고 '완료했습니다'라고 보고했습니다. 화면은 완벽했고 에러도 없었습니다. **6,500원이 틀렸습니다.**
   > 그게 왜 치명적인지는 다음 클립에서 숫자로 보여드리겠습니다."

### (18~19분) 비용

- Pro 하나면 충분하다는 것만. **요금제 표를 띄우고 읽지 말 것**
- "자세한 비용 관리는 Part 5에서 따로 다룹니다"

## 강조 포인트

- **"몇 번째를 고르세요"라는 표현을 절대 쓰지 말 것** — 환경마다 화면이 다름
- 설치 화면이 수강생마다 다르다는 것을 최소 2번 언급
- 프롬프트는 **읽고 나서** 붙여넣기 — 복붙 지시로 들리면 안 됨
- 에러가 나면 당황하지 말고 그대로 노출할 것. "에러를 복사해 붙여넣는다"가 유일한 대응임을 예고 (Clip 05에서 자세히)
