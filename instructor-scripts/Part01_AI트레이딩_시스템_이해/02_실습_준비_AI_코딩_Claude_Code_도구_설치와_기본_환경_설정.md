# 실습 준비: AI 코딩 Claude Code 도구 설치와 기본 환경 설정

## 촬영 전 준비 (카메라 밖)

- [ ] 에디터(VS Code 또는 Cursor)에서 Claude Code 확장을 설치할 준비
- [ ] 바탕화면에 작업용 빈 폴더 `ai-trading` 생성 준비
- [ ] 브라우저에 네이버/다음 포털 증권 화면(삼성전자 시세 확인용) 미리 열어두기

## 도입 멘트 (1분)

지난 클립에서 시스템 전체의 설계도를 확인했습니다. 오늘부터는 그 시스템을 함께 만들 최고의 AI 조수를 우리 컴퓨터에 준비합니다. 복잡한 파이썬 설치나 버전 충돌 걱정 없이, **설치와 환경 구축조차 AI에게 위임하고 우리는 눈으로 결과만 확인**하는 제로코드 환경을 완성해 보겠습니다.

## 진행 전제조건

- 수강생 컴퓨터에 **VS Code 또는 Cursor 에디터**가 이미 설치되어 있다고 가정합니다.
- Anthropic 계정 가입 및 유료 플랜(**Claude Pro** 또는 **Claude Max**)이 준비되어 있어야 합니다. (기본 실습은 Pro 플랜으로 충분하며, Max 플랜도 완벽 지원)

## 구간별 상세 강사 멘트

### (1~4분) 이론 핵심
- **전통 코딩 vs AI 코딩**: "우리가 파이썬 문법을 외울 필요는 없습니다. 규칙과 목표를 정의하고 검증하는 아키텍트의 역할을 맡습니다."
- **왜 확장(Extension)인가?**: 
  1. 원클릭 설치로 환경 설정 스트레스 제로
  2. 수정 전후를 나란히 보여주는 **좌우 비교 화면(Diff)** 제공
  3. 문제 발생 시 체크포인트로 안전한 롤백 지원

### (4~7분) Step 1: 확장 설치 및 자율권 모드 설정
- 마켓플레이스에서 `Claude Code` 검색 후 설치 및 로그인 시연
- **자율권 모드 설명**:
  > "프롬프트 입력창 아래 모드 버튼을 누르시면 몇 가지 모드가 있습니다.  
  > **Plan**은 코드 수정 없이 계획서만 짜는 모드, **Manual**은 하나하나 확인하며 승인하는 모드, **Auto**는 안전한 작업을 알아서 척척 진행해 주는 모드입니다.  
  > 오늘은 초기 설치와 실행 명령이 포함되므로 **`Auto` 모드를 선택**합니다. 만약 목록에 Auto가 보이지 않는다면 Edit automatically를 선택하시고, 명령어 실행 팝업에서 **'Yes, and don't ask again'**을 눌러주시면 됩니다."

### (7~10분) Step 2: 시스템 파이썬 환경 진단
- 30초 진단 프롬프트 실행:
  > "아직 아무것도 설치하지 않고 컴퓨터 상태만 먼저 진단합니다. AI에게 단번에 일을 시키면 중간에 꼬였을 때 혼자 우회하기 때문입니다."
- **화면 갈림길 안내**:
  > "제 화면에는 파이썬이 있다고 나오지만, 여러분 컴퓨터에는 '없음'으로 나올 수 있습니다. 지극히 정상이니, 그럴 때는 다음 프롬프트에 `uv를 사용해서 파이썬 3.12부터 설치해줘` 한 줄만 더해주시면 됩니다."

### (10~15분) Step 3: 4칸 프롬프트 실행
- 4칸 구조(맥락-만들것-하지말것-확인)를 화면에 띄우고 프롬프트 입력:
  > "수강생 여러분은 `FinanceDataReader` 같은 복잡한 패키지 이름을 외우실 필요가 전혀 없습니다. 우리는 AI에게 '한국 주식 데이터를 가져올 도구'라는 목적만 말하면, AI가 최적의 오픈소스를 스스로 판단해 설치합니다."
  > "하지 말 것(Guardrail)에 명확한 한계를 주어야 AI가 엉뚱한 파일을 수십 개 만들거나 가짜 숫자를 하드코딩하지 않습니다."
- 독립 가상환경(`.venv`)의 개념을 간단히 설명 (이 폴더만의 격리 도구 상자).

### (15~18분) Step 4: 시세 교차 검증 & Diff 화면 체험
1. **데이터 무결성 검증**:
   > "AI가 '완료했습니다'라고 해도 맹신하면 안 됩니다. 포털 화면을 띄워 표의 마지막 줄 종가와 실제 시세를 직접 대조합니다."
2. **수동 승인(Diff) 체험**:
   - 모드를 `Manual`로 변경 후 5일 평균 종가 계산 코드 추가 요청
   - 에디터 중앙에 열리는 좌우 비교 화면(Diff)에서 초록색 변경 코드를 확인하고 직접 수정한 뒤 승인하는 모습 시연.

## 마무리 멘트 (1분)

이제 여러분 컴퓨터에 퀀트 트레이딩을 위한 완벽한 AI 개발 환경이 준비되었습니다.  
다음 클립에서는 오늘 사용한 **4칸 프롬프트 골격(맥락-산출물-울타리-검증)**을 하나씩 해부하고, AI의 거짓 보고를 완벽하게 걸러내는 프롬프트 설계법을 마스터하겠습니다.
