## 00:30 ~ 02:00 | 2. 에디터와 AI 확장 설치 (Step 1-1)

화면을 봐주시기 바랍니다.

가장 먼저 작업할 빈 폴더를 하나 열어주겠습니다.  
상단 메뉴에서 `File`, 그리고 `Open Folder`를 누르신 다음, 바탕화면이나 원하시는 위치에 `ai-trading`이라는 이름의 새 폴더를 만들어서 열어줍니다.

`[화면: ai-trading 폴더가 열린 빈 에디터 화면]`

자, 폴더가 깔끔하게 열렸죠? 이제 이 에디터 안에 우리의 AI 파트너인 **Claude Code 확장 프로그램**을 설치하겠습니다.

`[화면: 왼쪽 사이드바 Extensions 아이콘(네모 블록) 클릭]`

그리고 상단 검색창에 영어로 `Claude Code`라고 입력해 줍니다.

`[화면: 검색 결과에서 Anthropic 공식 Claude Code 확인 및 Install 클릭]`

검색 결과 맨 위에 Anthropic 사에서 공식 배포한 `Claude Code`가 나타납니다. 여기서 파란색 `Install` 버튼을 눌러줍니다.  
설치가 클릭 한 번으로 끝나기 때문에 별도의 복잡한 설치 프로그램을 다운로드하거나 경로를 잡으실 필요가 전혀 없습니다.

설치가 완료되면 왼쪽이나 오른쪽 사이드바에 Claude 아이콘이 새로 생깁니다.  
이 아이콘을 누르면 대화창이 열리는데요, 처음 사용하시는 분들은 로그인 안내가 나오면 안내에 따라 로그인을 완료해 주시면 됩니다.

## 02:00 ~ 04:30 | 3. 자율권 모드 설정 — Auto와 Plan의 차이 (Step 1-2)

`[화면: Claude 대화창 하단 입력창 부근 확대]`

자, 이제 대화창이 준비되었습니다.  
프롬프트 입력창 맨 아래쪽을 보시면 현재 어떤 모드로 설정되어 있는지 작은 글씨나 아이콘이 보이실 겁니다.

이 부분을 마우스로 클릭하시거나, 키보드에서 `Shift`와 `Tab` 키를 동시에 누르면 모드를 바꿀 수 있는 메뉴가 나타납니다.

`[화면: Shift + Tab을 눌러 모드 선택 팝업 표시]`

이 메뉴는 쉽게 말해서 **"AI에게 어디까지 알아서 일할 수 있는 자율권을 줄 것인가"**를 결정하는 스위치입니다. 총 4가지 모드가 있습니다.

1. 첫 번째 **Plan(플랜)** 모드는 코드를 전혀 수정하거나 실행하지 않고, "어떤 방식으로 구현할지 전체 계획서만 먼저 작성"하는 설계 모드입니다. 구조가 복잡한 전략을 짤 때 유용합니다.
2. 두 번째 **Manual(매뉴얼)** 모드는 AI가 파일 하나를 고칠 때마다, 명령어 하나를 실행할 때마다 사람에게 "이거 실행해도 될까요?" 하고 승인 버튼을 띄우는 수동 검토 모드입니다.
3. 세 번째 **Edit automatically**는 파일 수정은 알아서 해주지만, 터미널 명령어 실행은 여전히 승인을 물어보는 모드입니다.
4. 마지막 네 번째 **Auto(오토)** 모드는 안전 검사를 통과한 파일 수정과 설치 명령어를 AI가 스스로 판단해서 막힘없이 진행해 주는 자동 모드입니다.

`[화면: Auto 모드 선택 클릭]`

오늘 우리는 초기 파이썬 환경을 구축하고 라이브러리를 설치해야 하므로, 승인 버튼을 매번 누르지 않아도 되는 **`Auto` 모드를 선택**하겠습니다.

만약 여러분 화면 목록에 `Auto`가 보이지 않는다면, `Edit automatically`를 선택하신 뒤 잠시 후 명령어 실행 승인 팝업이 뜰 때 **`Yes, and don't ask again` (예, 다시 묻지 않기)** 버튼을 한 번 눌러주시면 그 뒤로는 조용하게 알아서 실행됩니다.

이제 오늘 실습의 마지막 하이라이트입니다.  
지금까지는 속도를 위해 AI에게 `Auto` 모드로 자율권을 주었지만, 이번에는 자율권을 거둬들이고 **사람이 AI의 코드를 승인 전에 직접 눈으로 확인하고 고치는 경험**을 해보겠습니다.

1. 프롬프트 하단의 모드 버튼을 눌러 **`Manual` (매뉴얼)** 모드로 변경합니다.
2. 그리고 대화창에 가벼운 1줄 요청을 보냅니다:  
   *"hello_market.py에 최근 5일 종가의 평균을 계산해서 표 아래에 한 줄로 출력하는 코드를 추가해줘."*

`[화면: 프롬프트 전송 후 에디터 중앙에 좌우 분할 Diff 창이 열리는 화면]`

엔터를 치자마자, 이번에는 코드가 바로 바뀌지 않고 에디터 중앙에 **좌우 비교 화면, 즉 Diff 창**이 새 탭으로 열립니다!

- **왼쪽 화면**: 기존에 작성되어 있던 원본 코드입니다.
- **오른쪽 화면**: AI가 새롭게 추가하거나 수정한 제안 코드이며, 초록색으로 칠해진 줄이 새로 들어갈 코드입니다.

여기서 가장 중요한 핵심은, **오른쪽 화면에 마우스 커서를 올리고 우리가 직접 글자를 타이핑해서 수정할 수 있다는 점**입니다.

`[화면: 오른쪽 코드에서 출력 텍스트를 "5일 평균 종가(원):"으로 직접 수정하는 모습]`

제가 코드의 출력 문구를 살짝 수정해 보겠습니다.  
이렇게 내가 직접 검토하고 수정한 뒤, 상단의 `Accept` (승인) 버튼을 누르면 그제서야 최종 파일에 반영됩니다.

AI가 초안을 잡고, 최종 결정과 검토는 사람이 직접 내리는 **'인간 개입형 시스템 아키텍트의 기본 루프'**를 직접 경험하신 것입니다.

## 17:00 ~ 19:00 | 7. 자주 묻는 질문 (FAQ) & 트러블슈팅

`[화면: 교재 FAQ 슬라이드]`

오늘 실습을 진행하시면서 혹시 마주칠 수 있는 대표적인 질문 3가지를 정리해 드리겠습니다.

**Q1. 윈도우에서 파이썬이 깔려 있다고 뜨는데 실제 실행이 안 됩니다.**  
윈도우에 기본으로 내장된 '마이크로소프트 스토어 안내용 껍데기' 프로그램 때문입니다. AI에게 `"uv를 사용해서 Python 3.12를 새로 설치하고 가상환경을 다시 만들어줘"`라고 한 줄만 요청하시면 깨끗하게 해결됩니다.

**Q2. 패키지 다운로드 중에 타임아웃 에러가 뜹니다.**  
일시적인 인터넷 지연 현상입니다. 대화창에 `"pip install 타임아웃 시간을 늘려서 다시 설치해줘"`라고 요청하시면 AI가 재시도합니다.

**Q3. 콘솔 화면에서 한글이 깨져 보입니다.**  
윈도우 환경의 기본 인코딩 문제일 수 있습니다. `"출력에서 한글이 깨지지 않도록 UTF-8 인코딩을 적용해줘"`라고 말씀하시면 AI가 출력 코드를 즉시 보정해 줍니다.
